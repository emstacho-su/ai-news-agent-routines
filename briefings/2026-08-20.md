## Tools & Frameworks

### [NEW] Claude Code v2.1.236–237: Concise mode, ANTHROPIC_DEFAULT_MODEL, cross-session idle notify
Two releases landed this week that directly affect multi-session agentic workflows:

**v2.1.236 (Aug 19):**
- `ANTHROPIC_DEFAULT_MODEL` env var: sets the startup model for new sessions; `/model` picks still override and persist
- `notify_when_idle` added to cross-session `SendMessage`: another session sends exactly one notification when it goes idle (opt-in, one-shot, no polling; macOS + Linux)
- `/permissions` can now be opened while Claude is mid-task, with rule changes applying to the rest of the current turn
- Built-in `claude-api` skill context cost reduced from ~200k tokens to ~25k via on-demand doc loading

**v2.1.237 (Aug 20):**
- Built-in "Concise" output style under `/config → Output style`: Claude leads with results and skips preamble/narration, work depth unchanged
- Prompt caching fix for sessions using an LLM gateway or custom base URL (was broken)

Sources: [Claude Code changelog](https://code.claude.com/docs/en/changelog), [Classmethod writeup](https://dev.classmethod.jp/en/articles/20260820-cc-updates-v2-1-237/)

**Why it matters:** `notify_when_idle` + `ANTHROPIC_DEFAULT_MODEL` are particularly useful for orchestrated multi-session workflows — you can now fire a background session at a default model and get paged when it's done without polling. Concise mode is the answer to the "stop narrating the work" complaint.

## Research & Technical

### [NEW] OpenAI Astra: 10 long-open math/CS problems solved with fully verified Lean 4 proofs
On August 1, OpenAI announced that an internal version of its next major model, Astra, resolved ten open problems in math and theoretical computer science, each open for at least a decade. The headline result is the first explicit construction of a non-sofic group (a question open since Gromov, 1999). Others include the disproof of Connes's rigidity conjecture on von Neumann algebras, proof of Ehrhart's volume conjecture, and resolution of three Erdős catalogue problems. Full 249-page manuscript plus machine-checkable Lean 4 certificates published to GitHub; `sorry` count: zero. Compute cost: ~$2,000 at Sol API rates. Fields Medal winner Timothy Gowers said he would recommend one of the proofs for a top journal. [SiliconAngle](https://siliconangle.com/2026/08/02/openais-astra-solves-10-long-open-math-problems-publishes-proofs/), [The Next Web](https://thenextweb.com/news/openai-astra-model-ten-math-proofs-non-sofic-groups), [Forbes](https://www.forbes.com/sites/jonmarkman/2026/08/03/openais-astra-solved-10-decades-old-math-problems-for-just-2000/)

## Wildcard

### [NEW] llama.cpp CVE-2026-43631: use-after-free RCE in llama-server (builds b7492–b9060)
A use-after-free in llama-server's vocab pointer when `--sleep-idle-seconds` is enabled allows unauthenticated remote attackers to execute arbitrary code. Affects builds b7492 through b9060. Two Android JNI wrapper issues also landed in the same disclosure window (CVE-2026-70640, -70638: race condition and integer overflow). If you're self-hosting llama.cpp for local inference — common in security research and dev tooling — update immediately. [GitHub Advisory GHSA-6hc7-9rph-cm99](https://github.com/advisories/GHSA-6hc7-9rph-cm99), [SentinelOne CVE DB](https://www.sentinelone.com/vulnerability-database/cve-2026-43631/)
