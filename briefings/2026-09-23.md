## Anthropic

### [NEW] Claude Opus 5.5: Fable 5.1 performance at 40% lower cost

Anthropic released Claude Opus 5.5 on September 22, 2026, the first model in a new 5.5 family. The model matches Claude Fable 5.1 on most workloads (coding, knowledge work, computer use) and costs 40% less to run than Opus 5 on typical agentic tasks. Pricing is $4/$20 per million input/output tokens — 20% below Opus 5 — with cache reads at $0.20/M (60% lower than Opus 5's $0.50/M) and cache writes at $5/M (vs $6.25/M). Available on Claude Platform, AWS Bedrock, Google Cloud, and Azure as `claude-opus-5-5`. Sources: [Anthropic](https://www.anthropic.com/claude-opus-5-5), [MacRumors](https://www.macrumors.com/2026/09/22/anthropic-claude-opus-5-5/), [Unite.AI](https://www.unite.ai/anthropic-releases-claude-opus-5-5-with-lower-pricing-and-new-safeguards/).

**Why it matters:** Cache reads dominate agentic/coding workload costs. At $0.20/M, an Anthropic-stack agent loop that was previously running on Opus 5 gets a significant cost reduction — worth re-benchmarking against Fable 5.1 to decide which to use on token-intensive routines.

**Safety note:** External evaluators (METR, Frontier Design) assessed Opus 5.5 before release. System Card classifies it CB-1 (can assist with non-novel weapons synthesis); does not cross CB-2 threshold. Anthropic collaborated with NIST CASI on bio/cyber capability measurement.

### [UPDATE] Claude Code v2.1.280: Opus 5.5 default, MCP description length control, symlink fix

**Background:** Claude Code v2.1.278 (Sept 19) set Fable 5.1 as the default Fable model and added AGENTS.md support for cross-agent repos.

**New (v2.1.280, Sept 22 2026):**
- `claude-opus-5-5` is now the default Opus model (1M context, $4/$20/M, $0.20/M cache reads)
- `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` env var lets you override the 2,048-character cap on MCP tool descriptions and server instructions
- Fixed symlink path security bug: write permissions evaluated by in-tree spelling rather than symlink target — previously, allow rules could be bypassed by writing through a symlink that resolved to a path outside the allowed tree
- Fixed auto mode retrying a declined action repeatedly; it is now denied once and not re-attempted
- 113 total items: model defaults, UI/dialog fixes, runtime and session bug fixes, VS Code/web/Slack integration fixes

Sources: [GitHub release](https://github.com/anthropics/claude-code/releases/tag/v2.1.280), [Havoptic](https://www.havoptic.com/tools/claude-code).

## Model Releases

### [NEW] OpenAI GPT-6 Sol and Luna: 50% cheaper than GPT-5.6, Astra-level reliability

OpenAI released GPT-6 Sol and GPT-6 Luna on September 22, 2026, expanding the GPT-6 family below Astra. Both are trained with methods similar to Astra but tuned for cost and speed. Sol targets complex coding and reasoning tasks and makes roughly half as many factual errors as GPT-5.6 Sol, reaching close to Astra reliability at a fraction of the price. Luna is positioned for clerical/assistant work and is free to all ChatGPT users via the desktop app. API pricing for Sol is $2/$10 per million input/output tokens (vs. GPT-5.6's $4/$20 promotional rates); Luna pricing was not separately confirmed in early reports. Both are available today to ChatGPT Work and Codex paid users; Luna is also live for free users. Sources: [TechCrunch](https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/), [gHacks](https://www.ghacks.net/2026/09/23/openai-launches-gpt-6-sol-and-luna-with-50-lower-api-pricing-than-gpt-5-6/), [Dataconomy](https://dataconomy.com/2026/09/23/openai-launches-cheaper-gpt-6-sol-luna-models/).

**Why it matters:** GPT-6 Sol at $2/$10/M undercuts Sonnet 5 ($3/$15) and is now in the same bracket as Claude Haiku 5.5 tiers. If Sol's coding reliability actually approaches Astra, it becomes a serious consideration for cost-sensitive agent loops currently running on Sonnet-tier models.

## Wildcard

### [NEW] UN Security Council convenes first joint briefing with US and Chinese frontier AI labs

France (September Security Council president) convened a high-level session on AI and international security on September 23, 2026, during the 81st UN General Assembly high-level week. For the first time, the Council directly hosted frontier AI developers from both the US and China. Sam Altman (OpenAI), Dario Amodei (Anthropic), Clément Delangue (Hugging Face), and Yoshua Bengio (co-chair, UN Independent International Scientific Panel on AI) briefed the Council; DeepSeek was also invited but founder Liang Wenfeng did not attend (senior representation expected). Amodei used the occasion to reiterate his "We Must Pace the Frontier" position and call for international coordination on AI safety evaluations. No binding resolutions are expected from the open briefing. Sources: [Cryptobriefing](https://cryptobriefing.com/altman-un-security-council-ai-briefing/), [The420.in](https://the420.in/openai-anthropic-un-security-council-ai-safety-altman-amodei/), [Security Council Report](https://www.securitycouncilreport.org/whatsinblue/2026/09/artificial-intelligence-high-level-briefing-2.php).

## Practical tips

- **Claude Opus 5.5 cache reads are $0.20/M** — for agentic loops that prepend a large system prompt or context on every call, upgrading from Opus 5 may cut costs by more than 60% on the cache-read component alone. Worth running a quick cost projection on any workload that was previously blocked by Opus 5 pricing.
- **`CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`** — if you're building dense MCP tools with long descriptions/instructions (e.g., a research MCP with rich schema docs), you can now increase the 2,048-char cap rather than truncating tool docs.
- **v2.1.280 symlink fix is a security patch** — if you have auto-mode allow rules covering specific directories and your project uses symlinks, update to v2.1.280. Previous versions evaluated permissions by the in-tree symlink spelling rather than the resolved target.
