## Anthropic

### [UPDATE] Plugin4Shell: Zero-Click RCE Hits Claude Code — Patched in v2.1.179

**Background:** Claude Code's plugin system uses SHA pinning to lock installed plugins to reviewed code versions.

**New:** AIR (AI Risk) disclosed Plugin4Shell on September 18 — a SHA-pinning bypass that lets an attacker redirect a pinned plugin's checkout to malicious code without requiring any user interaction. Because Claude Code and Codex auto-update pinned plugins by default, the exploit is zero-click once a malicious branch is staged. All four affected tools (Claude Code, OpenAI Codex, GitHub Copilot, Gemini CLI) share the same flawed assumption: that naming a commit SHA and verifying it are equivalent operations. Anthropic shipped the patch in Claude Code v2.1.179; OpenAI patched Codex v0.146.0. Microsoft has not yet patched Copilot; Google deprecated Gemini CLI rather than shipping a fix.

**Why it matters:** This is the first disclosed supply-chain vulnerability in the AI agent ecosystem. If you run Claude Code with third-party plugins, update to v2.1.179 immediately.

Sources: [Help Net Security](https://www.helpnetsecurity.com/2026/09/18/plugin4shell-ai-coding-agents-vulnerability/), [AIR blog](https://www.air.security/blog-posts/plugin4shell), [CyberSecurityNews](https://cybersecuritynews.com/plugin4shell-zero-click-rce/), [Eastern Herald](https://easternherald.com/2026/09/20/plugin4shell-ai-coding-agents-supply-chain-vulnerability/)

### [UPDATE] Claude Code v2.1.275 — MCP Reliability Fixes and Skills Sync

**Background:** v2.1.274 (Sept 17) added `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` to bound first-turn MCP connection wait.

**New:** v2.1.275 ships two MCP correctness fixes: Streamable HTTP MCP tool calls no longer time out after ~5 minutes when a longer per-server timeout is configured; MCP servers configured as `http` that speak legacy HTTP+SSE no longer fail to connect when they return 422 or other 4xx on the initial handshake. The sign-in-expiry error now explicitly says how to re-authenticate via `/mcp`. Separately, skills and plugins enabled on your claude.ai account now sync to signed-in terminal sessions (opt out with `syncClaudeAiSkills: false` / `syncClaudeAiPlugins: false`).

Sources: [Claude Code Changelog](https://www.gradually.ai/en/changelogs/claude-code/), [Releasebot Anthropic](https://releasebot.io/updates/anthropic/claude-code)

## Research & Technical

### [NEW] Medical AI Clinician Pushback: Deskilling and Governance Gaps

A 2026 Wolters Kluwer survey of 355 US physicians and nurses surfaces a gap between AI adoption rates and institutional readiness. Physicians' daily AI use tripled year over year, but formal governance awareness increased only from 21% to 27%. Top concerns: advertiser-driven bias (72%), deskilling (74%), and hallucinations (74%). Clinicians are pushing back specifically on AI's expansion beyond diagnostics and imaging — the argument is that broader clinical deployment lacks adequate performance evidence. Early-career professionals are flagged as most vulnerable to deskilling. About one-quarter of surveyed clinicians said they were not confident they could identify incorrect AI outputs.

**Why it matters:** As AI coding agents become default in developer workflows, the same deskilling concern applies — worth watching if the debate migrates from healthcare to software engineering.

Sources: [Healthcare Dive](https://www.healthcaredive.com/news/healthcare-ai-adoption-accelerates-provider-worries-deskilling-wolters-kluwer/821653/), [Frontiers in Medicine](https://www.frontiersin.org/journals/medicine/articles/10.3389/fmed.2026.1765692/full)
