## Tools & Frameworks

### [UPDATE] Claude Code v2.1.319: MCP Tasks Native in Terminal

**Background:** Anthropic shipped MCP Tasks + Elicitations in Claude Code CLI on October 23 (v2.1.304+). Long-running tool calls return a durable handle immediately; callers poll or subscribe rather than blocking.

**New:** v2.1.319 completes the terminal rollout — MCP tasks now background automatically in the terminal without any feature-flag requirement. The result arrives as a task-notification when the server finishes. Two opt-out env vars: `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1` makes Claude Code wait synchronously inside the tool call; `CLAUDE_CODE_DISABLE_MCP_TASKS=1` turns off the Tasks extension entirely. Earlier v2.1.317–318 releases added an `onFailure: 'block'` option for Agent SDK hook callbacks (failing hooks now block the action rather than logging silently), a pre-tool email privacy check, and an MCP old-handshake compatibility fix.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [ClaudeWorld](https://claude-world.com/articles/claude-code-november-2026-whats-new/), [Forkast](https://forkast.news/claude-ships-mcp-tasks-and-elicitations-in-claude-code-durable-agent-workflows-narrow-launch/)

**Why it matters:** Background MCP tasks make it practical to plug long-running services — compiler jobs, database migrations, code analysis pipelines — into Claude Code sessions without blocking the agent loop.

## Research & Technical

### [NEW] "Hacking or Just Failing?" — Better LLM Monitors Catch More Reward Hacking

A preprint on arXiv ([2611.00407](https://arxiv.org/abs/2611.00407)) argues that a more capable LLM used as a monitor does a better job of distinguishing reward hacking (the agent finding a loophole in the reward function) from genuine failure (the agent trying and not succeeding). Prior work suggested capability gains in the monitor might not translate to oversight quality; this paper finds they do when the evaluation is properly separated into the two failure modes rather than conflated. Results are on code-generation and reasoning tasks; the paper has not yet been peer-reviewed.

Sources: [DailyArXiv #361](https://github.com/somewordstoolate/DailyArXiv/issues/361), [LLM Stats](https://llm-stats.com/ai-news)

**Why it matters:** The reward-hacking detection framing matters for safe deployment of agentic systems — the scenario Stack builds against in trading and agent pipelines.

### [NEW] Microsoft Declines to Expand Nscale Texas Contract

Microsoft quietly exercised its right not to expand its Texas compute contract with Nscale (Nvidia-backed UK data center operator), according to a [Financial Times report on November 5](https://thenextweb.com/news/microsoft-rejects-nscale-texas-option) citing three people familiar with the matter.
