## Anthropic

### [UPDATE] Fable 5 Restored Globally; Mythos 5 Back for Approved US Orgs

**Background:** Fable 5 and Mythos 5 were pulled globally June 12 under a US Commerce Department export directive triggered by an Amazon-reported jailbreak. Mythos 5 was cleared for ~100 US critical-infrastructure orgs under Annex A by June 30. General consumer restoration was pending.

**New:** The Commerce Department formally lifted the export controls on June 30. Fable 5 went live globally on July 1 across Claude.ai, Claude Code, Claude Cowork, Amazon Bedrock, and GitHub Copilot. Mythos 5 is being restored separately to approved US organizations only.

Anthropic shipped two things alongside the restoration: (1) a new cybersecurity safety classifier that blocks the Amazon-reported jailbreak technique in over 99% of cases; and (2) a draft industry jailbreak scoring framework co-developed with Amazon, Microsoft, Google, and other Glasswing partners. The framework scores findings on four axes: capability gain (does the jailbreak exceed existing tools?), breadth of gain (how many offensive tasks does it unlock?), ease of weaponization (prompting effort required), and discoverability (how widely known is the technique?). This is significant — it's the first attempt at a standardized severity rubric for model jailbreaks analogous to CVSS for software CVEs.

For Pro, Max, and Team subscribers: Fable 5 is included in up to 50% of weekly usage limits through July 7 at no extra cost, then available via programmatic credits ($10/1M input, $50/1M output). Anthropic also committed to substantially scaling up joint work with government partners on AI security, including a compute allocation for government testing.

Sources: [Anthropic blog](https://www.anthropic.com/news/redeploying-fable-5), [NBC News](https://www.nbcnews.com/business/business-news/commerce-department-gives-green-light-anthropic-bring-back-fable-5-rcna352501), [The Hacker News](https://thehackernews.com/2026/07/anthropic-restores-claude-fable-5-after.html), [CoinDesk](https://www.coindesk.com/tech/2026/07/01/anthropic-restores-ai-models-fable-mythos-after-the-u-s-lifts-export-controls), [Al Jazeera](https://www.aljazeera.com/economy/2026/7/1/us-lifts-restrictions-on-powerful-ai-models-fable-mythos-anthropic-says)

**Why it matters:** Fable 5 is live in Claude Code today. With the 50% weekly limit bump (see below) also in effect, you're getting both the capability upgrade and more headroom — through July 7 on Fable 5 access and July 13 on limits. The jailbreak scoring framework is worth watching; if it gets adopted beyond Glasswing, it could influence how future capability restrictions get adjudicated.

### [UPDATE] Claude Code v2.1.197: Sonnet 5 Default, MCP Security Fix, +50% Weekly Limits

**Background:** Claude Code has been on an aggressive release cadence; Sonnet 4.6 was previously the default non-Fable model.

**New:** v2.1.197 sets Claude Sonnet 5 as the default model in Claude Code. Sonnet 5 brings a native 1M-token context window (vs 200K on Sonnet 4.6) and runs at promotional pricing of $2/$10 per Mtok through August 31 — cheaper than Opus 4.8 at $5/$25.

Notable changes in this release:
- **Org default models:** Admins set a default in the org console; it shows as "Org default" (or "Role default") in `/model` for users who haven't overridden it. Clean for teams standardizing on a model tier.
- **Readable session names:** Generated at start for easier identification in `claude agents` and `--resume`.
- **Clickable file attachments:** Cmd/Ctrl-click opens the file in Finder/Explorer.
- **MCP security fix:** `claude mcp list/get` no longer auto-spawns `.mcp.json` servers that a repo self-approved via a committed `.claude/settings.json`. Untrusted workspaces now show `⏸ Pending approval`. This closes a gap where opening a malicious repo could silently invoke untrusted MCP tools.
- **Weekly limits +50%:** Raised through July 13 at 6PM PDT across Pro, Max, Team, and seat-based Enterprise. Free plan excluded.
- **/code-review improvement:** Five cleanup finders merged into one, cutting token usage ~25%.

Sources: [Releasebot](https://releasebot.io/updates/anthropic/claude-code), [Claude Code changelog](https://code.claude.com/docs/en/changelog), [claudefa.st](https://claudefa.st/blog/guide/changelog)

**Why it matters:** The MCP security fix is directly relevant to your security concentration — repo-cloned `.mcp.json` self-approval was a real attack surface. The Sonnet 5 default with 1M context is a meaningful working-context upgrade; long codebases or multi-file sessions that previously required chunking can now fit in one window.

## Practical Tips

- **Fable 5 is live in Claude Code now.** Through July 7, it counts against only 50% of your weekly limit. Combined with the 50% limit increase through July 13, this is the highest effective ceiling since launch.
- **Sonnet 5 is the new default** — 1M context at $2/$10 promotional. If you're running agents or long sessions that previously hit context limits, update Claude Code and try without chunking.
- **MCP security change:** If you work in shared or open-source repos with committed `.claude/settings.json` MCP configs, your team's workspaces will now need explicit re-approval after updating to v2.1.197. Worth a heads-up if you run multi-dev environments.
- **The jailbreak scoring framework** (capability gain / breadth / ease of weaponization / discoverability) is publicly described — worth reading if you're building red-teaming tooling. It's the closest thing to a formal rubric the industry has produced.
