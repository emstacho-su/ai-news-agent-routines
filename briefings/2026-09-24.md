## Anthropic

### [NEW] Anthropic Threat Intelligence Report: Eight Months of Claude Misuse Disruptions

Anthropic published its most detailed threat report to date, covering disruptions between December 2025 and August 2026 across seven harm categories: cyber operations, influence operations, surveillance, scams and fraud, biological misuse, conventional weapons development, and distillation. Key cases: a suspected Russian espionage group whose Claude agents watched AV/EDR products for detections of its own malware, then automatically rebuilt the malware in a loop until detection stopped; five separate attempts by scientists to use Claude for potential bioweapons research (including a gain-of-function study destined for a military research institute), all blocked. The report notes that Haiku, Sonnet, and Opus models were involved in most cases — Fable and Mythos class models appear only in one illicit distillation case. [Anthropic](https://www.anthropic.com/threat-intelligence-report-september-2026) | [CellCog analysis](https://cellcog.ai/blog/anthropic-threat-report-september-2026/) | [AiCybr](https://aicybr.com/blog/anthropic-threat-intelligence-report-september-2026)

**Why it matters:** The malware-rebuild loop case is the clearest public example yet of agentic AI being used for autonomous attack iteration — directly relevant to Stack's security concentration work, and the kind of capability profile that informs defensive agent monitoring design.

### [UPDATE] Claude Gets Docs and Slides; Cowork, Chat, and Design Merge Into One App

**Background:** Claude Cowork was a separate agentic workspace product; Claude Design was a standalone canvas tool on the Labs track.

**New:** On September 16, Anthropic began merging Claude chat, Cowork, and Design into a single interface (rollout to Pro/Max first, then Team/Free/Enterprise on separate schedules) and added two new beta creation tools — Claude Docs (Word/Google Docs export) and Claude Slides (PowerPoint/PDF/Google Slides export). Claude now picks which tool to reach for autonomously mid-conversation: if you ask it to research a topic it may browse, write a document, and build a slide deck in one session. Claude Design now operates inside conversations rather than as a separate product.

Sources: [Engadget](https://www.engadget.com/2259938/anthropics-claude-can-now-create-editable-documents-for-you-cowork-chat-together/) | [TechWeez](https://techweez.com/2026/09/17/claude-docs-slides/) | [Coursiv](https://coursiv.io/blog/claude-docs-slides-design)

## Research & Technical

### [NEW] Flash-dLLM: IO-Aware KV Caching + Parallel Decoding for Diffusion LLMs

Paper submitted Sep 22 to ArXiv. Diffusion LLMs (dLLMs) have been gaining traction as an alternative to autoregressive decoding, but have suffered from memory-IO bottlenecks since they require full KV cache access on each diffusion step. Flash-dLLM introduces IO-aware KV caching (moves cache management to match diffusion step access patterns) and parallel decoding, with reported speedups over existing baselines. This is in the efficiency-for-deployment track, not a capability paper — useful if you're thinking about dLLM inference infrastructure. [ArXiv listing](https://arxiv.org/list/cs.LG/current)

### [NEW] Gated-Memory Routing for Multi-Agent LLM Collaboration (EMNLP 2026)

"Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems" was accepted at EMNLP 2026. The paper addresses the problem of what context each agent in a multi-agent system should carry forward vs. discard — framing it as a learned routing problem rather than a fixed summarization strategy. Relevant if you're working on multi-agent memory architecture (the Claude Agent SDK's subagent orchestration is exactly this problem domain). [ArXiv listing](https://arxiv.org/list/cs.AI/current)
