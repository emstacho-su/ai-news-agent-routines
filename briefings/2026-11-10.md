## Anthropic

### [NEW] Claude Fable 5.2 and Mythos 5.2: 30% faster, 20% cheaper, same 1M context

Anthropic released Claude Fable 5.2 and Claude Mythos 5.2 on November 9, 2026. Both share one underlying model: Fable 5.2 is the publicly available version with cybersecurity and biology safeguards active; Mythos 5.2 removes those restrictions and is limited to verified organizations through Anthropic's tiered access programs. API pricing drops to $8 per million input tokens and $40 per million output tokens, down from $10/$50 for Fable/Mythos 5.1. Output generation is reportedly up to 30% faster than 5.1 versions, and a **fast mode** delivering up to 2.5× token generation speed is available in Claude Code, Claude Platform, Google Cloud, and Microsoft Foundry. The models support 1M-token context windows and up to 128K output tokens. Fable 5.2 triggers ~55% fewer safety blocks than Fable 5.1 per Anthropic's internal benchmarks. Sources: [Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-2), [MacRumors](https://www.macrumors.com/2026/11/09/anthropic-launches-claude-fable-5-2/), [Digital Trends](https://www.digitaltrends.com/computing/claude-fable-5-2-and-mythos-5-2-are-here-to-raise-the-bar-for-ai-coding-and-scientific-research/), [DataCamp](https://www.datacamp.com/blog/claude-fable-5-2-and-mythos-5-2).

**Why it matters:** The price drop plus 2.5× fast mode in Claude Code significantly changes cost/latency math for agentic workloads — especially SWE tasks that are already heavy on Fable 5.1 tokens. Worth updating your cost benchmarks.

## Tools & Frameworks

### [UPDATE] Claude Code v2.1.317–319: MCP URL policies, denyInsteadOfPrompting, background Tasks GA

Building on the background MCP Tasks GA in v2.1.319 (covered Nov 8), three additional changes in this version range are worth noting:

- **MCP URL link cards (v2.1.317):** When an MCP server requests Claude open a URL in a cloud session, Claude Code now shows a link card the user can open or decline — instead of silently following the redirect. Closes a potential exfiltration vector via MCP-triggered URL loads. Source: [DEV Community](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-8-2026-485k).

- **URL-based MCP server deny rules (v2.1.318):** Admins can now add `deniedMcpServers` entries that match Anthropic-provided servers by upstream URL, blocking them via policy even if the server name changes. Combined with the existing allow-list model, this gives enterprise admins finer-grained MCP server governance. Source: [Claude Code Changelog](https://releasebot.io/updates/anthropic/claude-code).

- **`permissions.denyInsteadOfPrompting` (v2.1.319):** New policy flag that converts permission prompts to silent denials — useful in automated/CI contexts where interactive prompts would stall jobs. Source: [Claude Code Changelog](https://releasebot.io/updates/anthropic/claude-code).

**Why it matters:** The URL link card and URL-based deny rules are defensive posture improvements for anyone running Claude Code in team or enterprise settings with untrusted MCP servers. `denyInsteadOfPrompting` is directly useful for CI pipelines using Claude Code Routines.

## Practical Tips

**Fable 5.2 fast mode:** In Claude Code, `--fast` (or the new fast-mode toggle) enables up to 2.5× token generation. For agentic loops where you don't need extended reasoning, enabling fast mode on medium-effort tasks cuts wall-clock time significantly. The speed-quality tradeoff on hard SWE-bench-style tasks is not yet independently benchmarked — worth testing on your own workloads before committing.

**MCP denyInsteadOfPrompting in Routines:** If you're running Claude Code in a Routine where permission prompts would stall the job, add `"denyInsteadOfPrompting": true` under `permissions` in your project settings to convert interactive permission prompts to silent denials and keep the run flowing.
