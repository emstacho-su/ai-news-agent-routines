## Anthropic

### [NEW] Anthropic's provable-inference Phase 1 deadline arrives today — no delivery announced yet

Anthropic's [Frontier Safety Roadmap](https://anthropic.com/responsible-scaling-policy/roadmap) sets September 30, 2026 as the Phase 1 target for a provable-inference prototype — a technique for cryptographically signing model outputs so they are verifiably attributable to specific known model weights (detects unauthorized weight tampering and inference-time manipulation). The deadline was already pushed once from May 15 to Sept 30 after Anthropic reprioritized resources toward broader security hardening. As of this briefing, Anthropic has made no public announcement confirming delivery or a further slip. [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/anthropic-self-imposed-safety-deadline-103708422.html) flagged the deadline as a signal test: silence or another delay would suggest IPO roadshow preparation is crowding out the safety R&D commitments that differentiate Anthropic from its peers.

**Why it matters:** This is the most concrete near-term test of whether Anthropic maintains its safety-first posture under IPO pressure. Provable inference, if real, would be a significant technical moat — cryptographic auditability of model outputs is something no other frontier lab has shipped. Watch the Anthropic newsroom and RSP roadmap page this week for a delivery announcement, delay notice, or continued silence.

## Tools & Frameworks

### [UPDATE] OpenAI DevDay 2026: Dots, Codex Cloud, Agents API with MCP, Sign In with ChatGPT (20+ announcements)

OpenAI held DevDay at Fort Mason, San Francisco on September 29, delivering 20+ developer-focused announcements. Key items:

**Dots** — always-on persistent agents that live inside ChatGPT; they keep executing tasks after the chat session closes and Pro-tier Dots can have their own email inbox. Dots are the building block for **ChatGPT Space**, a shared team workspace where multiple Dots and humans collaborate, and **Pages**, a co-edited document layer designed for human–agent joint authorship.

**Codex Cloud** — Codex now runs entirely in the cloud, so users can start and monitor coding tasks from any device including a phone; the Codex CLI now accepts voice instructions.

**Agents API** — production-grade agentic infrastructure: OpenAI-hosted browser for computer use, native MCP server connections (connects agents to any MCP-compatible tool), parallel subagents, and durable session state across context resets. Developer mode in ChatGPT (beta) adds full MCP read/write access directly in the chat UI for external tool connections.

**Sign In with ChatGPT** — Plus and Pro subscribers can use their plan usage allowance across 16 partner tools including Notion, Vercel, and Cognition's Devin rather than paying for separate subscriptions.

Sources: [BGR](https://www.bgr.com/2272332/openai-devday-2026-announcements/), [Axios](https://www.axios.com/2026/09/29/openai-dev-day-2026-dots-space-sol), [CNBC live updates](https://www.cnbc.com/2026/09/29/openai-devday-2026-live-updates.html), [OpenAI recap](https://openai.com/index/devday-2026-recap/), [9to5Mac](https://9to5mac.com/2026/09/29/openai-teases-20-announcements-at-devday-watch-live/)

**Why it matters:** The Agents API's native MCP support and Codex Cloud push OpenAI into direct competition with Claude Code Routines territory. For Stack: building MCP servers that work across both Anthropic and OpenAI clients is now the practical path — the MCP 2.0 stateless core mandated by the Claude Plugin Directory portal should be directly compatible with ChatGPT's new MCP client.

## Wildcard

### [UPDATE] White House AI CEO summit outcome: voluntary self-policing pledge signed, Trump signs "Super Intelligence" EO

Following the September 29 summit attended by Amodei (Anthropic), Huang (NVIDIA), Zuckerberg (Meta), Karp (Palantir), Brockman (OpenAI), and Speaker Johnson, companies signed a voluntary self-policing agreement: internal safety controls, outside auditors, and internal boards to review auditor reports. Trump called the agreement "morally binding" and said he would appoint a dedicated AI oversight adviser. Separately, Trump signed an executive order directing all federal agencies to replace the term "AI" with "Super Intelligence (SI)" in official communications — framing rather than regulation, with no licensing requirements imposed on industry. [WNG](https://wng.org/podcasts/wednesday-morning-news-september-30-2026-1790702228), [Bloomberg Law](https://news.bloomberglaw.com/tech-and-telecom-law/openai-anthropic-google-to-join-white-house-ai-safety-meeting)

### [NEW] America.gov: Trump's AI front door to federal services, powered by Gemini and Grok — not Claude

Trump launched [America.gov](https://wng.org/podcasts/wednesday-morning-news-september-30-2026-1790702228), an AI-powered conversational portal giving citizens a single interface to navigate federal services. The system is powered by Gemini and Grok. The exclusion of Claude is notable and likely tracks with the ongoing Anthropic-Pentagon supply-chain-risk dispute and Fable 5 export restrictions that have complicated the Anthropic-federal government relationship.

## Practical Tips

- **Cross-provider MCP compatibility is now the default assumption.** OpenAI's Developer mode (beta) supports MCP read/write in ChatGPT; the Agents API adds MCP server connections for agents. If you're building `mcp-servers/resend/` or other MCP servers, testing against both Claude Code and a ChatGPT MCP client is worth adding to your QA plan. MCP 2.0 stateless core (required by Claude Plugin Directory) should be compatible.
- **Sign In with ChatGPT** is an interesting auth pattern for AI-native tools — OpenAI is building the infrastructure for plan-allowance pooling across partner apps. Worth watching how Vercel and Devin implement it before designing any external-tool auth for your own dashboard.
