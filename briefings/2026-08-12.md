## Anthropic

### [NEW] Compliance API Extended to Cowork and Claude Code

Anthropic extended its Compliance API to cover Claude Cowork (desktop app, web, mobile) and Claude Code (CLI and desktop app), in beta for Claude Enterprise customers. Security and compliance teams can now pull session content and metadata from both products through the same API interface — and the same Compliance Access Key — they already use for standard Claude chat. No new integration is required. Coverage for Cowork and Claude Code is included with existing Compliance API entitlement. [Claude blog](https://claude.com/blog/compliance-api-cowork-and-claude-code)

**Why it matters:** Claude Code's Cowork integration means agentic coding sessions and collaborative work sessions are now both audit-eligible under the same pipeline — directly relevant if your org (or a future employer) has data-loss-prevention or eDiscovery requirements. Combined with the self-hosted runner (v2.1.224, shipped last week), enterprise Claude Code now has the two things compliance teams need: compute inside the perimeter and logs pulled via a standard API.

## Model Releases

### [UPDATE] OpenAI Pauses Astra Development Over Critical Cybersecurity Risk

**Background:** OpenAI unveiled Astra on August 1 as its next-generation model class — multi-agent coordination architecture — and demonstrated it solving ten open mathematics problems (including one endorsed for Annals of Mathematics). Astra had never been given a release date.

**New:** On August 7, OpenAI announced that internal Preparedness Framework evaluation tests for Astra could not rule out "Critical" cybersecurity capabilities — specifically, the ability to autonomously discover and exploit zero-day flaws in hardened systems from reconnaissance through exploit delivery without human direction. OpenAI is now requiring expanded safety testing, isolated evaluation environments, and universal monitoring across agentic configurations before any release. The pause does not affect currently deployed products; GPT-5.6 Sol, Terra, and Luna remain available via API and ChatGPT. OpenAI did not provide a revised timeline. [TechJournal](https://techjournal.org/openai-pauses-astra-critical-cyber-risk), [True-Tech](https://true-tech.net/openai-astra-development-paused/)

**Why it matters:** Astra's architecture (agents that can coordinate for hours or days) combined with Critical-level cyber uplift is roughly the threat model Claude Mythos hit — and that resulted in US-government-gated release and an NSA director testifying before Congress. OpenAI voluntarily halting the rollout is the right move, but it also signals that frontier capability ceilings for autonomous cyber are now being hit repeatedly across multiple frontier labs.

### [UPDATE] Qwen3.8-Max Open Weights Still Pending; 27B Companion Also Planned

**Background:** Alibaba released Qwen3.8-Max on August 3 — a 2.4T-parameter MoE model (95B active), 1M context, claiming benchmark parity with Fable 5. Open weights under MIT were announced for "mid-August," pointing to the week of August 10.

**New:** As of August 12, neither the Qwen3.8-Max open weights nor the companion Qwen3.8-27B model have shipped. No updated date from Alibaba; community trackers show the release window still as "mid-August." The 27B companion — designed for consumer-GPU inference — was confirmed in a Medium post and is expected alongside the Max weights. [Neomanex](https://neomanex.com/news/qwen38-max-open-weights-countdown-aug-2026), [Developers Digest](https://www.developersdigest.tech/blog/qwen-3-8-max-release-2026)

## Wildcard

### [RUMOR] OpenAI "Doug": Largest Pre-Training Run, November 2026 Target

Multiple AI commentators and leakers reported on August 9-10 that OpenAI is running an internal pre-training job codenamed "Doug" — described as the largest base-model pre-training run OpenAI has ever attempted. Doug is not Astra (the next-generation model announced August 1) and is distinct from GPT-6, which would be codenamed Astra internally. The framing is that Astra serves as a validation step proving the pre-training fixes work, while Doug applies those fixes at full scale. Leakers place a target release window around November 2026. OpenAI has not confirmed the existence of Doug, the November timeline, or the scale claims. [KuCoin](https://www.kucoin.com/news/flash/openai-developing-doug-its-largest-pre-training-model-to-date), [BigGo Finance](https://finance.biggo.com/news/5ed990e1-8bd9-4c4b-a5a8-e4029b26a040)

OpenAI's prior pre-training runs hit scaling bottlenecks that required the "Garlic" intermediate job to validate fixes; Doug reportedly reflects that validation succeeded and full-scale training has restarted.
