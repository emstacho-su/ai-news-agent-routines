## Tools & Frameworks

### [UPDATE] MCP 2026-07-28 RC: Tasks API rebuilt and JSON Schema 2020-12 now in scope

**Background:** The MCP 2026-07-28 RC has been tracked since May 21 (when the RC locked). Core changes — stateless protocol, session elimination, `Mcp-Method`/`Mcp-Name` routing headers — were covered June 26.

**New:** Two additional breaking changes now have solid technical documentation worth flagging before the July 28 deadline:

1. **Tasks API restructure.** `tasks/list` is removed (there's no server-side scope for "whose tasks?" once sessions are gone). The new lifecycle: server answers `tools/call` with a task handle; client drives via `tasks/get`, `tasks/update`, `tasks/cancel`. Existing servers that return task IDs in response bodies need to update to this handle model.

2. **JSON Schema 2020-12 for tool schemas.** `oneOf`, `anyOf`, `allOf`, conditionals, and `$ref` are now formally supported in tool input schemas. Servers that relied on the earlier flat-schema constraint can now compose complex input types correctly. Error code `-32002` (resource-not-found) moves to the standard `-32602` (invalid params) per the spec cleanup.

The Tier 1 SDK 10-week window from the May 21 RC lock runs out July 28. If you maintain or depend on an MCP server, the migration checklist at [DEV Community](https://dev.to/akaranjkar08/mcp-spec-ships-july-28-every-breaking-change-and-how-to-migrate-4co8) and the Azure/App Service scaling guide at [Microsoft Tech Community](https://techcommunity.microsoft.com/blog/appsonazureblog/mcp-just-went-stateless-%E2%80%94-what-the-2026-spec-changes-about-scaling-on-app-servic/4530222) are worth reading now. Sources: [MCP official RC post](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [ChatForest breaking changes guide](https://chatforest.com/builders-log/mcp-spec-2026-07-28-release-candidate-stateless-breaking-changes-builder-guide/), [thefalcon.dev server-author walkthrough](https://www.thefalcon.dev/writing/mcp-2026-stateless-spec-what-breaks).

**Why it matters:** If you build or consume any MCP server in this repo's routines stack, both the Tasks handle pattern and JSON Schema 2020-12 tooling are actionable now — not after July 28.

## Wildcard

### [NEW] arXiv becomes an independent nonprofit after 25 years at Cornell

arXiv formally separated from Cornell University on July 1, 2026, becoming a standalone nonprofit after operating under Cornell since 1991. The driver is AI submission volume: the server now processes more AI/ML papers than any other category and implemented a 10-12% rejection rate for suspected AI-generated content in early 2026, alongside a one-year submission ban for unchecked AI-generated papers (announced February 2026) and an English-language requirement. Cornell and arXiv leadership both cited the funding model needing to match the organization's global scale and independence. [TechTimes](https://www.techtimes.com/articles/319527/20260702/arxiv-leaves-cornell-after-25-years-ai-paper-flood-tests-its-free-access-future.htm)

**Why it matters:** arXiv is the primary distribution channel for AI research — its policies on AI-generated content and its independence from Cornell affect how research reaches practitioners. The rejection rate and submission ban are the first infrastructure-level responses to the AI paper flood.
