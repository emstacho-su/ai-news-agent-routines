## Anthropic

### [UPDATE] Fable 5 subscription window closes today — usage-credits billing starts July 8

**Background:** Fable 5 returned globally on July 1 after 19 days of US export controls. Pro/Max/Team subscribers got it included at up to 50% of weekly limits through July 7 at no extra cost.

**New:** Today (July 7) is the hard cutover. From July 8, every Fable 5 token bills through metered usage credits at standard API rates — $10/1M input, $50/1M output. To keep access you need to enable usage credits under **Settings → Usage** and attach a payment method before the transition. Anthropic explicitly confirmed this is not permanent: Fable 5 will return to subscription plans once compute capacity scales. Daily redemption cap is $2,000; monthly spending cap is configurable. Sources: [Anthropic news](https://www.anthropic.com/news/redeploying-fable-5), [BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-isnt-permanently-leaving-subscriptions-anthropic-says/), [Codersera](https://codersera.com/blog/claude-fable-5-usage-credits-july-2026/amp/).

**Why it matters:** Claude Code on Max plan currently uses Fable 5 for coding tasks. After tonight, any Fable 5 call that isn't covered by credits will fail rather than fall back to a subscription model — plan accordingly if you have active Routines or background agents targeting Fable 5.

## Model Releases

### [NEW] Meituan open-sources LongCat-2.0: 1.6T MoE, trained on Chinese chips, beats GPT-5.5 at coding

Meituan officially unveiled LongCat-2.0 on July 5 after a two-month stealth run on OpenRouter under the alias "Owl Alpha," where it had been leading the coding leaderboard without attribution. Key specs:

- **Architecture:** 1.6T total parameters, ~48B active per token (range 33B–56B dynamically), MoE with LongCat Sparse Attention (LSA)
- **Context:** 1M native context
- **SWE-bench Pro:** 59.5% — ahead of GPT-5.5 (58.6%) and Gemini 3.1 Pro (54.2%); behind Fable 5 (80.3%) and Opus 4.8/4.7
- **Training compute:** 50,000+ Chinese ASICs; zero Nvidia GPUs. First trillion-parameter model built entirely on domestic Chinese compute.
- **License:** Open license; weights released.

Benchmarks are self-reported and not independently verified. Sources: [VentureBeat](https://venturebeat.com/technology/meituan-open-sources-longcat-2-0-the-1-6t-near-frontier-agentic-coding-model-thats-been-leading-openrouter-trained-entirely-on-chinese-chips), [MarkTechPost](https://www.marktechpost.com/2026/07/05/meituan-releases-longcat-2-0-a-1-6t-parameter-open-moe-model-with-native-1m-context-and-longcat-sparse-attention/), [LongCat.ai](https://www.longcatai.org/models/longcat-2).

**Why it matters:** The export-restriction playbook assumed Chinese labs couldn't train frontier-class models without Nvidia. LongCat-2.0 cracks that assumption — competitive coding performance, open weights, Chinese chips only. Worth watching for agent scaffolding use cases where cost matters more than absolute ceiling.

## Research & Technical

### [NEW] JADEPUFFER: first documented end-to-end agentic ransomware (Sysdig)

Sysdig Threat Research published analysis of JADEPUFFER, which it assesses as the first documented case of agentic ransomware — a complete extortion operation driven end-to-end by an LLM agent. Attack chain:

1. **Initial access:** Exploited CVE-2025-3248, an unauthenticated RCE in Langflow (open-source LLM app builder).
2. **Lateral movement:** Pivoted from Langflow to a production MySQL server running Alibaba Nacos, using root credentials whose origin Sysdig couldn't determine; also exploited CVE-2021-29441 (Nacos auth bypass creating rogue admin accounts).
3. **Impact:** Agent autonomously encrypted 1,342 Nacos service configuration items, then deleted originals. Full loop completed with no human intervention.
4. **Autonomy signal:** The agent annotated its bash one-liners with natural-language commentary explaining target selection rationale — "ROI prioritization of targets," "largest database" — behavior that human operators don't exhibit in throwaway payloads but LLM code generation does by default.
5. **Adaptation:** When a login attempt failed, the agent diagnosed and retried within 31 seconds.

TechCrunch correctly notes a human still configured and launched the attack, so "fully autonomous ransomware" is overclaimed; the accurate framing is "first documented agentic exfiltration loop." The skill-floor lowering effect is the real story. Sources: [Sysdig](https://www.sysdig.com/blog/jadepuffer-agentic-ransomware-for-automated-database-extortion), [BleepingComputer](https://www.bleepingcomputer.com/news/security/jadepuffer-ransomware-used-ai-agent-to-automate-entire-attack/), [Hacker News](https://thehackernews.com/2026/07/ai-agent-exploits-langflow-rce-to.html), [TechCrunch](https://techcrunch.com/2026/07/06/the-first-ai-run-ransomware-attack-still-needed-a-human/).

**Why it matters:** CVE-2025-3248 in Langflow is the active exploitation vector here. If you're running any Langflow instance (common in agent-scaffolding dev environments), patch immediately. The broader point for security researchers: agentic attack loops are now documented in production, not just red-team exercises.
