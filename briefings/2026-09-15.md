## Anthropic

### [UPDATE] Claude Code v2.1.271 (Sept 14): fast mode for remote sessions, per-command domain allowlisting, VS Code auto-archiving

**Background:** v2.1.269-270 (Sept 11-12) added the plugin evaluation framework and fixed long-session git permission prompts.

**New (Sept 14):**
- **Fast mode in remote sessions** — the host's fast-mode setting or `/fast` typed in a cloud/self-hosted runner session now applies, subject to org policy. Previously fast mode was CLI-only.
- **Mouse support in `/config` fullscreen panel** — wheel scroll, click to change values, row highlighting. Removes the keyboard-only constraint in that panel.
- **Per-command `allowed_domains` for Bash, PowerShell, Monitor in auto mode** — fine-grained network allowlisting per tool call when sandboxing is active. Tighter than the session-wide list.
- **`omitClaudeMd` in agent frontmatter / `--agents` JSON** — run custom or plugin subagents without loading user/project/local CLAUDE.md files; useful for hermetic agent definitions.
- **`claude self-hosted-runner --drain-marker-file <path>`** — write a file when the runner enters drain state; enables graceful shutdown signaling to orchestration layers.
- **VS Code: auto-archive inactive sessions** — new "Archive inactive sessions" setting, default 14 days; fixes sidebar chat going blank after Reload Window for conversations open >10 min.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)

**Why it matters:** Per-command `allowed_domains` is the right primitive for multi-step agents that call internal APIs from Bash — avoids blanket allowlisting at session scope. The VS Code auto-archive fix matters if you keep long-lived sessions in the IDE sidebar.

### [UPDATE] AEF-1 standard formalized: Anthropic, OpenAI, xAI cosign embedded-evaluator specification

**Background:** Dario Amodei's "We Must Pace the Frontier" essay (Sept 12) called for embedded independent evaluators with employee-level access; Altman and Musk publicly agreed; METR was named as Anthropic's first embedded evaluator. The standards body talks with Google were ongoing.

**New:** The three labs have now cosigned AEF-1 (AI Evaluator Framework 1), a concrete spec defining:
- What "employee-like access" means operationally (system access, training pipeline visibility, incident reporting rights)
- How third-party evaluators are credentialed and rotated
- Reporting obligations when evaluators flag an alignment concern

xAI's participation is the key expansion — the pledges last week were Anthropic + OpenAI; AEF-1 adds Musk's lab. Google/DeepMind is not a cosignatory but Hassabis tied endorsement to the broader standards body formation.

## Tools & Frameworks

### [NEW] GitHub Agentic Workflows public preview: Markdown-defined agents inside GitHub Actions

GitHub Agentic Workflows (in public preview since June 11, 2026) lets you define repository automation agents in plain Markdown files under `.github/workflows/`. The `gh aw` CLI converts them into standard GitHub Actions workflows that run via GitHub Copilot CLI or other coding agents. Key design choices:

- **Safe-output model** — agents use a pre-approved move vocabulary (`assign_to_agent`, `add_comment`, `noop`, etc.) for write operations; arbitrary shell execution is not a default
- **Read-only default** — workflows run read-only unless the `aw.json` project config explicitly grants write capabilities
- **Practical agent types in production**: Issue Monster (triage-by-appetite), Dead Code Removal Agent (static analysis → PR), CI failure analysis, Linear/Jira sync

**September v0.88.4 update:**
- DIFC policy generation: automatically derives data-flow integrity/confidentiality policies for workflows authenticated via GitHub App
- Agentic firewall hardening and sandbox tightening
- `aw.json` project support for adding workflows to existing repos without YAML migration

Sources: [GitHub Changelog (public preview)](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/), [GitHub Agentic Workflows blog](https://github.github.com/gh-aw/blog/2026-09-07-weekly-update/), [Developer Tech](https://www.developer-tech.com/news/github-agentic-workflows-github-actions/)

**Why it matters:** The safe-output + read-only-default model is a reasonable first-order mitigation for agentic scope creep in CI. DIFC policy generation is novel — auto-deriving a data-flow policy from authentication context rather than hand-writing it.

### [NEW] OpenClaw 2.0 (v2026.8.1): collaborative sessions, simplified setup, rebuilt browser UI

OpenClaw is the leading open-source personal AI agent; 2.0 shipped August 31, 2026 from 933 contributors across 16K PRs. Key changes:

- **Auto-detection of existing AI access** — installer detects active ChatGPT/Claude CLI sign-ins, API keys, Ollama/LM Studio routes; no manual configuration for common setups
- **Rebuilt browser interface** — conversation-first entry point; task monitoring, workflow interaction, and agent config all from the same UI
- **Collaborative cloud sessions** — shared sessions via Gateway; authorized collaborators can join or take over running tasks using shared state without receiving provider credentials directly

## Wildcard

### [NEW] Abliteration.ai: commercial service strips safety guardrails from open-weight models

A startup called Abliteration.ai (launched early September 2026) sells access to open-weight models with built-in safety mechanisms deliberately removed via activation-pattern suppression. Current offering is a modified GLM-5.3 (Z.AI) stripped of refusal training, including bio-related guardrails.

The company markets it as a tool for offensive cybersecurity work and red-teaming. TechCrunch testing reportedly found it straightforward to elicit malware-writing instructions without the stated "security researchers only" framing providing meaningful friction.

The technical approach (find internal activations that trigger refusals, tweak weights to suppress them) is documented in the academic literature and has been applied to open-weight models manually before; Abliteration.ai is notable for making this a turnkey commercial service.
