## Anthropic

### [UPDATE] Claude Code v2.1.225–226: gateway spend limits enforced, auth fixes

**Background:** v2.1.224 (Aug 6-8) shipped self-hosted environments in public beta for Team/Enterprise.

**New:** v2.1.225 (Aug 7) adds gateway spend-limit support — when a session hits an org-configured cap, the model names the specific limit and its reset time rather than surfacing a generic error. Also fixes a critical authentication regression introduced in the previous release. v2.1.226 (Aug 8) is a stability-only release with 15 bug fixes including MCP OAuth retry improvements on macOS.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)

**Why it matters:** The spend-limit message is directly relevant — if you're running Routines under a Team/Enterprise gateway, your sessions now fail with actionable context instead of opaque quota errors.

### [NEW] Alibaba Qwen3.8-Max: 2.4T MoE, 95B active, 1M context, open-weight coming

Alibaba released Qwen3.8-Max on August 3. Architecture: 2.4T total parameters, 95B active via Sparse MoE, 1M-token context. Claims benchmark scores comparable to Anthropic Fable 5 and ranks 5th in Text Arena, 2nd in Vision Arena. API live on Alibaba Cloud Model Studio now; open-weight release (MIT) scheduled for mid-August — the first Max-class Qwen model to be open-sourced. The model can ingest hundred-page documents, full TV series, or 100-hour livestreams into searchable knowledge bases.

Sources: [MarkTechPost](https://www.marktechpost.com/2026/08/03/alibaba-qwen-releases-qwen3-8-max/), [CNBC](https://www.cnbc.com/2026/08/03/alibaba-ai-model-qwen-rival-anthropic.html), [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-03/alibaba-drops-another-china-ai-model-with-breakthrough-performance)

## Research & Technical

### [NEW] Google WeatherNext 2: AI cyclone forecasting open-sourced (Apache 2.0), Nature paper

Google DeepMind published WeatherNext 2, WeatherNext 2-mini, and WeatherNext Cyclones under Apache 2.0 on August 6-7, alongside a Nature paper. Co-developed with the US National Hurricane Center, CIRA, and UK Met Office. The headline result: on cyclones from 2023–2025, WeatherNext's 3-day track/intensity/wind-structure forecast matches what prior operational systems delivered at 2 days — roughly +24 hours of lead time. In a documented case (Hurricane Melissa), WeatherNext Cyclones gave the NHC a full extra day of warning.

WeatherNext 2-mini runs on a single TPU in a free Colab notebook. Weights and code at GitHub under Apache 2.0.

Sources: [Dataconomy](https://dataconomy.com/2026/08/07/weathernext-ai-model-hurricane-forecasts/), [Unite.AI](https://www.unite.ai/googles-weathernext-2-gains-a-full-day-of-cyclone-warning-goes-open-source/), [TechTimes](https://www.techtimes.com/articles/323617/20260808/weathernext-publishes-proof-cyclone-ai-gave-nhc-extra-day-warning-hurricane-melissa.htm)

**Why it matters:** This is a reproducible real-world result (NHC case study, open weights) rather than benchmark theater. Practically useful for anyone working on geospatial ML or multi-modal temporal forecasting — the dataset and training approach are now available.
