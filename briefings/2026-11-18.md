## Tools & Frameworks

### [NEW] Claude Code 2.1.326: Code Mode for agent teams, extended MCP reconnect

Claude Code 2.1.326, first seen Nov 17 on Releasebot, adds two noteworthy changes. Code Mode (experimental: Claude writes JavaScript tool calls instead of natural-language commands) can now be enabled while agent teams are active, with sandbox protections applied in that combined mode. The Claude Agent SDK also extends background reconnect windows for remote HTTPS MCP servers from ~27 minutes to roughly one day, reducing session disruptions in long-running agentic workflows. Breaking change in this SDK window: hook options must now be arrays.

Sources: [Releasebot Claude Code](https://releasebot.io/updates/anthropic/claude-code), [Developer Digest](https://www.developersdigest.tech/blog/claude-agent-sdk-whats-new-2026).

**Why it matters:** The MCP reconnect extension directly affects routines that keep a remote MCP server alive across a long job — a session-hour gap no longer kills the connection. The hook-options-must-be-arrays change is a silent break if you're running older SDK code.

## Wildcard

### [NEW] US BIS closes AI chip overseas data-center loophole

The US Commerce Department's Bureau of Industry and Security issued an interim final rule (effective ~Nov 15–16) closing a gap in existing AI chip export controls: physically avoiding chip shipment restrictions by remotely accessing AI compute hosted in third countries. The rule applies the same export controls to remote-access arrangements at overseas data centers above a 12 million aggregate total processing performance (TPP) threshold. Companies in Singapore, Thailand, Malaysia, Indonesia, and Brazil that supply large-scale AI compute must now obtain US export licenses. Existing arrangements have a 90-day compliance window; exporters must also run know-your-customer checks on direct and indirect ownership chains. Commerce cited its 2018 Export Control Reform Act authority to issue without prior notice-and-comment.

Sources: [WUNC](https://www.wunc.org/2026-11-16/u-s-tightens-controls-on-remote-access-to-ai-technology-amid-nvidia-fallout), [SCMP](https://www.scmp.com/tech/article/3374639/us-tightens-ai-chip-export-curbs-close-chinas-overseas-data-centre-loophole), [BTW Media](https://btw.media/en/us-closes-nvidia-ai-chip-overseas-loophole), [CyberScoop](https://cyberscoop.com/commerce-ai-chip-export-restrictions/).
