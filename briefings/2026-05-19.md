## Tools & Frameworks

### [UPDATE] Claude Code v2.1.144 — 52 changes; URL plugin loading, session-scoped /model, bg session resume

Key additions in what appears to be the largest single-version drop since v2.1.141:

- **`--plugin-url` flag** — fetches a plugin archive from a URL for the current session; useful for testing a plugin before adding it to the marketplace, or shipping internal plugins from an artifact store without committing them to the workspace.
- **`/model` session-scoped** — `/model` now changes the model for the current session only; press `d` in the model picker to set a default for new sessions. Previous behavior set a global default from the picker.
- **`/resume` for background sessions** — sessions started via `claude --bg` or agent view now appear alongside interactive sessions in the TUI, labeled `bg`, with elapsed duration surfaced in completion notifications.
- **Edit tool exact-string replacement** — the Edit tool now performs exact string replacements to prevent unintended partial matches; behavior change may affect existing hooks or scripts that relied on looser matching.
- **System search via Grep** — internal system searches now use the grep tool for consistent, file-based results and more reproducible behavior.
- **Cross-project Ctrl+R** — reverse-search now defaults to all prompts across every project; `Ctrl+S` narrows back to current project/session.

Known issue: Binary crashes immediately when spawned from VS Code (any mode) while working fine from Terminal.app; tracked at [issue #60436](https://github.com/anthropics/claude-code/issues/60436).
