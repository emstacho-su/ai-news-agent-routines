### [UPDATE] Claude Code v2.1.185 — auto-mode safety expands to IaC and git amend
**Background:** v2.1.183 blocked destructive git commands (`reset --hard`, `checkout -- .`, `clean -f`) when the user hadn't asked to discard work.

**New (v2.1.185, June 20):**
- `terraform destroy`, `pulumi destroy`, `cdk destroy` blocked in auto mode unless you explicitly named the stack to destroy
- `git commit --amend` blocked when the commit being amended was not made by the agent in the current session
- `git stash drop` added to the blocked-without-ask list
- Model deprecation warnings added at session start when running a deprecated model string
- New `/config help` subcommand for in-session settings exploration

Sources: [Releasebot](https://releasebot.io/updates/anthropic/claude-code), [code.claude.com changelog](https://code.claude.com/docs/en/changelog), [claudefa.st](https://claudefa.st/blog/guide/changelog)

**Why it matters:** The IaC destroy guardrail is the critical one — an auto-mode agent running `cdk deploy` followed by cleanup logic can no longer accidentally call `cdk destroy` on the wrong stack. Directly relevant for any CI/CD pipeline using Claude Code.

### [UPDATE] MCP 2026-07-28 RC — stateless core, routing headers, deprecations finalized
**Background:** MCP roadmap's major 2026 milestone: stateless Streamable HTTP core, GA target July 28.

**New details now documented:** The RC (locked May 21) removes the `initialize`/`initialized` handshake and `Mcp-Session-Id` header entirely. Protocol version, client info, and capabilities now travel inline in a `_meta` field on every request — servers are fully stateless and horizontally scalable. New required routing headers:
- `Mcp-Method`: the MCP operation name
- `Mcp-Name`: the tool/resource/prompt name being invoked

Gateways can now route, rate-limit, and log by specific MCP operation without parsing JSON bodies.

Three features formally deprecated (to be removed in a future spec):
- **Roots** → replace with tool parameters or server config
- **Sampling** → call the LLM provider API directly (do not use `sampling/createMessage`)
- **Logging** → use stderr or OpenTelemetry

Extensions advancing alongside: **MCP Apps** (server-rendered UI) and **Tasks** (long-running async work with status polling). GA remains July 28; SDK Tier 1 maintainers are expected to ship RC support within the 10-week window from May 21.

Sources: [MCP blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [mcp.directory](https://mcp.directory/blog/mcp-2026-07-28-release-candidate), [byteiota](https://byteiota.com/mcp-stateless-2026-release-candidate/)

**Why it matters:** If you have any MCP server in production, two things to do now: (1) strip all session state, (2) rewrite any `sampling/createMessage` calls to use the provider SDK directly. Both are breaking changes on GA day.

## Practical Tips
- **Claude Code + IaC in CI:** v2.1.185's `terraform/pulumi/cdk destroy` block is opt-in safety in auto mode, not bypass-proof. If you have a legitimate cleanup pipeline that calls `cdk destroy`, add an explicit destroy intent to the prompt before the auto-mode agent runs — "destroy the `test-env` stack."
- **MCP server migration:** The July 28 deadline is 37 days out. Drop `Mcp-Session-Id` tracking now, add `Mcp-Method`/`Mcp-Name` headers, and convert any `sampling/createMessage` calls to direct Anthropic SDK calls. Catch these before GA locks the spec.
- **OpenCode + local models:** For agentic tasks where you want to conserve programmatic API credits (e.g., file reads, trivial refactors), OpenCode's Ollama support lets you route low-stakes steps to a local model while keeping Claude on complex reasoning. The LSP integration makes this practical for typed languages.
