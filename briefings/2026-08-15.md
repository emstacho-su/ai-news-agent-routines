## Anthropic

### [NEW] Anthropic in talks to acquire Decart for ~$6 billion

Bloomberg and Reuters (Aug 13) reported that Anthropic is in early discussions to acquire Decart, an Israeli AI infrastructure startup, for approximately $6 billion — which would be by far Anthropic's largest acquisition. Decart builds software that reduces the cost of training and running AI models by optimizing chip utilization; if the deal closes, Decart's team would join Anthropic's inference and performance group. The timing aligns with surging Claude adoption straining existing compute. Talks remain at an early stage and could collapse.

Sources: [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-13/anthropic-said-in-talks-to-buy-ai-startup-decart-for-6-billion), [Fortune](https://fortune.com/2026/08/13/anthropic-said-in-talks-to-buy-startup-startup-decart-for-6-billion), [PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/anthropic-pursues-6-billion-decart-deal-to-cut-ai-costs/)

**Why it matters:** Decart's inference optimization work would directly compound the Volta 10B compute deal and Theseus Infrastructure build-out — fixing the efficiency layer, not just adding raw capacity.

## Model Releases

### [UPDATE] Qwen3.8-27B open weights ship under Apache 2.0

**Background:** Qwen3.8-Max (2.4T total params, 95B active via Sparse MoE) launched Aug 3; open-weight release of the companion 27B dense model was pending with no confirmed date as of Aug 12.

**New:** Weights landed on Hugging Face Aug 13-14 and the official release dropped at midnight Aug 15, under Apache 2.0. Qwen3.8-27B is a 27B causal model distilled from Qwen3.8-Max, with 262K native context, integrated vision, customizable reasoning depth, and enhanced agentic capabilities. Alibaba claims it beats Muse Glimmer 30B on several benchmarks. Runnable on high-end consumer GPUs and Ryzen AI Max-equipped PCs — the local-deployment angle is the key pitch.

Sources: [Cryptobriefing](https://cryptobriefing.com/alibaba-qwen3-27b-open-weights-release/), [OfficeChai](https://officechai.com/miscellaneous/alibaba-releases-qwen-3-8-27b-beats-muse-glimmer-30b-on-many-benchmarks/), [BigGo Finance](https://finance.biggo.com/news/b3b5cb0c-d942-401f-ba61-2923b0c81857)

## Research & Technical

### [NEW] Google HEIR: run AI inference on fully homomorphic encrypted inputs

Google released HEIR (Homomorphic Encryption Intermediate Representation) as an open-source compiler toolchain built on the MLIR framework. HEIR converts pretrained models — including StableHLO-compatible ML models — to run inference on homomorphically encrypted inputs, so the server processing the query never sees the underlying plaintext data. It supports all mainstream FHE techniques, integrates with major software libraries and hardware accelerators, and is designed as a research and benchmarking platform, not just a production tool. ArXiv paper: [2508.11095](https://arxiv.org/abs/2508.11095).

Sources: [arXiv 2508.11095](https://arxiv.org/abs/2508.11095), [GitHub google/heir](https://github.com/google/heir), [Google Developers Blog](https://developers.googleblog.com/expanding-our-fully-homomorphic-encryption-offering/)

**Why it matters:** FHE inference has been theoretically appealing for privacy-sensitive workloads (healthcare, legal, finance) but impractical due to compile complexity. HEIR is a serious infrastructure push to change that — worth watching for MCP server or API gateway use cases where query privacy matters.

## Wildcard

### [NEW] Google "Let Google Call" — consumer AI agents make autonomous phone calls

Google is rolling out consumer agents that autonomously call stores, check inventory, book appointments, confirm prices, and complete purchases by phone on users' behalf. When a user searches for a product or service "near me," a "Let Google Call" option appears; the agent calls the retailer, collects what it needs, and reports back via email or text. Initial verticals: home repair, beauty, and pet care. Rollout is staged by region; still running within Google's summer 2026 window.

Sources: [TechBuzz](https://www.techbuzz.ai/articles/google-launches-ai-agents-to-shop-call-stores-for-you), [AI Agent News](https://assindo.com/news/ai-agent-news-august-2026), [Nerd Level Tech](https://nerdleveltech.com/ai-agents-calling-businesses-voice-handoff)

**Why it matters:** This is the first at-scale deployment of autonomous voice agents completing real-world commercial transactions for mainstream consumers — a meaningful shift from assistants that recommend to assistants that execute.
