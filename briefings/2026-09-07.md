## Model Releases

### [UPDATE] Meta Muse Spark 1.3 — Efficiency Gains, Video Input, Reaches Frontier
**Background:** Muse Spark 1.2 (Aug 5) was a coding-focused retrain, DeepSWE 59.3%; Muse Code terminal agent launched alongside it. Both targeted Claude Code / Codex CLI directly.
**New (Sept 2):**
- Muse Spark 1.3 released to API for developers; Max Reasoning tier announced, pending additional safety testing.
- Needs roughly 20% fewer tool calls and 25% fewer tokens than 1.2 to complete comparable engineering tasks — meaningful for long multi-step agentic runs where token burn compounds.
- Adds video input (in addition to text and image from 1.2); context window remains 1M.
- Ranks #6 of 636 on Artificial Analysis Intelligence Index — the highest Meta model has ever charted. Fourth Muse Spark release in five months.
- Pricing unchanged: $1.25/Mtok input, $4.25/Mtok output (competitive with Fable 5.1 tier-for-tier on coding tasks at roughly 1/8 the cost).
- Rolling out to Instagram, Facebook, and Meta AI apps.

Sources: [Bloomberg](https://www.bloomberg.com/news/articles/2026-09-02/meta-releases-more-powerful-ai-model-edging-closer-to-rivals), [Axios](https://www.axios.com/2026/09/02/meta-debuts-muse-spark-13-as-personal-agent-work-continues), [Artificial Analysis](https://artificialanalysis.ai/articles/muse-spark-1-3), [Meta AI Research](https://research.meta.ai/blog/introducing-muse-spark-1-3)

### [UPDATE] Qwen3.8-Max-0902 — Code Arena First Place, Doubles TerminalBench
**Background:** Qwen3.8-Max launched Aug 3 as the first open-weight Max-class model (2.4T MoE, 95B active, 1M context); Qwen3.8-27B dense open weights shipped Aug 15.
**New (Sept 2–3):**
- Alibaba pushed the 0902 post-training snapshot with no architecture changes and no price change ($2/Mtok input, $6/Mtok output).
- Jumps to #1 in Code Arena WebDev: 1,691 pts — 3 pts above Claude Opus 5 Max (1,687) and 22 above the prior Qwen3.8-Max (1,669). All 8 tracked coding benchmarks improved.
- Largest gains on TerminalBench 3.0 (11.3 → 29.0) and ProgramBench Almost Solved (10.5 → 28.0), both more than doubling — suggesting the post-training targeted long-horizon terminal/agentic tasks specifically.
- Still lags Opus 5 Max on broader benchmarks per CellCog analysis; the lead is narrow and coding-domain-specific.

**Why it matters:** A $2/Mtok model edging out $15/Mtok Opus 5 Max on WebDev leaderboards is the headline, but benchmark leaderboard rankings reverse regularly. Worth running your actual workload before switching.
Sources: [TechNode](https://technode.com/2026/09/02/alibaba-upgrades-qwen38-max-with-new-0902-snapshot/), [OpenRouter](https://openrouter.ai/qwen/qwen3.8-max-0902), [CellCog](https://cellcog.ai/blog/qwen3-8-max-0902/), [DataCamp](https://www.datacamp.com/blog/qwen3-8-max)
