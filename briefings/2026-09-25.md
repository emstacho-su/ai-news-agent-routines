## Anthropic

### [NEW] Claude Discovers Novel CRISPR-Like Enzyme System (ART) in Bacteriophages

Anthropic's Life Sciences research group — formed spring 2026 to test whether general-purpose AI can systematize biological discovery — published its first result September 24. Claude ran **949 parallel agent sessions over 21.5 hours**, scanning a database of roughly 1.9 billion protein clusters, and autonomously flagged a previously undescribed enzyme system in bacteriophage DNA. Anthropic calls it **array-associated reverse transcriptases (ART)**: a three-component system consisting of a reverse transcriptase enzyme, a partner gene, and a long array of evenly spaced DNA repeat sequences whose layout resembles a CRISPR array. All wet-lab validation is performed by human scientists; Anthropic says the function of ART is still undetermined and is inviting external research proposals. [Anthropic](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system), [The Next Web](https://thenextweb.com/news/anthropic-claude-enzyme-system-crispr-like-repeats), [Quartz](https://qz.com/anthropic-claude-crispr-like-enzyme-system-bacteriophage-092426).

**Why it matters:** 949 coordinated agent sessions on a single biological discovery task is the clearest large-scale demo yet of Claude doing real research-adjacent work, not just answering questions about research. The Life Sciences Verification Program (LSVP, beta since Sept 17) is the access gate if you want to replicate or build on this — credentials + institutional oversight required.

### [UPDATE] Opus 5.5 Ships "Preserved Thinking" Anti-Distillation Safeguard

Since the Sept 22 launch, Anthropic has confirmed that Claude Opus 5.5 includes **preserved thinking** — an anti-distillation safeguard that prevents API users from modifying the prior assistant context in an attempt to replay or extract Claude's extended reasoning. The restriction is enforced server-side. Standard tool-use loops are unaffected; this specifically targets context-injection patterns used to exfiltrate thinking traces. [9to5Mac](https://9to5mac.com/2026/09/22/anthropic-upgrades-claude-with-new-opus-5-5-model-details-here/), [BNN Bloomberg](https://www.bnnbloomberg.ca/business/artificial-intelligence/2026/09/22/anthropic-unveils-claude-opus-55/).

**Why it matters:** If you're using `betas=["thinking"]` with extended reasoning, you can still read and log thinking output normally — preserved thinking blocks *editing* the prior turn to inject synthetic reasoning, not reading it. Check your agent loop if you're doing any context replay or COT compression patterns.

## Tools & Frameworks

### [UPDATE] Claude Code Projects: Broader Access Rolling Out

The Sept 17 beta launched Claude Code Projects to select Pro/Max cloud users with a "broader access coming within a week" note. That window has now closed and access is expanding to more Claude Code subscribers. Recap of the feature: you describe a goal; Claude scopes the work, routes it to **parallel cloud sessions each on its own branch and repository clone**, each session can run tests and open PRs, and sessions keep running after you close your laptop. Heavy parallelism draws on your plan's usage limits. Team/Enterprise rollout still to follow. [MarkTechPost](https://www.marktechpost.com/2026/09/17/anthropic-launches-claude-code-projects-in-beta-parallel-cloud-sessions-that-keep-running-after-you-close-your-laptop/), [Times of AI](https://www.timesofai.com/news/anthropic-claude-code-projects-multi-agent/).

### [NEW] Amazon Opens Seller Central to Outside AI Agents, Launches with Claude

Amazon announced September 23 at Amazon Accelerate that Seller Assistant now ships a **Selling Partner plugin** that gives outside AI agents — starting with Anthropic's Claude (via Amazon Bedrock) and Amazon Quick — live read/write access to a seller's inventory, pricing, listings, and analytics without opening Seller Central directly. The plugin includes persistent memory of pricing patterns and inventory cycles that follows the seller across Seller Central, Quick, and Claude. All seller data stays within Amazon's infrastructure. US beta only; international to follow. [GeekWire](https://www.geekwire.com/2026/amazon-opens-its-seller-tools-to-outside-ai-agents-starting-with-anthropics-claude/), [Unite.AI](https://www.unite.ai/amazon-brings-seller-assistant-to-claude-and-amazon-quick/), [API Evangelist](https://apievangelist.com/2026/09/24/amazon-opened-seller-central-to-agents-and-kept-the-storefront-closed/).

## Practical Tips

**Using Opus 5.5 in v1-routines or any agent loop:** Cache reads are 60% cheaper ($0.20/M vs $0.50/M on Opus 5) — this is the biggest immediate cost lever for routines with long system prompts. Prefix caching on a 10K-token system prompt that fires daily drops from ~$5/day to ~$2/day in cache-read cost alone. Worth benchmarking before locking in model string.
