## Anthropic

### [UPDATE] Anthropic publishes frontier lab transparency metrics paper

**Background:** Anthropic has previously disclosed that Claude leads ~26% of internal R&D work with ~30,000 agents active at any one time.

**New:** On September 17, Anthropic published a formal methodology paper at [anthropic.com/institute/measuring-pace-of-ai-development](https://www.anthropic.com/institute/measuring-pace-of-ai-development) proposing three public metrics for tracking AI development pace inside frontier labs:

1. **R&D Automation Index (AL0–AL5):** A scale applied to every class of R&D task at Anthropic, from AL0 (no AI) to AL5 (fully autonomous). As of August 2026, over 90% of tasks are at or above the level where AI collaborates with humans.
2. **Agent Oversight Metrics:** Three sub-metrics — *coverage* (share of agent actions passing through a monitor), *review latency* (time from action to review), and *escalation rate* (share blocked/flagged). Published alongside the ~30,000-agent internal platform stat.
3. **Safety Compute Allocation:** First public snapshot (July 13–20 window): 6% of total compute toward safety, 12% toward safety-focused AI-driven R&D.

Anthropic is releasing the methodology so other labs can publish comparable numbers. Sources: [SiliconANGLE](https://siliconangle.com/2026/09/17/anthropic-details-practical-metrics-to-help-monitor-the-speed-of-ai-development/), [CNBC](https://www.cnbc.com/2026/09/17/anthropic-shares-3-metrics-to-help-ai-companies-monitor-development.html).

**Why it matters:** Ties directly to Dario Amodei's "pace the frontier" essay. If other labs publish the same metrics, it becomes possible to compare safety-compute ratios and automation rates across the industry — a concrete precursor to any future slowdown agreement.

## Tools & Frameworks

### [NEW] Claude Code Projects redesigned for parallel cloud sessions (beta, Sept 17)

Anthropic shipped a redesigned Projects experience for Claude Code on September 17, open in beta to select Pro and Max cloud users, with broader access expected within a week.

The new architecture has a **coordinator session** that receives a high-level goal, breaks it into parallel worker threads, and assembles the final result. Each worker is a full Claude Code cloud session running **Opus by default at high effort**, on its own branch and repo copy. Workers can run tests and open pull requests; the coordinator tracks progress, reviews outputs, and stitches them together.

The project also maintains **shared memory and a common file library** across threads, so context from one worker is visible to others. Each thread draws on the subscriber's plan, so heavily parallelized projects will hit usage limits faster than single sessions.

Sources: [Unite.AI](https://www.unite.ai/anthropic-redesigns-claude-code-projects-to-coordinate-agent-threads/), [XenoSpectrum](https://xenospectrum.com/en/claude-code-projects-redesign/), [MLQ.ai](https://mlq.ai/news/anthropic-opens-parallel-claude-code-projects-beta-to-select-pro-and-max-users/).

**Why it matters:** This is the first first-party parallel-agent UX inside Claude Code with managed branching. Worth testing on a non-trivial repo to see how well the coordinator handles merging divergent worker branches.

## Model Releases

### [UPDATE] OpenAI to retire GPT-5.5 from ChatGPT and Codex on October 14

**Background:** GPT-5.5 Instant has been ChatGPT's default model since May 2026.

**New:** OpenAI announced GPT-5.5 will retire from ChatGPT, ChatGPT Work, and Codex (all tiers: consumer, Business, Enterprise, Edu) on October 14, 2026. The **OpenAI API is unaffected** — anything authenticated with an API key keeps working. Replacement model is GPT-5.6 Sol. Codex users signed in via ChatGPT should update workspace defaults, custom agents, and scheduled tasks before the cutoff. Sources: [Gizmochina](https://www.gizmochina.com/2026/09/16/openai-retiring-gpt-5-5-on-october-14-you-may-need-to-update-your-workflow/), [Let's Data Science](https://letsdatascience.com/news/openai-retires-gpt-55-from-chatgpt-and-codex-1a6f69be).

## Practical tips

- **Claude Code Projects beta:** If you're on Pro or Max with cloud sessions, check for the new Projects interface. Running parallel branches on a feature-sized PR is the right first test — keep coordinator context under ~50k tokens to avoid runaway costs.
- **GPT-5.5 sunset:** October 14 only hits ChatGPT/Codex. If you're on the API with an API key, nothing breaks. Check any ChatGPT-backed scheduled tasks or custom agents.
- **Anthropic transparency metrics:** The [methodology page](https://www.anthropic.com/institute/measuring-pace-of-ai-development) has full definitions for AL0–AL5 and the three agent-oversight sub-metrics — useful framing for reporting on your own agents' oversight posture.
