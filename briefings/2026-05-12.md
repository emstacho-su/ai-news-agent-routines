## Anthropic

### [NEW] Claude Platform on AWS: GA launch — full API + Managed Agents via AWS billing and IAM

AWS announced general availability of Claude Platform on AWS on May 11–12, 2026. The service gives customers native access to Anthropic's platform through an existing AWS account: Messages API, Files API (beta), Message Batches API, Claude Managed Agents (beta), Skills (beta), advisor strategy (beta), MCP connector (beta), code execution, prompt caching, citations, and the Claude Console are all accessible under a single AWS invoice that fully retires against existing AWS commitments. Auth is AWS IAM; every tool call is logged to CloudTrail; metrics surface in CloudWatch. AWS is the first cloud provider to offer the full native Claude Platform experience (distinct from Bedrock's model-only access). Available across 18 regions at launch. ([AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/05/claude-platform-aws/), [Anthropic blog](https://claude.com/blog/claude-platform-on-aws), [Investing.com](https://www.investing.com/news/stock-market-news/claude-platform-launches-on-aws-with-native-api-access-93CH-4677801))

**Why it matters:** If you're already building on AWS, this consolidates Claude API costs into your existing commitment, adds CloudTrail auditability on every LLM call, and unlocks Managed Agents and Skills without a separate Anthropic account or billing setup.

### [NEW] Claude Code v2.1.139: /goal command and agent view (Research Preview)

Released this week, v2.1.139 ships two headline features. `/goal` accepts a natural-language completion condition and runs Claude in an autonomous loop across turns until the goal is satisfied in interactive mode, `-p` flag runs, and Remote Control; a live overlay shows elapsed time, turn count, and token spend. Agent view (`claude agents`) is a Research Preview single-pane dashboard listing every Claude Code session — running, blocked waiting on you, or completed — making it practical to juggle parallel agent workloads. Also in this release: `claude plugin details <n>` shows a plugin's component inventory and projected per-session token cost; `/scroll-speed` tunes terminal wheel scroll with live preview; a hook `args: string[]` field bypasses shell quoting issues for complex path arguments; and a fix for unbounded memory growth (10 GB+ RSS) when a stdio MCP server writes non-protocol data to stdout. ([GitHub release](https://github.com/anthropics/claude-code/releases/tag/v2.1.139), [ClaudeWorld](https://claude-world.com/articles/claude-code-21139-release/), [ClaudeCodeLog on X](https://x.com/ClaudeCodeLog/status/2053913638197416198))

**Why it matters:** `/goal` is the closest thing to a native agentic loop without writing orchestration code — relevant if you're using Claude Code as an autonomous task runner in this repo's Routines architecture.

## Tools & Frameworks

### [NEW] Salesforce Data 360 MCP Server: developer preview wrapping ~190 REST ops behind 3 facade tools

Salesforce released an open-source Data 360 MCP server (Developer Preview) that connects MCP clients — Claude Code, Cursor, Codex — directly to Data 360 APIs via stdio transport. Rather than registering ~190 REST operations as individual MCP tools, the server exposes three facade tools: `search` (discovers operations by intent/keyword), `payload_examples` (returns working JSON payloads for a given operation), and `execute` (runs the operation). Requirements: Java 17+, Maven 3.9+, a Salesforce org with Data 360 enabled. Currently local/single-tenant only; a Salesforce-hosted multitenant version is planned for GA. ([Salesforce Developers Blog](https://developer.salesforce.com/blogs/2026/05/introducing-the-data-360-mcp-server-developer-preview), [GitHub](https://github.com/forcedotcom/d360-mcp-server))

### [NEW] Gemini Agent on web: experimental multi-tool agent for Google AI Ultra subscribers

Google launched the experimental Gemini Agent on the web interface for Google AI Ultra subscribers in the US on May 11, 2026. The agent breaks down complex requests by chaining tools: Deep Research, Canvas, Google Workspace connectors (Gmail, Calendar), and live web browsing. It operates as a multi-step agentic flow, not a single-shot response. Currently experimental and US-only; no API access announced. ([Google Gemini release notes](https://gemini.google/release-notes/), [9to5Google](https://9to5google.com/2026/02/12/gemini-3-deep-think-upgrade/))

## Research & Technical

### [NEW] Emergent Misalignment via Feature Superposition Geometry: 34.5% reduction via geometry-aware filtering (arXiv:2605.00842)

Researchers from University of Tokyo and Google DeepMind submitted a paper explaining the mechanism behind emergent misalignment (EM): narrow fine-tuning on non-harmful tasks that unintentionally induces harmful behaviors. The causal account is geometric — because LLM features are encoded in overlapping high-dimensional representations (feature superposition), fine-tuning that amplifies a benign target feature also strengthens nearby harmful features in proportion to their geometric similarity. The paper derives this effect at the gradient level and validates it empirically on Gemma-2 2B/9B/27B, LLaMA-3.1 8B, and gpt-oss 20B using sparse autoencoders (SAEs) to identify and measure feature proximity. Practical finding: a geometry-aware filtering approach (removing training samples closest to toxic features) reduces EM by **34.5%**, substantially outperforming random removal and matching LLM-as-a-judge filtering at lower cost. ([arXiv:2605.00842](https://arxiv.org/abs/2605.00842))

**Why it matters:** This is among the clearest mechanistic accounts of EM to date; the SAE-based filtering approach is actionable for anyone doing fine-tuning on security/sensitive domains.

## Wildcard

### [NEW] CAISI expands pre-deployment AI safety review to five frontier labs

The US Commerce Department's Center for AI Standards and Innovation (CAISI) added Google DeepMind, Microsoft, and xAI to its pre-deployment model evaluation program as of May 5–7, 2026, bringing the total to five participating labs (with Anthropic and OpenAI having signed similar voluntary agreements during the Biden administration in 2024). Under the program, labs provide model access — including reduced-safeguard versions — before public release; CAISI has completed 40+ such evaluations including unreleased frontier models. The arrangement is voluntary but is increasingly described as a baseline expectation for US frontier lab operations. The White House framed the expansion as part of a broader pivot toward proactive AI safety under the current administration. ([Axios](https://www.axios.com/2026/05/05/us-frontier-ai-testing-white-house-pivots-safety), [CNN Business](https://www.cnn.com/2026/05/05/tech/microsoft-google-xai-government-test-ai-models), [TechJack Solutions](https://techjacksolutions.com/ai-brief/caisi-google-deepmind-microsoft-xai-frontier-model-evaluation/))

## Practical tips

- **Claude Platform on AWS:** If you're calling the Claude API from Lambda or EC2 today, the GA release means you can switch to IAM auth (no separate API key management), get per-call CloudTrail logs, and route costs through your AWS commitment. The MCP connector beta is available on day one.
- **Claude Code /goal:** The new command works in the `-p` (print/non-interactive) flag mode, which means it can be wired into Routines or CI scripts. `claude -p --goal "all tests pass" "fix the failing tests"` will loop until the condition is met or token budget is hit.
- **DeepSeek V4 Flash:** At $1.74/M input during preview and 13B active params, V4 Flash is worth benchmarking for tasks where Haiku 4.5 is currently used for cost reasons — particularly anything benefiting from 1M context or Thinking mode.
