### [UPDATE] Project Glasswing: expanded to 150+ orgs, 10,000+ critical flaws found

### [NEW] A2A Protocol v1.0 GA — cross-platform agent interoperability

The Agent-to-Agent (A2A) Protocol reached v1.0 GA with a 7-vendor steering committee: AWS, Google, IBM, Microsoft, Salesforce, SAP, and ServiceNow. Built on an IETF draft co-developed with Google, A2A lets agents from different providers expose callable endpoints for cross-framework tool discovery. Wire-compatible with Copilot Studio and Microsoft Agent Framework 1.0 out of the box. 150+ organizations adopted it in the first year. The protocol routes agent-to-agent calls through MCP tool surfaces, meaning MCP-native agents pick it up with minimal additional wiring. A2A entered public preview in Copilot Studio in May 2026 and reached GA at Build 2026.

Sources: [Microsoft devblog](https://devblogs.microsoft.com/agent-framework/a2a-v1-is-here-cross-platform-agent-communication-in-microsoft-agent-framework-for-net/), [Azure blog](https://azure.microsoft.com/en-us/blog/agent-factory-connecting-agents-apps-and-data-with-new-open-standards-like-mcp-and-a2a/), [Linux Foundation](https://www.linuxfoundation.org/press/a2a-protocol-surpasses-150-organizations-lands-in-major-cloud-platforms-and-sees-enterprise-production-use-in-first-year)

**Why it matters:** If you're building multi-vendor agent pipelines — e.g., a Claude Code agent orchestrating a Salesforce agent or an SAP workflow — A2A is now the protocol to target rather than rolling custom inter-agent transports.

### [NEW] FastMCP 3.4.0 — stdio-to-remote transport bridge

FastMCP 3.4.0 ("The remote release") shipped June 2. Key addition: a standalone Python bridge connecting stdio-only MCP hosts to remote HTTP/SSE servers. Enables gateway patterns where a CLI tool that only speaks stdio (like Claude Code) can reach any HTTP-hosted MCP server without a custom shim. Auto-OAuth for HTTPS; supports bearer tokens and custom headers; proxies arbitrary MCP servers transparently regardless of transport type.

Sources: [gofastmcp.com](https://gofastmcp.com/updates), [GitHub](https://github.com/PrefectHQ/fastmcp/releases)

**Why it matters:** Directly relevant for any MCP server you're hosting remotely that Claude Code's stdio transport can't reach natively — the bridge is now a one-liner install instead of a DIY WebSocket proxy.

## Model Releases

### [NEW] MiniMax M3: open-weight, 1M context, $0.60/$2.40 per M tokens

Released June 1, 2026. MiniMax M3 uses a new Mixture-of-Sequential-Attention (MSA) architecture that claims 9× faster prefill and 15× faster decoding at 1M context vs. prior generation. Benchmarks: 59.0% SWE-bench Pro (ahead of GPT-5.5 Instant and Gemini 3.1 Pro per MiniMax's own runs). Pricing: $0.60/M input, $2.40/M output — roughly 5–10× cheaper than frontier models at equivalent context. Native image and video understanding included. Open weights + technical report releasing on HuggingFace within ~10 days of launch. Note: benchmark runs use MiniMax's own agent scaffolding; independent community verification pending.

Sources: [VentureBeat](https://venturebeat.com/technology/minimax-m3-debuts-eclipsing-gpt-5-5-and-gemini-3-1-pro-on-key-benchmark-performance-for-just-5-10-of-the-cost), [MarkTechPost](https://www.marktechpost.com/2026/06/01/minimax-releases-minimax-m3-with-msa-architecture-supporting-1m-token-context-native-multimodality-and-agentic-coding/)

### [NEW] NVIDIA Cosmos 3: open omnimodal foundation model for physical AI

NVIDIA launched Cosmos 3 on May 31/June 1 — the first fully open omnimodal foundation model targeting physical AI applications (robotics, autonomous vehicles, warehouse monitoring). Two open-weight checkpoints: Cosmos3-Nano (16B total / 8B dense) and Cosmos3-Super (64B total / 32B dense). Accepts text, image, video, audio, and action sequences in a single prompt via Mixture-of-Transformers architecture. Distinct from text/code LLMs — the target inference loop is sense-plan-act for embodied systems. Weights on GitHub/Hugging Face.

Sources: [NVIDIA Newsroom](https://nvidianews.nvidia.com/news/nvidia-launches-cosmos-3-the-open-frontier-foundation-model-for-physical-ai)

## Research & Technical

### [NEW] Sysdig: first autonomous LLM-agent intrusion confirmed in the wild

Sysdig Threat Research documented the first confirmed live cyberattack driven by an autonomous LLM agent, observed in May 2026. Attack chain: Marimo notebook RCE (CVE-2026-39987) → credential extraction → AWS Secrets Manager pivots → SSH bastion access → PostgreSQL database exfiltration. Four environment pivots completed with zero human intervention in under one hour. The LLM agent spread 12 redundant API calls across 11 Cloudflare edge locations for infrastructure evasion. Full database exfiltration on the bastion phase completed in under 2 minutes.

Sources: [Sysdig](https://webflow.sysdig.com/blog/ai-agent-at-the-wheel-how-an-attacker-used-llms-to-move-from-a-cve-to-an-internal-database-in-4-pivots), [The Hacker News](https://thehackernews.com/2026/05/ai-agent-cyberattack-llm-sysdig.html)

**Why it matters:** Post-exploit LLM agents compress attacker dwell time from hours or days to minutes. The Cloudflare edge-distribution for evasion also shows the agent reasoning about detection, not just execution. For Stack's security concentration: this is the real-world baseline that agentic red-team tooling (RAMPART, etc.) now needs to be benchmarked against.

## Wildcard

### [UPDATE] Trump AI EO signed June 2 — 30-day voluntary model review

**Background:** A 90-day pre-release model-sharing EO was canceled in late May 2026 after Musk, Zuckerberg, and Sacks each called Trump directly to oppose it. The scrapped version would have required labs to submit models up to 90 days before release.

**New:** A revised EO was signed on June 2. Key changes: review period cut to 30 days (from 90); participation is explicitly voluntary; mandatory licensing or preclearance requirements are barred. The new EO focuses on cybersecurity benchmarks and vulnerability sharing rather than broad model access. Distinct from the CAISI framework (which is a narrower national security eval program at NIST already involving five labs).

Sources: [NPR](https://www.npr.org/2026/06/02/nx-s1-5844347/ai-safety-trump-executive-order), [CNBC](https://www.cnbc.com/2026/06/02/trump-executive-order-ai.html), [NBC News](https://www.nbcnews.com/tech/tech-news/trump-ai-executive-order-rcna348072)
