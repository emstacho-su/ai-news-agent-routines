## Tools & Frameworks

### [UPDATE] Claude Code — July 3 changelog: Manual is now the default, AskUserQuestion changes behavior

Claude Code shipped a July 3 release that includes two behavior changes with practical impact for scripted or unattended use:

1. **"Manual" replaces "default" as the permission mode name.** The mode that previously appeared as `default` in the CLI, `--help`, VS Code, and JetBrains is now labeled `Manual`. Both `--permission-mode manual` and `"defaultMode": "manual"` are accepted alongside the old strings, so existing configs continue to work — but any script or CI that parses permission mode output by name will see the new string.

2. **AskUserQuestion dialogs no longer auto-continue.** Previously the dialog would auto-advance after an idle timeout. That behavior is now opt-in: set an idle timeout explicitly via `/config` if you want auto-continuation back. Any background or headless agent that depended on the dialog timing out silently will now block indefinitely without a configured timeout.

Additional fixes in the same release: SSL/TLS certificate errors (TLS-inspecting proxies, missing `NODE_EXTRA_CA_CERTS`, expired certs) now fail fast with an actionable fix hint instead of burning all retries first. tmux 3.4+ rendering flicker fixed via synchronized terminal output. Claude Sonnet 5 sessions no longer incorrectly use the mid-conversation system role for harness reminders. `/mcp server list` now tracks focus correctly for screen readers and magnifiers.

Sources: [Claude Code changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)

**Why it matters:** If you run Claude Code in CI, background agents, or any unattended context, audit your permission-mode config strings and verify that any flow hitting AskUserQuestion has an explicit timeout configured — the silent auto-advance is gone.

## Model Releases

### [NEW] Grok 4.5 enters private beta at SpaceX and Tesla

xAI's Grok 4.5 is in private testing at SpaceX and Tesla as of June 28, 2026. The model is built on xAI's 1.5-trillion-parameter V9 foundation model — roughly three times the size of the v8-small model handling current Grok production traffic — with supplemental training added from Cursor IDE coding data.

Elon Musk announced the beta on X and claimed Grok 4.5's performance is "close to, or better than" Claude Opus. xAI has published no benchmarks, evaluation methodology, or system card to support that claim. No GA timeline has been announced; xAI is using SpaceX and Tesla as internal test environments before broader commercial release. Musk separately stated xAI plans to release new models "trained completely from scratch" at SpaceX every month for the rest of 2026.

Sources: [CyberNews](https://cybernews.com/ai-news/musk-grok-4-5-private-beta-superior-claude-opus/), [Times of AI](https://www.timesofai.com/news/xai-launches-grok-4-5-private-beta/), [ExplainX](https://www.explainx.ai/blog/grok-4-5-private-beta-spacex-tesla-cursor-v9-2026)

**Why it matters:** Cursor coding data in supplemental training is an interesting data-flywheel play — same data that trained Sonnet 5's default in Claude Code. Treat performance claims from Musk's X posts as marketing until benchmarks drop.

**Background:** Meta's Avocado model was delayed past its May 2026 target. It shipped as "Muse Spark" in April 2026 with benchmarks below GPT-5.5.

Context: OpenAI reportedly debuted a stronger GPT-5.6 late last month (available only to government-approved partners), so Watermelon is effectively racing a moving target.

## Wildcard

### [NEW] OpenAI proposes giving US government a 5% equity stake (~$42.6B)

OpenAI CEO Sam Altman proposed, in preliminary discussions with Trump administration officials, that the US government receive a 5% equity stake in OpenAI — and that the same arrangement apply to all leading US AI labs, potentially including Anthropic, Google, and Meta. The vehicle would be an Alaska-style sovereign wealth fund that would distribute investment returns broadly.

At OpenAI's current ~$852B private valuation, a 5% stake is worth roughly $42.6B. The discussions reportedly included Commerce Secretary Howard Lutnick and Treasury Secretary Scott Bessent. The proposal is in early stages, would require Congressional approval, and there's no indication Anthropic, Google, or Meta have agreed to participate. A 5% government stake across frontier AI labs would create complex governance entanglements — and if structured as Altman described, it would require those companies to accept the same constraint.

Sources: [TechCrunch](https://techcrunch.com/2026/07/02/openai-proposed-donating-5-of-its-equity-to-a-us-sovereign-wealth-fund/), [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-02/openai-proposes-giving-the-us-government-a-5-stake-ft-says), [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/openai-floats-5-percent-government-stake-days-after-washington-delayed-gpt-5-6), [MLQ](https://mlq.ai/news/openai-proposes-5-us-government-stake-worth-426-billion-to-ease-washington-pressure/)

**Why it matters:** The framing is important — this is regulatory arbitrage dressed as a public good. OpenAI wants Washington to see itself as a financial stakeholder, which changes the political incentive structure around regulation. Watch whether it accelerates GPT-5.6 general availability.

### [NEW] UN AI for Good Global Commission launched with CEO-level members

The UN and the International Telecommunication Union (ITU) launched the AI for Good Global Commission on July 1, 2026. This is the first UN-level AI governance body to formally include the CEOs and presidents of leading AI companies as members. Salesforce CEO Marc Benioff and Rwandan President Paul Kagame serve as co-chairs.

This is separate from the UN Global AI Governance Dialogue that opens in Geneva on July 6, which is an intergovernmental forum. The AI for Good Commission is a standing body, not a one-time dialogue.

Sources: [UN News](https://news.un.org/en/story/2026/07/1167848), [AI News](https://www.artificialintelligence-news.com/)

### [NEW] Meta Brain2Qwerty v2: non-invasive BCI reaches 61% word accuracy

Meta released Brain2Qwerty v2, a non-invasive brain-computer interface that converts brain activity to text using magnetoencephalography (MEG) sensors combined with a large language model. The system achieves 61% average word accuracy without any surgical implant. The prior version required more constrained input or had lower accuracy; v2 is specifically designed to handle naturalistic, continuous brain activity. ## Practical tips

- **Claude Code permission audits due.** If you use Claude Code in any CI, background agent, or automated context: (1) check that your config uses `"defaultMode": "manual"` (same as before — the string alias is new, not the mode itself); (2) verify any flows that could hit AskUserQuestion have an explicit idle timeout configured via `/config`, or they will block indefinitely.

- **Grok 4.5 coding claims:** xAI's Cursor data play is worth watching when benchmarks drop. Cursor has a large, high-signal professional coding dataset. If the model follows through, it's a genuine signal rather than just a larger parameter count.
