## Tools & Frameworks

### [NEW] Claude Code Limits Drop 17% on September 14

On August 29, Anthropic announced that starting September 14, the standard weekly usage limits rise permanently by 25% for Pro, Max, Team, and seat-based Enterprise plans. The catch: the current "summer 50% boost" promo is what gets pulled. Indexed against an original base of 100, today's allowance is 150; after September 14 it becomes 125 — a 16.7% cut from what you have now. If you are running heavy Claude Code workloads, the effective window to bank on current capacity ends September 13. Sources: [Digital Applied](https://www.digitalapplied.com/blog/claude-code-weekly-limit-reduction-september-14), [Ground News](https://ground.news/article/claude-code-limits-change-entropic-reduces-user-usage-cap-by-17), [Explainx.ai](https://www.explainx.ai/blog/anthropic-claude-code-limits-17-percent-cut-september-2026-august-2026).

**Why it matters:** Direct impact on Max-plan Claude Code usage. If you're running multi-agent workflows or routines that consume significant weekly quota, adjust scheduling before September 14.

### [UPDATE] OpenAI Ships WebMCP Site Tools in ChatGPT's Browser

OpenAI added WebMCP Site Tools to ChatGPT's desktop browser in August 2026. WebMCP is an open standard where websites publish named, callable functions — instead of an agent scraping HTML and guessing button targets, the site explicitly advertises its own API surface. ChatGPT Work and Codex auto-discover those tools when visiting a WebMCP-enabled site. Millions of Shopify storefronts are already enabled; Expedia, Instacart, and Target are piloting. OpenAI ran a 10-day WebMCP Challenge with $3K prizes and industry backing from Shopify, Cloudflare, Vercel, and others. Sources: [Search Engine Journal](https://www.searchenginejournal.com/chatgpt-adds-webmcp-support/587237/), [VKTR](https://www.vktr.com/ai-platforms/openai-adds-webmcp-to-chatgpts-browser/).

**Why it matters:** WebMCP is the agent-browsing equivalent of MCP for local tools. If adoption follows Shopify's lead, agent tasks that currently rely on Playwright/Puppeteer DOM scraping could route to structured WebMCP calls instead — faster, less fragile, and token-cheaper.

## Wildcard

### [UPDATE] DoD Expands GenAI.mil With ChatGPT Mil + Grok — Anthropic Deadline Month

On August 31, the Pentagon added OpenAI's ChatGPT Mil and xAI Starshield's Grok for Government to the GenAI.mil platform alongside Google Gemini, giving all ~3 million DoD personnel access to three competing frontier models. Timing is notable: the 180-day deadline for DoD contractors to phase Claude out of DoD workflows expires this month (September 2026) — the result of the March 2026 supply-chain-risk designation. A federal court injunction blocked enforcement of that designation on First Amendment grounds, but the multi-vendor AI buildout continues regardless. Sources: [Air Force Times](https://www.airforcetimes.com/industry/techwatch/2026/08/31/the-militarys-chatgpt-is-now-live-via-the-pentagons-genai-platform/), [Aroged](https://www.aroged.com/2026/09/01/pentagon-receives-its-own-versions-of-chatgpt-and-grok/).
