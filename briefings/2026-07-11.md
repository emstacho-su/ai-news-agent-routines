## Anthropic

### [UPDATE] Claude Code gets a built-in sandboxed browser
Claude Code desktop (macOS/Windows) shipped a built-in browser in v2.1.202+, highlighted in Anthropic notes and covered by [9to5Mac](https://9to5mac.com/2026/07/10/anthropic-highlights-claude-codes-in-app-browser-on-the-desktop/) on July 10. Keyboard shortcut: **Cmd+Shift+B** (macOS) / **Ctrl+Shift+B** (Windows). Claude can navigate to docs or designs, click through pages, and interact with them the same way it already handles `localhost` dev server previews. The browser runs in an isolated profile (no saved history or logins) and supports OAuth pop-ups including Google sign-in. External links pasted in the chat can open in the browser pane or default browser. Each new domain requires a one-time Allow/Deny prompt.

**Why it matters:** Eliminates the copy-paste loop between browser and IDE — Claude can open a library's changelog, read it, and continue coding without switching windows. Also enables testing authenticated flows without exposing your real browser session.

Sources: [9to5Mac](https://9to5mac.com/2026/07/10/anthropic-highlights-claude-codes-in-app-browser-on-the-desktop/), [Digital Trends](https://www.digitaltrends.com/cool-tech/claude-code-can-now-browse-the-web-without-opening-chrome/), [Claude Code Docs](https://code.claude.com/docs/en/whats-new)

### [NEW] Claude Reflection Dashboard (beta)
Anthropic launched a usage reflection feature in beta, visible at **Settings → Reflect** on web and Claude Desktop. For users with Memory on (Free, Pro, Max), a monthly recap surfaces: topics you spent time on, most active day and peak hour, and qualitative observations about how you work with Claude. A companion **Settings → Time and focus** page lets you set optional break reminders and quiet hours. Sources: [TestingCatalog](https://www.testingcatalog.com/anthropic-adds-usage-reflection-dashboard-to-claude-for-all-users/), [Releasebot Anthropic](https://releasebot.io/updates/anthropic)

**Why it matters:** Minor UX feature, but the quiet hours + break reminders are genuinely useful for not having Claude Code background sessions fire at 2am when you don't want them to.

### [NEW] API key expiration controls in the Console
Anthropic added optional expiration dates when creating API keys or Admin API keys in the [Claude Console](https://console.anthropic.com). Choose a preset duration, a custom duration, or Never. For keys with a lifetime ≥ 7 days, Anthropic emails the creator before expiry. Existing keys are unaffected. The Admin API now exposes an `expires_at` field. Sources: [Anthropic Release Notes](https://releasebot.io/updates/anthropic), [Anthropic API docs](https://docs.anthropic.com/en/release-notes/api)

**Why it matters:** Good for teams doing security-key rotation — forces key hygiene without manual audits, and the `expires_at` Admin API field lets you automate rotation reminders in CI pipelines.

## Tools & Frameworks

### [UPDATE] MCP 2026-07-28 spec: beta Tier-1 SDKs are live
The final MCP spec locks July 28 (17 days). Per [the MCP blog](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/), beta SDK builds for the Tier-1 maintainers (Python, TypeScript, etc.) are now available for the 10-week validation window. The headline breaking change: `Mcp-Session-Id` and `initialize/initialized` handshake are removed; capabilities now travel inline per request via `_meta`, making servers fully stateless behind a plain load balancer. New routing headers `Mcp-Method` and `Mcp-Name` replace session-based routing. Full JSON Schema 2020-12 support (`oneOf`, `anyOf`, `$ref`) is now formalized in tool input schemas. Roots/Sampling/Logging formally deprecated with 12-month removal runway. Sources: [MCP Blog RC post](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [MCP Blog SDK betas](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/), [WorkOS breakdown](https://workos.com/blog/mcp-2026-spec-agent-authentication)

**Why it matters:** If you run or maintain an MCP server, now is the time to test against beta SDKs — breaking the session ID / handshake pattern is not backwards-compatible and any server relying on sticky routing will break on July 28.

## Model Releases

### [NEW] OpenAI GPT-Live-1 and GPT-Live-1 mini
OpenAI launched full-duplex voice models on July 8, now the default for ChatGPT Voice. [TechCrunch](https://techcrunch.com/2026/07/08/openai-releases-new-voice-models-for-more-natural-live-conversations/) and [MLQ News](https://mlq.ai/news/openai-launches-gpt-live-1-a-full-duplex-voice-model-that-listens-and-speaks-simultaneously/) cover the key details: GPT-Live is built on a full-duplex architecture (listens and speaks simultaneously), can acknowledge with backchannels ("mhmm", "yeah") mid-thought, and handles natural interruptions. Backend is GPT-5.5 for most turns; delegates to frontier models for web search or complex reasoning tasks. GPT-Live-1 replaces Advanced Voice Mode for Go/Plus/Pro users; GPT-Live-1 mini is the default for Free. Rolling out globally on iOS, Android, and ChatGPT.com. Sources: [OpenAI](https://openai.com/index/introducing-gpt-live/), [TechCrunch](https://techcrunch.com/2026/07/08/openai-releases-new-voice-models-for-more-natural-live-conversations/)

## Wildcard

### [NEW] Apple sues OpenAI for trade secret theft
Apple filed a federal lawsuit in Northern California on July 10 alleging systematic trade secret theft. [CNBC](https://www.cnbc.com/2026/07/10/apple-openai-lawsuit-trade-secrets.html) and [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-10/apple-sues-openai-for-trade-secret-theft-in-blockbuster-case/) both report the allegations: OpenAI's hardware chief Tang Tan (former Apple VP) allegedly directed job candidates to bring "actual parts" from Apple for show-and-tell during interviews, and coached departing Apple employees on how to evade security processes. A named ex-Apple employee allegedly stole a company laptop when leaving. Apple claims OpenAI is asking hardware manufacturing partners to implement a proprietary metal finishing technique Apple invented, misleading them about having Apple's permission. Apple seeks damages, injunctions, and destruction of misappropriated IP. Over 400 former Apple employees are now at OpenAI. The lawsuit reverses the Apple-OpenAI partnership that produced Apple Intelligence in 2024. Sources: [CNBC](https://www.cnbc.com/2026/07/10/apple-openai-lawsuit-trade-secrets.html), [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-10/apple-sues-openai-for-trade-secret-theft-in-blockbuster-case/), [TechCrunch](https://techcrunch.com/2026/07/10/apple-sues-openai-over-alleged-trade-secret-theft/)
