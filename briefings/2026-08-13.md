## Anthropic

### [NEW] Claude text watermarking goes global under EU AI Act

Anthropic began embedding invisible watermarks in all text generated by new Claude models, announced August 11, 2026. Generated files (.svg, .png, .jpg) receive C2PA-standard signed provenance metadata. Anthropic is applying the marks worldwide — not just to EU users — as a voluntary overreach beyond what Article 50 strictly requires. The mark signals that content was processed by Claude but is not conclusive proof: paraphrase, editing, or pre-marking models can remove it. Text watermarks don't affect readability or quality per Anthropic's own statement.

**Why it matters:** If you're shipping Claude-generated code artifacts or content files through a pipeline, the C2PA metadata in .png/.svg outputs will now travel with the file. Worth auditing if you're using Claude Code for image generation or SVG work that feeds into downstream systems with provenance requirements.

Sources: [TechTimes](https://www.techtimes.com/articles/323873/20260811/claude-now-watermarks-text-everywhere-mark-proves-processing-not-authorship.htm), [The Next Web](https://thenextweb.com/news/anthropic-watermarks-claude-output-eu-ai-act-article-50), [Euronews](https://www.euronews.com/next/2026/08/11/eu-compliance-delivered-globally-anthropic-to-watermark-claudes-output-worldwide)

### [UPDATE] Claude Sonnet 5 API pricing locked at $2/$10 permanently

**Background:** Sonnet 5 launched April 1 at $2/$10 per Mtok as introductory pricing, with a scheduled jump to $3/$15 on September 1.

**New:** On August 10, Anthropic canceled the September 1 price increase and made $2/$10 the permanent standard rate. Subscription plan prices are unchanged. This removes a 50%+ cost cliff that was 20 days away for API users. The new tokenizer (which encodes the same text as 0–35% more tokens than Sonnet 4.6) remains unchanged, so the effective cost advantage over Sonnet 4.6 is narrower than the headline pricing suggests.

Sources: [explainx.ai](https://explainx.ai/blog/anthropic-sonnet-5-permanent-pricing-august-2026), [Anthropic pricing docs](https://platform.claude.com/docs/en/about-claude/pricing)

## Tools & Frameworks

### [UPDATE] Claude Code August 13 changelog

Today's update to Claude Code adds:
- **Server-supplied hook support for self-hosted runner sessions** — matches the hook behavior already available in managed-environment sessions; self-hosted deployments can now configure SessionStart/PreToolUse/PostToolUse hooks server-side without per-user config.
- **SSE keepalive pings during long thinking pauses** — targets Vertex AI and Bedrock upstreams specifically, where idle-timeout disconnections were breaking long-reasoning sessions mid-stream.
- **`claude remote-control --continue`** — documented command for resuming the most recent Remote Control session (distinct from self-hosted runners — RC remains tied to the originating machine).
- **Plugin marketplace command sources** — new extension point for marketplace-sourced slash-command definitions.

**Why it matters:** The self-hosted runner hook support closes the config-parity gap between managed and self-hosted deployments, which matters if you're running Claude Code sessions inside your own infra (Routines pattern). The Vertex/Bedrock SSE fix is a reliability improvement for anyone using Claude Code via AWS or GCP.

Sources: [gradually.ai Claude Code changelog](https://www.gradually.ai/en/changelogs/claude-code/), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)
