### [NEW] Claude Code Artifacts: session work as live shareable web pages

Launched June 18, 2026 for Team and Enterprise subscribers (Claude Code CLI and desktop app v1.13576.0+).

Artifacts turn a Claude Code session into a live, interactive web page. The artifact is constructed from three sources: the repository snapshot, any connected MCP tools/plugins, and the full conversation history. Once published, the page refreshes in-place when Claude Code makes a new commit or update — teammates with the link see changes without reloading.

**Key mechanics:**

- Every publish is a version at the same URL; full version history with point-in-time restore.
- Access is restricted to authenticated org members — no public links.
- Designed for: PR walkthroughs, incident status pages, release checklists, system explainers, internal dashboards built during a session.

**Availability:** Team and Enterprise only. Not available on Pro/Max or the free tier.

Sources: [Anthropic blog](https://claude.com/blog/artifacts-in-claude-code), [VentureBeat](https://venturebeat.com/data/anthropics-claude-code-artifacts-update-brings-live-shared-dashboards-and-interactive-workspaces-to-enterprises), [TechTimes](https://www.techtimes.com/articles/318691/20260619/claude-code-artifacts-turns-ai-coding-sessions-live-shareable-browser-pages.htm)

**Why it matters:** If you're on Team/Enterprise and running Claude Code for handoffs — PR reviews, incident runbooks, architectural docs — Artifacts eliminates the export-and-paste step. Session output becomes a living page, not a markdown dump.

### [NEW] NVIDIA Nemotron 3 Ultra: best US open-weight model for agentic workloads

*Released June 4, 2026 at Computex — covered belatedly.*

NVIDIA completed the Nemotron 3 family with Ultra, a 550B total / 55B active parameter model under a fully open license, purpose-built for long-running agents. The prior two members: Nano (31.6B, December 2025) and Super (120B, March 2026 / GTC).

**Architecture:** Mixture-of-Experts with a Mamba-Attention hybrid backbone. The Mamba layers handle long-context state efficiently without the quadratic attention cost — relevant for agents running hundreds of turns with tool calls between them.

**Benchmarks:** Score of 48 on the Artificial Analysis Intelligence Index — the highest of any US open-weight model at launch. Claims 5× higher throughput than comparable open models in its class.

**Licensing:** Fully open (Apache 2.0 per NVIDIA's standard Nemotron release terms); no usage restrictions.

**Design target:** Agents that plan → call tools → delegate to sub-agents → read observations → recover from errors across hundreds of turns while burning fewer tokens than comparable models.

Sources: [NVIDIA Newsroom](https://nvidianews.nvidia.com/news/nvidia-debuts-nemotron-3-family-of-open-models), [Artificial Analysis](https://artificialanalysis.ai/articles/nvidia-nemotron-3-ultra-released), [NVIDIA Technical Blog](https://developer.nvidia.com/blog/nvidia-nemotron-3-ultra-powers-faster-more-efficient-reasoning-for-long-running-agents/)

**Why it matters:** If you need a large open-weight model for an agent that runs long sessions with many tool calls, Nemotron 3 Ultra is now the benchmark to beat. The Mamba-Attention hybrid is a different architectural bet than pure-MoE models like GLM-5.2 or DeepSeek V4 — worth evaluating for token efficiency at high turn counts.
