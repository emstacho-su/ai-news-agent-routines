## Anthropic

### [UPDATE] Claude Code v2.1.273 (Sept 15): gateway hint headers, MCP disconnect notification

**Background:** v2.1.271 (Sept 14) landed fast mode for remote/cloud sessions and per-command `allowed_domains` for Bash in auto mode.

**New (Sept 15, v2.1.273):**
- **`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`** — opt-in env var that sends new request headers to the LLM gateway on every call: `x-claude-code-request-class`, `x-claude-code-agent-type`, `x-claude-code-prev-tool-durations`, `x-claude-code-compaction`, and `x-claude-code-context-compacted`. Designed for gateway operators who want per-request observability without tapping the model payload.
- **MCP server disconnect notification** — when an MCP server disconnects mid-session and auto-reconnect gives up, Claude Code now surfaces a notification with a pointer to `/mcp` rather than silently failing. Previously the session would proceed with the server absent and the user often wouldn't know.
- Also includes session-forking from `--remote-control` sessions: a session started via `claude --remote-control` can now be forked to run as an independent background session from the Claude app.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot Claude Code](https://releasebot.io/updates/anthropic/claude-code), [AI CLI Tools Digest 2026-09-16](https://github.com/kouweizhu/agents-radar/issues/66)

**Why it matters:** The gateway hint headers are the right primitive for teams running Claude Code through an internal LLM proxy — you can now tag cost-allocation, rate-limit, or log by agent type without parsing model payloads. The MCP disconnect notification closes a silent-failure footgun that was particularly bad in headless/Routine sessions.

### [NEW] Claude Enterprise Smart Reports (beta): transcript-level usage analytics

Launched September 10, available on Claude Enterprise plans (excludes CMEK, HIPAA, and Access Transparency configurations; excludes Claude Code in ZDR orgs).

Smart Reports are generated on demand. Claude reads a sample of your org's transcripts and returns a prose + chart report covering:

- **Workstreams and output types** — how work divides across analysis, documentation, code, and other categories
- **Cost attribution** — spend by workstream across chat, Claude Code, and Claude Cowork
- **Friction surface** — sessions that ran into repeated errors, dead ends, or manual intervention
- **Skill candidates** — repeated patterns that could be packaged as shared skills instead of re-prompted each time

Reports look back up to 28 days. During beta: up to 10 reports/month at no charge. Generation runs via Claude reading transcripts, so producing a report consumes org quota.

Sources: [Anthropic Claude Updates Sept 2026](https://releasebot.io/updates/anthropic/claude), [Claude Enterprise Smart Reports Beta](https://claypier.com/en/claude-enterprise-smart-reports-beta/), [Smart Reports Launch](https://gaiinsights.substack.com/p/anthropics-new-smart-reports-feature)

**Why it matters:** If you're managing a team of Claude Code users, this replaces ad-hoc "look at the admin usage tab" with a structured, prose-form analysis of *what work is actually happening* and where the friction is. The skill-candidates surface is the interesting one — it's Claude telling you what to systematize.

### [NEW] Docusign MCP Server GA September 30: agreement workflows for any agent

Docusign announced September 4 that its MCP server goes generally available to every AI agent on September 30. The server exposes Docusign's agreement layer — powered by Iris, Docusign's AI engine — as first-class tool calls in Claude, ChatGPT, Gemini, Copilot, Slack, and any MCP client.

Key capabilities exposed as MCP tools:
- Send, track, and manage agreements without leaving the agent
- Draw on Iris's negotiation memory: past accepted terms, clauses, and company policy
- Full CLM (Contract Lifecycle Management) workflow access for enterprise configurations

Enterprise controls include account-level admin permissions, global multi-region infrastructure, and multilingual support.

Sources: [Docusign Press Release](https://www.prnewswire.com/news-releases/docusign-agreement-layer-for-the-agentic-enterprise-coming-to-every-agent-302870029.html), [Docusign MCP GA explainer](https://signb.ee/blog/docusign-mcp-ga-every-agent), [Nasdaq announcement](https://www.nasdaq.com/press-release/docusign-agreement-layer-agentic-enterprise-coming-every-agent-2026-09-04)

**Why it matters:** Docusign MCP means that an agent doing deal prep or procurement can send contracts and track counterparty signature status without a human stepping in to switch apps. Agreement execution has historically been the last manual gate in agentic sales/procurement flows; this removes it.

### [NEW] Shanghai AI Lab Atria Dawn Preview: 744B open-weight agentic MoE (MIT)

Shanghai Artificial Intelligence Laboratory (SAIL) quietly released Atria Dawn Preview on GitHub September 11 — no blog post, no announcement — followed by a 140-author technical report three days later on September 14. Built on the 744B-parameter GLM-5.2 MoE foundation and trained via a Verifiable Experience Pipeline that grounds tool use in executable environments.

Key properties:
- **Architecture:** 744B-parameter MoE; targets research and engineering scenarios requiring continuous environmental understanding, multi-step tool use, and failure recovery
- **Full agentic loop:** problem analysis → solution design → tool use → code implementation → experiment execution → result analysis → failure recovery — all in a single context
- **License:** MIT. Self-hosting requires 756GB–1.5TB of weights; no per-token billing, but infrastructure cost shifts to you
- **Benchmarks:** vendor-reported claims of "highest score on 5 of 16 benchmarks" spanning real-world research, engineering, and digital work tasks. No Artificial Analysis or comparable independent verification yet as of this briefing

Sources: [AI Weekly alert](https://aiweekly.co/alerts/shanghai-ai-lab-ships-atria-dawn-preview-a-744b-agentic-moe), [Startup Fortune](https://startupfortune.com/shanghai-ai-lab-quietly-releases-atria-a-free-744-billion-parameter-ai-agent/), [GitHub repo](https://github.com/atria-asi/Atria-Dawn-Preview), [HuggingFace](https://huggingface.co/internlm/Atria-Dawn-Preview), [OrcaRouter explainer](https://www.orcarouter.ai/blog/atria-dawn-preview-quiet-release)

## Wildcard

### [NEW] Gemini Notebook switches to compute-based usage limits (live since Sept 2)

Google's Gemini Notebook (formerly NotebookLM) migrated from fixed daily caps to compute-based limits effective September 2, 2026. The new model:

- **Compute-weighted cost** — a short factual query costs far less than generating a Video Overview or a full Slide Deck; limits factor prompt complexity, model, and feature
- **5-hour refresh** — quota resets every 5 hours until the weekly cap is hit (vs. the old single daily cap)
- **Live usage indicator** — in-UI meter below the chat window shows remaining capacity in the current 5-hour window
- **Graceful degradation** — if your first choice exceeds budget, Notebook suggests a lower-cost output format and lets you defer heavy outputs

This is the third major AI product in 2026 (after Claude Code and Gemini app) to move off flat daily caps toward compute-proportional quotas.

Sources: [9to5Google](https://9to5google.com/2026/08/28/gemini-notebook-usage-limits/), [Android Police](https://www.androidpolice.com/gemini-notebook-ditching-daily-limits-more-complicated/), [Google Blog](https://blog.google/innovation-and-ai/products/gemini-notebook/new-flexible-usage-limits/), [GCN](https://gcn.com/gemini-notebook-switches-compute-based-limits/21309/)
