## Anthropic

### [UPDATE] Fable 5.1 + Mythos 5.1: operational details surface
**Background:** Anthropic released Fable 5.1 and Mythos 5.1 on September 1; earlier coverage captured the 75% cache-read price cut ($0.25/M from $1.00/M) and benchmark wins over Fable 5 and GPT-5.6 Sol.

**New:** Post-launch coverage fills in the spec sheet and safeguard mechanics:
- **Context / output:** 1M-token context window, 128K token max output per response.
- **Cost at scale:** ~25% cheaper for typical workloads, ~45% cheaper for highly agentic workloads (cache-read dominance at scale); base input/output pricing unchanged at $10/$50/M.
- **Claude Code false positives:** ~60% reduction in cybersecurity false positives — Anthropic explicitly says Fable 5.1 can identify software vulnerabilities but is safeguarded against developing exploits.
- **Benchmark:** 52.6% on Terminal-Bench-Science; outperforms Fable 5, Opus 5, and GPT-5.6 Sol on coding + knowledge-work evals.
- Mythos 5.1 carries the same architecture with tighter access controls for vetted security/life-sciences orgs.

**Why it matters:** The vulnerability-finding-but-not-exploit safeguard is meaningful for defensive security work in Claude Code — the false-positive reduction means fewer interrupted sessions when scanning real codebases.

### [UPDATE] Claude Cowork gets a sandboxed built-in browser
**Background:** Cowork (agentic workspace) expanded to web and mobile in July 2026; Microsoft 365 write tools followed shortly after.

**New:** Anthropic shipped a built-in browser inside the Claude desktop app for Cowork. It opens sites in a side panel — Claude reads, clicks, and types without touching your own browser. Key mechanics:
- Fully sandboxed; safety classifiers review actions on external sites.
- You can choose whether browsing sessions persist across Cowork runs.
- Login import site-by-site from Chrome, Edge, or Firefox on macOS; Firefox on Windows/Linux.
- Claude never sees your personal tabs, bookmarks, or passwords.
- Rolls out to Pro, Max, Team, and Enterprise plans.

Sources: [Anthropic blog](https://claude.com/blog/cowork-built-in-browser), [MLQ News](https://mlq.ai/news/anthropic-adds-built-in-web-browser-to-claude-code-desktop-app/), [Memeburn](https://memeburn.com/claude-desktop-is-getting-a-built-in-browser-for-cowork-and-that-changes-the-game/).

**Why it matters:** Cowork tasks that required manual browser handoff (reading docs, pulling live data, handling login-gated pages) can now be fully delegated — directly relevant for any Cowork-based research or agent workflows.

## Tools & Frameworks

### [UPDATE] Claude Code September MCP fixes: org-wide managed servers, session data-loss fix
**Background:** Claude Code has supported remote MCP servers since early 2026; enterprise MCP deployment previously required per-user configuration.

**New batch of improvements:**
- **`managedMcpServers` managed setting** — organizations can now provision HTTP/SSE MCP servers to every user automatically without per-user setup. The setting is controlled via the enterprise managed configuration layer.
- **Concurrent session data-loss fix** — a bug where parallel Claude Code sessions silently overwrote each other's `~/.claude.json` was patched; workspace trust, MCP state, and project settings no longer reset when running many sessions simultaneously.
- **`--permission-prompts none`** — new flag for unattended/headless hosts; disables interactive permission prompts entirely for CI and automation contexts.
- **Stale browser-hosted MCP fix** — remote (claude.ai) sessions no longer take 60 seconds to start a turn after a browser-hosted MCP server's page has gone away.
- OAuth credential cleanup fix: `claude mcp remove` now properly clears stored OAuth credentials even in `strictPluginOnlyCustomization` environments.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code).

**Why it matters:** The concurrent session data-loss fix is a real reliability issue for anyone running multi-session or parallelized Claude Code workflows. `managedMcpServers` removes the last major friction point for org-wide MCP rollouts.

## Model Releases

### [UPDATE] OpenAI Astra clears Critical cybersecurity threshold; release imminent
**Background:** Astra was paused in August after Preparedness Framework tests couldn't rule out "Critical" cyber capability; Astra had already solved ten long-open math problems at ~$2,000 compute cost (announced August 1).

**New (September 1 disclosure):** OpenAI confirmed Astra is the **first model to meet its "Critical" cybersecurity threshold** and cleared it for a staged release:
- Autonomously discovered two zero-day vulnerabilities in a separate evaluation of recent CVEs — without human guidance.
- Expert-led red team: Astra built a full browser-compromise chain that escaped a VM sandbox and executed commands on the host OS.
- Also chained multiple vulnerabilities in a hardened OS from unprivileged user to root (full privilege escalation) without intermediate steps.
- Jailbreak refusal rate: 91.5% (vs. 59% for GPT-5.6 Sol).
- **Advanced cyber capabilities** (autonomous zero-day finding, exploit chaining) restricted to "Daybreak" coalition members — vetted security orgs, not general API access.
- Internal test builds circulating under names `mozaik-alpha-fdm` and `ultima-alpha`; public rollout expected imminently.

Sources: [TechCrunch](https://techcrunch.com/2026/09/01/open-ais-astra-model-is-on-the-way-and-very-good-at-breaking-into-computer-systems/), [SecurityWeek](https://www.securityweek.com/openais-astra-becomes-first-model-to-cross-critical-cybersecurity-threshold/), [OpenAI](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/), [CNBC](https://www.cnbc.com/2026/09/01/open-ai-astra-cyber-model.html), [Axios](https://www.axios.com/2026/09/01/openai-astras-cyber-critical).

**Why it matters:** Astra's critical-tier capability creates real pressure on Anthropic's Mythos program — both are now in the same "restricted to vetted defenders" tier for advanced offensive capabilities. ## Practical Tips

**Fable 5.1 for agentic Claude Code:** With cache reads at $0.25/M (75% down) and ~45% cost reduction for agentic workloads, long-running Claude Code sessions reading large codebases become significantly cheaper. If you're on a Max plan, effective cost is token-quota-denominated rather than API-billed, but the cost accounting matters if you're evaluating API pricing for v1-routines.

**`--permission-prompts none`:** If you're running Claude Code in a CI-equivalent context (non-interactive session, fixed trusted toolset), this flag removes the interactive gate entirely. Combine with `--restricted` (added in v2.1.248) for the most locked-down headless mode.

**`managedMcpServers`:** If you're running Claude Code across multiple machines or users (org/team plans), the new managed setting means you can push MCP server configs org-wide without touching individual `~/.claude.json` files — a notable ops improvement.
