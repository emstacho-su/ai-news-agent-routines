## Anthropic

### [UPDATE] Claude Code default permission mode flips to "auto" on paid plans — August 14

**Background:** v2.1.203 (July 8) reverted the default to "Manual" mode after community pushback that auto mode was too aggressive. New sessions on all tiers have required explicit approval since then.

**New:** Starting today, auto mode is the default for new sessions on Pro, Max, and Team plans. Anthropic's safety classifier screens every tool call before execution, so the model still can't run destructive operations without a prompt — the difference is that routine read/write/bash calls are auto-approved when the classifier rates them safe. Existing users who've set a personal default keep it unless they accept a one-time switch prompt; org-managed defaults are untouched. Enterprise teams still deploy with whatever `defaultMode` their settings enforce.

Sources: [DEV Community deep-dive](https://dev.to/rulestack/auto-mode-is-now-claude-codes-default-what-the-classifier-approves-and-how-to-switch-back-4j2j), [Digital Applied](https://www.digitalapplied.com/blog/claude-code-auto-mode-default-permission-model-shift), [AI Career Lab](https://theaicareerlab.com/blog/claude-code-auto-mode-default-2026), [beri.net on deny rules](https://www.beri.net/article/claude-code-auto-mode-default-august-14-deny-rules-not-prompts).

**Why it matters:** If you're starting new sessions or onboarding teammates today, the approval-prompt cadence you've gotten used to is gone by default. The practical implication for Stack's Routines work: headless sessions in automated pipelines should behave identically to before (auto mode was already the Routine default), but local interactive sessions will now approve more without asking.

## Model Releases

### [NEW] Grok 4.6: post-training refinement focused on long-running agents

xAI released Grok 4.6 on August 12 (checkpoint dated August 10). It's a refinement release built on the same V9 1.5T-parameter foundation as Grok 4.5 — improvements come entirely from post-training (upgraded SFT and RL), not a new base model. The stated focus is agent persistence: staying on-task across many-step agentic runs, complex codebases, and iterative artifact creation.

Benchmarks: 61/100 on the Artificial Analysis Intelligence Index, matching GPT-5.6 Sol Max. Pricing: $2/$6 per million input/output tokens, with cached input at $0.50/M. Context: 500K tokens. A larger Grok 4.7 (new 2.1T-parameter foundation) is expected late August or early September. [RUMOR]

Sources: [xAI announcement](https://x.ai/news/grok-4-6), [xAI docs release notes](https://docs.x.ai/developers/release-notes), [Testing Catalog](https://www.testingcatalog.com/icymi-xai-releases-grok-4-6-for-long-running-agent-work/), [Codersera guide](https://codersera.com/blog/grok-4-6-launch-guide-2026/).

## Research & Technical

### [UPDATE] OpenAI Astra: government auditors in, release timeline measured in months

**Background:** OpenAI paused Astra development August 7 after internal eval showed it could approach the "Critical" cybersecurity threshold in its own safety framework — capable of identifying and developing zero-day exploits without human guidance.

**New:** External auditors from the UK AI Security Institute and unnamed US government agencies are now conducting independent testing. All Astra work is confined to air-gapped environments with no network access; model weights are under stronger encryption; chain-of-thought outputs are under automated monitoring. OpenAI has not provided a release date; its own blog language implies a multi-month delay, not a brief pause.

Sources: [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-07/openai-pauses-some-work-on-new-astra-model-over-cyber-concerns), [Forbes](https://www.forbes.com/sites/jonmarkman/2026/08/09/openai-pauses-astra-after-it-nears-first-ever-critical-cyber-risk/), [TechCrunch](https://techcrunch.com/2026/08/07/openai-says-it-slowed-astra-model-development-over-security-concerns/), [The Hacker News](https://thehackernews.com/2026/08/openais-next-ai-model-astra-shows-cyber.html), [CNBC](https://www.cnbc.com/2026/08/10/openai-astra-cybersecurity-risks.html).

## Wildcard

### [NEW] AI-designed bacteriophages: 16 viable viruses from scratch, some outperforming nature

Researchers at Stanford and the Arc Institute used Evo-2 (a genome language model trained on 2 million bacteriophage sequences) to generate complete bacteriophage genomes from scratch — no natural template, no human-designed scaffold. Sixteen of the resulting phages successfully infected and killed bacteria in lab tests. Several killed E. coli faster than the natural phage strains used as a baseline. The work was published August 6 in *Science*.

Training excluded all virus sequences capable of infecting humans, animals, or plants, but the paper's biosecurity implications are already prompting discussion: the technique requires only a language model and synthesis, not expertise in phage biology. The immediate application the researchers cite is customized phage therapy for antibiotic-resistant infections.

Sources: [Stanford News](https://news.stanford.edu/stories/2026/08/evo-2-ai-tool-e-coli-killer-bacteriophages), [Axios](https://www.axios.com/2026/08/06/ai-virus-designed-bacteria-viruses), [Beta News](https://betanews.com/article/ai-designed-viruses-stanford-arc-institute/), [Newsmax](https://www.newsmax.com/us/stanford-lab-bacteria/2026/08/06/id/1265331/).

## Practical tips

- **Claude Code permission audit:** if you run shared or team sessions, check that your `defaultMode` setting in `.claude/settings.json` or managed org settings reflects your intent — today's flip to auto only affects users who had no explicit mode set.
- **MCP server targeting:** with the 2026-07-28 stateless spec at GA and rolling out across Claude, AWS, and Azure, server code that relies on `Mcp-Session-Id` or the `initialize` handshake should be migrated now.
