## Anthropic

### [NEW] Anthropic Cyber Mission: defensive security initiative launches
Anthropic launched the Anthropic Cyber Mission on October 8, framing it as a dedicated effort to help software defenders — distinct from the offensive-focused Cyber Verification Program (CVP) restructured the day prior. The initiative includes tools and research for securing software and systems. A $15M grant program for state, local, tribal, and territorial governments was announced under the same umbrella, with California and Texas already enrolled.

**Why it matters:** Anthropic is now operating two parallel cybersecurity programs: CVP (offensive, Mythos-gated) and Cyber Mission (defensive, broader access). Worth watching for any API or tooling hooks useful in Stack's security-concentration work. Sources: [anthropic.com](https://www.anthropic.com/news/anthropic-cyber-mission), [statescoop.com](https://statescoop.com/tag/tj-white/).

## Tools & Frameworks

### [UPDATE] OpenAI Decisions API enters public beta
**Background:** Previewed at OpenAI DevDay 2026 (Sept 29) as part of the broader Agents API launch.
**New:** The Decisions API entered public beta October 6, exposing a dedicated `/v1/decisions` endpoint backed by GPT-6 Luna. It returns three output types: **predicates** (probability a statement is true), **choices** (select from developer-defined options with confidence scores), and **scores** (numeric evaluation against a rubric). Pricing is $0.10/M input tokens; cache reads, cache writes, and output tokens are unbilled. OpenAI claims up to 10x faster response than going through the Responses API.

**Why it matters:** The "no output billing" pricing model is unconventional — likely optimized for high-volume classification and routing tasks in agent pipelines. Direct competition for Anthropic's structured-output patterns. Sources: [aiweekly.co](https://aiweekly.co/alerts/openai-launches-decisions-api-public-beta-on-gpt-6-luna), [propakistani.pk](https://propakistani.pk/2026/10/07/openai-launches-decisions-api-with-up-to-10x-faster-responses/), [OpenRouter listing](https://openrouter.ai/openai/gpt-6-luna-decisions-20261006).

## Practical tips

- **Sonnet 5.5 cache-read at $0.10/M** is now cost-competitive with Haiku-class caching. If you're running large-context pipelines with repeated prefixes on Sonnet 5.5, the economics shifted overnight.
- **OpenAI Decisions API** uses an entirely different endpoint shape (not chat-completions compatible). If you're evaluating it for classifier/router use in an agent pipeline, budget a separate integration path — it's not a drop-in swap.
