## Tools & Frameworks

### [UPDATE] DeepSeek Legacy Endpoints Retired — Today, 15:59 UTC

**Background:** DeepSeek V4 shipped April 24 with `deepseek-v4-flash` and `deepseek-v4-pro`; old model names were kept alive as transparent aliases through today's hard cutoff.

**New:** `deepseek-chat` and `deepseek-reasoner` now return errors. Any integration using either legacy name is broken as of this afternoon. The fix is a single line — update the model ID string to `deepseek-v4-flash` (equivalent to old chat) or `deepseek-v4-pro` (equivalent to old reasoner). DeepSeek also added a dedicated Anthropic-format endpoint at `https://api.deepseek.com/anthropic` for teams running Claude Code or other Anthropic-native tooling alongside DeepSeek models. Sources: [Enterprise DNA](https://enterprisedna.co/resources/news/deepseek-api-migration-july-24-deadline-2026/), [DeepSeek API Docs](https://api-docs.deepseek.com/news/news260424/), [TheRouter.ai](https://therouter.ai/news/deepseek-chat-reasoner-deprecation-v4-migration-routing/)

### [UPDATE] GitHub MCP Server Adds 2026-07-28 Stateless Spec Support

**Background:** MCP's July 28 spec goes fully stateless — `initialize`/`initialized` handshake removed, `Mcp-Session-Id` header gone, capabilities now travel inline per request via `_meta`; routing via `Mcp-Method`/`Mcp-Name` headers.

**New:** GitHub shipped spec support in its official MCP server on July 23 — the first major production server live on the new stateless protocol. Concrete gains: no DB writes on connect, no DB reads per call, routing headers readable directly from HTTP headers without JSON payload inspection. All Tier 1 SDKs (Python, TypeScript, Go) now have beta builds out. The final spec ships in 4 days on July 28. Sources: [GitHub Changelog](https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/), [MCP Blog](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/)

### [UPDATE] OpenAI Codex: Voice-Controlled Multi-Agent Computer Use

**Background:** Codex added mobile support and persistent memory earlier this year.

**New (July 24):** Voice control for computer use and multi-agent coordination is live in ChatGPT Work and Codex desktop apps. GPT-Live handles the audio layer — full-duplex voice that can simultaneously speak, listen, and coordinate work across multiple running agents. You direct agents by voice while they execute in parallel; no switching between voice and text modes. Sources: [Releasebot/OpenAI](https://releasebot.io/updates/openai/codex), [ExplainX](https://explainx.ai/blog/openai-codex-july-24-reveal-tibo-sottiaux-teaser-2026)

## Practical Tips

- **DeepSeek migration:** Change one string. `"deepseek-chat"` → `"deepseek-v4-flash"`, `"deepseek-reasoner"` → `"deepseek-v4-pro"`. If you're on the OpenAI-compat endpoint, the base URL stays the same; Anthropic-format is now at `https://api.deepseek.com/anthropic`.

- **Claude Code — Opus 4.7 fast mode gone:** Fast mode (`speed: "fast"` or the equivalent API flag) for `claude-opus-4-7` returns an error as of today. Migrate to `claude-opus-4-8`. Fast mode for 4.8 is the same latency tier on the new model.
