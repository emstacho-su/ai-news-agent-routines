### [UPDATE] Claude Code v2.1.289: plugin and shell safety hardening, agent.spawn API

**Background:** v2.1.287 (Oct 4) shipped Claude Mods — TypeScript function hooks for customizing CLI behavior.

**New:** v2.1.289 fixes a broad set of plugin, terminal, and shell-command safety issues; improves large-file rendering performance; and adds `agent.spawn` plus new agent state support to the programmatic API. Additionally, `disableClaudeAiConnectors` and `allowedMcpServers` URL rules are now correctly applied to MCP entries declared in `.mcp.json`, plugins, and agents (previously those config paths were silently skipped). MCP servers that request additional OAuth scope mid-tool-call now trigger a re-authentication prompt rather than silently proceeding.

**Note:** If an MCP server stops connecting after this update, add `"bareElicitationCapability": true` to its MCP config entry.

Sources: [Releasebot – Claude Code October 2026](https://releasebot.io/updates/anthropic/claude-code), [gradually.ai changelog](https://www.gradually.ai/en/changelogs/claude-code/), [DEV Community week-of-Oct-4 roundup](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-october-4-2026-3h6o)

**Why it matters:** The `allowedMcpServers` fix is a real security patch — orgs that thought they'd locked down which servers Claude Code could talk to may find that restriction wasn't being applied. Worth checking your `.claude/settings.json` if you have those rules set.

## Tools & Frameworks

### [NEW] OpenAI "28 Days of Quality of Life" campaign: GPT-6 Astra + Sol ~50% faster by default

OpenAI launched a 28-day daily-improvement drip on October 5. Day 1: GPT-6 Astra and GPT-6.1 Sol are **approximately 50% faster by default** across ChatGPT subscriptions and any partner that supports Sign in with ChatGPT (OpenCode, Pi, Amp, Devin, etc.) — no API parameter change needed, purely a serving-side optimization. Day 2+ details not yet published.

Sources: [OpenAI Release Notes Oct 2026](https://releasebot.io/updates/openai), [Releasebot](https://releasebot.io/updates/openai)

**Why it matters:** A 50% TTFT improvement on Astra without model changes means OpenAI is still primarily competing on inference infrastructure, not capability. For anyone routing between Astra and Claude Fable 5.1/Opus 5.5 based on latency, the gap just narrowed.

### [NEW] OpenAI Codex 0.160.1: Windows MCP environment fix

Codex 0.160.1 (Oct 6) fixes remote stdio MCP environment handling: `SYSTEMROOT`, `TEMP`, and `TMP` are now correctly preserved on Windows-hosted launches. Previously these were dropped, breaking tool invocations that depend on Windows system paths.

Sources: [Releasebot – OpenAI Oct 2026](https://releasebot.io/updates/openai)

## Model Releases

### [UPDATE] Gemini 4 enters fine-tuning; DeepMind CEO sets "well before end of 2026" target

**Background:** Google announced Gemini 4 post-training on October 4; pre-training started July 21 (Logan Kilpatrick's public X post).

**New:** In his first public appearance since replacing Demis Hassabis, DeepMind CEO Koray Kavukcuoglu confirmed Gemini 4 has moved from pre-training to fine-tuning and said Google intends to release a first version **"as soon as possible, well before the end of 2026."** No benchmark figures or specific date announced. The pre-training-to-fine-tuning turnaround (July 21 → early October) is roughly 10 weeks, faster than Gemini 3's cycle.

## Practical Tips

- **MCP config audit:** Claude Code v2.1.289 fixes `allowedMcpServers` URL filtering that was silently not enforced. If your project settings restrict MCP server access, verify your rules are now taking effect after the update — and flip `"bareElicitationCapability": true` if any server stops connecting.
- **OpenAI text watermarking opt-in live:** As of Oct 6, API customers can opt in to C2PA-compatible text watermarking on select models. Relevant if you're building products that need EU AI Act provenance compliance. Opting in adds a per-token overhead; no published benchmarks yet on impact.
