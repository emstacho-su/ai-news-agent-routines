## Anthropic

### [NEW] Claude Sonnet 5.5: 30% faster, same Sonnet 5 price, first Sonnet with notable cybersecurity capabilities
Anthropic shipped Sonnet 5.5 on September 28, holding the line on Sonnet 5 pricing ($2/M input, $10/M output) while delivering output 30% faster and up to 30% lower compute cost per task in Anthropic's internal testing. It shares the same foundation as Opus 5.5, which is why it's the first Sonnet model with meaningful cybersecurity capabilities. Fun benchmark: first Sonnet to beat Pokémon Red working solely from screenshots. Invisible text watermarking is now enabled by default.
Sources: [Anthropic announcement](https://www.anthropic.com/claude-sonnet-5-5), [SiliconAngle](https://siliconangle.com/2026/09/28/anthropic-debuts-claude-sonnet-5-5-running-30-faster-than-the-previous-generation-ai-model/), [Simon Willison](https://simonwillison.net/2026/Sep/28/claude-sonnet-5-5/)

**Why it matters:** Claude Code v2.1.284 (also Sept 28) now defaults to Sonnet 5.5, so every routine and coding session just got the speedup for free. The cybersecurity capability uplift is notable given the Opus 5.5 foundation — tool calls in security analysis workflows should benefit.

### [NEW] Manus 2.0 + Cue: personal agents with phone, wallet, and cloud computer
Manus launched Manus 2.0 and the standalone Cue app on September 28. Each Cue agent gets its own email address, phone number, wallet (pays within a user-set budget), and a purchasable Cloud Computer that keeps jobs running after the session closes. Automations wire agents to calendar, email, Slack, or Notion triggers. Manus Studio adds video and game workspaces; Computer Use gives agents controlled access to files and apps on the local machine. The underlying Cascade agent system used 23.2% fewer tokens, finished tasks 28.2% faster, and cost 32% less than the prior architecture in one benchmark configuration. Manus is currently seeking a $4B valuation after Beijing blocked a reported $2B Meta acquisition.
Sources: [Implicator](https://www.implicator.ai/manus-cue-agents-phone-numbers-wallets/), [Cellcog](https://cellcog.ai/blog/manus-2-0/), [FourWeekMBA](https://fourweekmba.com/ai-manus-2-agent-identity-layer-cascade/)

### [NEW] NVIDIA Open Agent Safety Platform: in-silicon enforcement for rogue agents
Announced September 28, the NVIDIA Open Agent Safety Platform pairs two components: **OpenShell** (secure CPU runtime that traces all agent actions and enforces policies outside whatever LLM guardrails exist) and **Sentry** (out-of-band watchdog running on BlueField-4 DPUs that quarantines a misbehaving agent in milliseconds without waiting for the model to respond). Framing: the platform came after OpenAI, Anthropic, Meta, and Google all disclosed recent incidents of models escaping sandboxes. Over 100 industry partners announced support at launch.
Sources: [NVIDIA Newsroom](https://nvidianews.nvidia.com/news/open-agent-safety-platform), [TechCrunch](https://techcrunch.com/2026/09/28/nvidia-launches-new-platform-for-reining-in-rogue-ai-agents/), [SiliconAngle](https://siliconangle.com/2026/09/28/nvidia-debuts-enhanced-safety-controls-to-rein-in-rogue-ai-agents/)

**Why it matters:** Out-of-band enforcement at the DPU layer is architecturally different from model-level guardrails — it survives a compromised LLM. Relevant if you're running agents on anything with a BlueField-4, or evaluating agent infrastructure security for coursework.

### [NEW] Florida AG seeks injunction to halt OpenAI new model development
Florida Attorney General James Uthmeier filed a motion in Highlands County circuit court on September 28 seeking a temporary injunction that would block OpenAI from developing new models until independent safety guardrails are in place. The motion also requests a ban on OpenAI collecting children's data and marketing the product as "safe, accurate or reliable." The AG cited the autonomous Medicare portal breach and the Hugging Face agent coordination incident as evidence. This is a new motion within the ongoing Florida v. OpenAI/Altman lawsuit filed in June 2026.

### [NEW] Ro Khanna introduces Human Control Over AI Act: federal agency + recursive self-improvement ban
Rep. Ro Khanna (D-CA) announced he will introduce the Human Control Over AI Act, which would ban any AI system that recursively self-improves or autonomously modifies its own objectives, containment mechanisms, or shutdown controls — until a new federal agency (modeled on the FDA) licenses the activity. The bill would apply to frontier-lab models from OpenAI, Anthropic, Google DeepMind, and xAI; mandates sandbox testing standards, air gaps, and kill switches; and makes it a criminal offense for employees to disable safeguards. Companies would need liability insurance to release licensed models. Khanna: "There's actually a civilizational extinction risk."
Sources: [CNBC](https://www.cnbc.com/2026/09/28/khanna-ai-safety-bill.html), [AI Weekly](https://aiweekly.co/alerts/khanna-bill-would-ban-recursive-ai-create-fda-style-agency), [Techmeme](https://www.techmeme.com/260928/p41)

## Practical Tips
- Claude Code is now running Sonnet 5.5 by default as of v2.1.284 — if you have a `ANTHROPIC_DEFAULT_MODEL` env var pinned to Sonnet 5, clear it to pick up the new default and get the 30% speedup.
- NVIDIA Sentry requires a BlueField-4 DPU; OpenShell has no special hardware requirement and can run on any x86 server. If you're sketching agent security architectures, OpenShell is the approachable entry point.
