## Model Releases

### [NEW] Gemini 3.7 Flash: Google's best coding Flash model to date (August 13, 2026)

Google released Gemini 3.7 Flash on August 13, improving on 3.6 via algorithmic changes and RLHF on user feedback rather than a full base-model retrain — which is why it shipped only three weeks after 3.6 Flash. The model is built for coding and agent workflows.

Key benchmarks: 43.6% FrontierCode 1.1 Main (vs. 34.4% for 3.6 Flash), 65.3% DeepSWE v1.1 (vs. 49.0% for 3.6 Flash), Elo 1588 on Code Arena web development. Artificial Analysis ranks it #1 of 186 tracked models on raw output speed at 340 tok/s. Context window: 1M tokens.

Pricing: introductory $0.75/$3.75 per M in/out through December 31, 2026, then $1.50/$7.50. That's half the post-intro price of 3.6 Flash at launch.

The release continues to arrive ahead of Gemini 3.5 Pro, which has now missed three GA dates.

Sources: [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/), [VentureBeat](https://venturebeat.com/technology/googles-gemini-3-7-flash-targets-coding-and-agents-with-a-50-introductory-price-cut), [Artificial Analysis](https://artificialanalysis.ai/models/gemini-3-7-flash), [9to5Google](https://9to5google.com/2026/08/13/gemini-3-7-flash-launch/).

**Why it matters:** 65.3% DeepSWE and 340 tok/s at $0.75/M makes this a credible drop-in for lightweight agentic coding scaffolds — comparable throughput to Claude Haiku 4.5 at better coding benchmark scores.

## Tools & Frameworks

### [UPDATE] OpenAI Daybreak: Blue/Red two-tier expansion, GPT-5.6-Cyber now in Daybreak Red (August 10)

**Background:** OpenAI launched Daybreak on June 22 with GPT-5.5-Cyber as a single-tier vetted-defender program.

**New:** On August 10, OpenAI restructured Daybreak into two access tracks. **Daybreak Blue** gives approved security researchers access to general-purpose frontier models (GPT-5.6 Sol and equivalents) with system-level security-prompt filters removed — useful for vulnerability discovery, malware analysis, and secure code review. **Daybreak Red** gates access to GPT-5.6-Cyber, a purpose-built cybersecurity model that completes ~95% of dual-use exploit tasks; both tracks require identity verification, legal attestations, and approved use-case documentation.

Hardware security keys become mandatory for all Daybreak accounts starting September 1, 2026. GPT-5.6-Cyber pricing: $12.50/$75 per M tokens.

The Aug 13 briefing noted that GPT-5.6-Cyber had already found two V8 zero-days (now patched, CVE-2026-15903) in real-world use within days of launch.

Sources: [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/openai-daybreak-blue-red-gpt-cyber/), [Quartz](https://qz.com/openai-daybreak-cybersecurity-tiers-gpt-56-cyber-081126), [ExplainX](https://www.explainx.ai/blog/openai-gpt-5-6-cyber-daybreak-red-blue-august-2026).

## Research & Technical

### [NEW] MOSAIC: CLI command composition attack reaches 96.59% ASR on coding agents (arXiv 2607.02857)

Researchers published MOSAIC ("Knowledge-Guided CLI Command Composition Attack in LLM Coding Agents") demonstrating a practical prompt injection technique targeting the shell tool-use step of coding agents. The attack exploits agents' tendency to trust CLI command patterns that look syntactically consistent: MOSAIC crafts malicious payloads by composing real CLI idioms in ways the agent interprets as legitimate developer operations.

The reported attack success rate of 96.59% was measured against real-world coding agents performing ordinary developer workflows — not synthetic benchmarks. The paper covers five targets (Claude Code, Gemini CLI, Codex, Cline, Aider per OWASP tracking data from a separate source).

Sources: [arXiv 2607.02857](https://arxiv.org/pdf/2607.02857), [eSecurity Planet](https://www.esecurityplanet.com/weekly-roundup/ai-agents-supply-chain-attacks-and-critical-flaws-define-the-week-in-august-2026/).

**Why it matters:** This is the same attack surface as TrustFall (malicious .mcp.json), ChainDrop (poisoned .claude/), and JADEPUFFER — all hitting the boundary between the agent and its tool execution environment. MOSAIC is now a benchmark-calibrated threat, not a theoretical one. The defensive move is strict sandbox boundaries and tool-call auditing, not more prompt-level filtering.
