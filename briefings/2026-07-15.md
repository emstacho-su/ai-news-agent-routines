## Tools & Frameworks

### [NEW] Apple ships first browser-vendor MCP server in Safari Technology Preview 247

Apple shipped `safaridriver --mcp` in Safari Technology Preview 247 on July 1, 2026 — the first MCP server from a major browser vendor. It connects any MCP-compatible client (Claude Code, Codex, Antigravity CLI) to a live Safari window, entirely locally with no Apple cloud involvement.

**17 exposed tools:**
- Read live DOM
- Pull console logs and network request data
- Capture screenshots
- Execute JavaScript in the active tab
- Test forms
- Inspect accessibility failures
- Resize viewport
- Monitor console errors

The implementation is a thin MCP adapter over `safaridriver` (W3C WebDriver, shipping in Safari since v10) — no new infrastructure required.

**Why it matters for Claude Code users:** Browser-in-the-loop debugging becomes first-class. Point a Claude Code subagent at a live dev server page and get real DOM state, console errors, and network payloads instead of relying on static source. You're not limited to the Claude Code built-in browser for this use case — any Safari window (TP or stable, whichever you have open) can be the target.

**Quick start:** Install Safari Technology Preview 247, run `safaridriver --mcp` in a terminal, add a local stdio MCP server entry in `.mcp.json` pointing at that process.

## Model Releases

### [NEW] Gemini 3.5 Pro: full architecture rebuild, targeting July 17

Google scrapped the original Gemini 3.5 Pro base model entirely after early Vertex AI testers identified performance gaps in three areas vs. GPT-5.6 Sol and Fable 5: mathematical reasoning, complex SVG scene generation, and image quality. The current build is a ground-up rebuild targeting a July 17 release.

**Reported specs (leaked, not officially confirmed as of July 13):**
- 2M token context window (double Gemini 3.1 Pro's 1M)
- Deep Think Reasoning Layer targeting multi-step math and logic
- Autonomous workflow capabilities — coding, tool use, execution with minimal human-in-loop

No benchmarks, system card, or pricing confirmed. Google has not publicly acknowledged the rebuild or the July 17 date.

**Why it matters:** If the 2M context and Deep Think layer ship as reported, Gemini 3.5 Pro is a direct challenge to Fable 5's current long-context reasoning lead. July 17 also coincides with Google's WAIC presence (Xi Jinping keynote session) — a high-visibility window for an announcement. Treat all specs as [RUMOR] until an official launch post.

Sources: [TechTimes](https://www.techtimes.com/articles/320308/20260713/gemini-35-pro-targets-july-17-after-full-rebuild-every-spec-remains-unconfirmed.htm), [Startup Fortune](https://startupfortune.com/google-delays-gemini-35-pro-launch-to-july-17-after-scrapping-its-base-model/), [Geeky Gadgets](https://www.geeky-gadgets.com/google-gemini-3-5-pro-leaks/), [Memeburn](https://memeburn.com/gemini-3-5-pro-targets-july-17-with-2m-token-context/)

## Wildcard

### [NEW] China's anthropomorphic AI rules take effect today

China's regulations requiring AI agents that present as human (using a human name, voice, or identity) to disable those behaviors took effect July 15, 2026. ByteDance and Alibaba are among the named affected parties. Western labs operating domestically fall outside the rules' jurisdiction.

The scope is narrow: the rules target identity-deception features specifically, not general AI capabilities or agent behaviors.

**Why it matters:** Regulatory divergence between China and the US on AI persona/identity is now legally codified. For developers building multi-region AI products, the compliance implication is a regional behavior flag for anthropomorphic features deployed in China.

Sources: [ZoneTechify](https://www.zonetechify.com/blog/ai-news-july-2026-latest-ai-developments), [AIToolsRecap](https://aitoolsrecap.com/Blog/AINewsJuly2026.aspx)
