### [UPDATE] Fable 5 / Mythos 5 — Day 8: Refund Deadline Today, No Restoration Timeline

**Background:** US Commerce Department export order (June 12) suspended Fable 5 and Mythos 5 globally. Anthropic blocked all users since real-time nationality verification isn't feasible at the API layer. June 15 Washington meeting ended without resolution.

**New:** David Sacks (PCAST co-chair, Trump's AI/crypto czar) published a detailed administration account on June 14: the US government warned Anthropic before the export order that Fable 5 had been jailbroken, and asked Dario Amodei to fix it or voluntarily de-deploy. Dario refused, calling the jailbreak non-serious. The Commerce Department then issued the directive. Anthropic disputes this framing and maintains the underlying capability exists in publicly deployed GPT-5.5 as well. Per a TechTimes report on June 18, Anthropic privately told enterprise customers models would be back "in days" — that claim is now two days old and no restoration has materialized. **Today (June 20) is the last day to claim a prorated refund** if you subscribed to Pro/Max/Team between June 9 and June 14; requests must be submitted by 11:59 PM. No new official restoration date as of this writing.

**Why it matters:** The Sacks account is the clearest government-side narrative yet, and it frames Anthropic as the party that blocked an easy fix. Whether accurate or not, it changes the political dynamic — Anthropic now has to rebut a specific factual claim, not just a vague national-security label.

## Tools & Frameworks

### [UPDATE] Claude Code v2.1.183 (June 19): Auto Mode Blocks Destructive Git

**New:** Auto mode now intercepts `git reset --hard`, `git checkout -- .`, and `git clean -f` before they execute if the user didn't explicitly request discarding local work. The safety classifier pre-screens subagent actions for irreversible git operations before launch — closing the gap where a subagent could wipe uncommitted changes while acting autonomously.

**Why it matters:** Practically useful for any session where you're letting Claude run multi-step agentic tasks. Previously, an agent chaining operations could blow away local changes as a side effect; now it will pause and ask.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)

## Practical Tips

**Fable 5 refund:** If you upgraded Pro/Max/Team between June 9–14, today is your last day. Submit via claude.ai account settings or billing portal. Apple Store subscribers must go through Apple's refund process directly — Anthropic cannot process those.

**Claude Code + git safety:** After upgrading to v2.1.183, double-check that any `.claude/settings.json` permission rules you've set for Bash don't inadvertently override the new safety classifier behavior. The new check is a pre-launch screen on subagent spawning, not a blanket Bash block, so explicit allowlist rules for Bash(*) still work — you'll just see a confirmation prompt on the destructive git variants.
