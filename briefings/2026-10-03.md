## Tools & Frameworks

### [NEW] Claude Mods — TypeScript Function Hooks for Claude Code (v2.1.287)

Claude Code v2.1.287 ships **Claude Mods**, a plugin system built on TypeScript Function Hooks that lets developers intercept tool calls, modify UI components, and extend CLI behavior like Express-style middleware. Key details:

- Mods are TypeScript modules that hook into pre/post tool-call events; they can modify inputs, short-circuit execution, or add entirely new UI panes.
- Admin-controlled side effects and scoped execution keep mod behavior auditable.
- Distributed through the claude.ai plugin directory (GA'd last week for MCP connectors); mods follow the same submission process.
- Also in v2.1.287: MCP servers on the 2025-11-25 protocol can now raise URL prompts (sign-in flows), fixed a bug where `mcp_tool` hooks on blocking PreToolUse events were skipped while MCP server was still connecting, and fixed duplicate MCP server connections when case/port/slash variants matched the same host.

**Why it matters:** Claude Mods is the answer to "I want Claude Code to behave differently in my specific repo without forking the CLI." TypeScript middleware is a familiar pattern for devs — lower barrier than writing full plugins. Sources: [ccleaks.com](https://ccleaks.com/news/claude-code-2-1-287-oct-2026), [Anthropic blog](https://claude.com/blog/claude-code-plugins), [Hermes AI](https://hermes-ai.net/news/anthropic-wants-claude-code-to-run-typescript-middleware-like-express/).

## Practical Tips

- **Claude for Government early access:** Claude Code CLI for government is in early access — if you have a .gov or .mil adjacent project, the procurement path is now formal.
- **Claude Mods dev setup:** The mod system uses the same TypeScript SDK already used for Claude Code plugins. If you've written a plugin before, porting to a mod hook is a function export change, not a rewrite. Check `claude.com/blog/claude-code-plugins` for the updated spec.
- **GPT-6.1 Sol cost calc:** At $2/$10 per M tokens with $0.10/M cached reads, GPT-6.1 Sol is cost-competitive with Claude Sonnet 5.5. Worth benchmarking on your specific workloads if you're vendor-neutral.
