## Anthropic

### [NEW] Anthropic forms $200M, four-year partnership with the Gates Foundation
Anthropic and the Gates Foundation announced a $200 million commitment on May 14 covering grant funding, Claude usage credits, and technical support across four years. The three verticals: global health (vaccine/therapy acceleration, overlooked-disease research starting with polio and HPV), education (AI tutoring and foundational literacy tools in sub-Saharan Africa and India), and economic mobility (agriculture-specific Claude improvements and public-good crop datasets for smallholder farmers). Anthropic is explicitly framing this as the "markets alone won't get here" investment. [Anthropic blog](https://www.anthropic.com/news/gates-foundation-partnership), [Gates Foundation press release](https://www.gatesfoundation.org/ideas/media-center/press-releases/2026/05/ai-anthropic-partnership).

**Why it matters:** Low direct relevance to Stack's dev work, but Anthropic is deliberately building a non-commercial use-case portfolio ahead of the IPO window. Watch whether the health/ag benchmarks they produce become public evals — those would be novel capability proxies.

## Tools & Frameworks

### [UPDATE] Claude Code v2.1.142-143: dispatch flags for background sessions, plugin dependency graph
v2.1.142 (May 14) adds eight flags to configure dispatched background sessions at invocation time: `--add-dir`, `--settings`, `--mcp-config`, `--plugin-dir`, `--permission-mode`, `--model`, `--effort`, and `--dangerously-skip-permissions`. v2.1.143 (May 15) ships plugin dependency enforcement — `claude plugin disable` now refuses when another enabled plugin depends on the target and prints a copy-pasteable disable-chain hint; `claude plugin enable` force-enables transitive dependencies automatically. Also new in .143: `worktree.bgIsolation: "none"` to allow background sessions to edit the working copy directly for repos where worktrees are impractical; per-turn and per-invocation projected context cost visible in the `/plugin marketplace` browse pane. [GitHub releases](https://github.com/anthropics/claude-code/releases), [Claudefa.st changelog](https://claudefa.st/blog/guide/changelog).

**Why it matters:** The `--mcp-config` and `--settings` dispatch flags are directly relevant to the Routines build — they let each background session receive its own MCP server config at dispatch time without writing per-session settings files manually. `worktree.bgIsolation: "none"` is also the right escape hatch for repos that break under worktree isolation.

### [NEW] OpenAI Codex: mobile launch, persistent memory, web browsing, 90+ plugins
On May 14-15, OpenAI shipped a large Codex expansion. Codex is now available inside the ChatGPT iOS/Android app across all plans including Free, with a mobile interface for monitoring running tasks and approving pending commands without returning to a desk. Also shipping: a persistent memory preview (stores preferences, corrections, and gathered context across sessions), an in-app browser where users can annotate web pages to give the agent precise instructions, and 90+ additional plugins combining skills, app integrations, and MCP servers. GPT-5.5 rolling out to Codex sessions simultaneously. [TechCrunch](https://techcrunch.com/2026/05/14/openai-says-codex-is-coming-to-your-phone/), [OpenAI blog](https://openai.com/index/work-with-codex-from-anywhere/), [OpenAI "codex for almost everything"](https://openai.com/index/codex-for-almost-everything/).

## Model Releases

### [NEW] Mistral Medium 3.5: 128B open-weights, 77.6% SWE-bench, Work mode in Le Chat
Mistral released Medium 3.5 on April 29 / May 3 — a 128B dense model with a 256K context window under a modified MIT open-weights license. Benchmark: 77.6% SWE-bench Verified, ahead of Devstral 2 and Qwen3.5 397B A17B. The release ships simultaneously with remote cloud coding agents in Mistral Vibe and a new Work mode in Le Chat, both powered by the same checkpoint. Work mode runs multi-step agentic tasks with parallel tool calls across email, calendar, docs, Jira, and Slack, with explicit tool-call visibility and approval gates before sensitive actions. [Mistral blog](https://mistral.ai/news/vibe-remote-agents-mistral-medium-3-5), [Hugging Face model card](https://huggingface.co/mistralai/Mistral-Medium-3.5-128B).

## Wildcard

### [NEW] Five Eyes joint guidance: "Careful Adoption of Agentic AI Services"
On May 1, CISA, NSA, and their counterparts from Australia (ASD ACSC), Canada, New Zealand, and the UK published the first coordinated multi-government security guidance targeting agentic AI specifically. Core message: "Until security practices, evaluation methods and standards mature, organisations should assume that agentic AI systems may behave unexpectedly." The document enumerates five risk categories — privilege, design/configuration, behavioral, structural, and supply-chain — and recommends starting with clearly defined low-risk tasks, incremental expansion, explicit accountability, and continuous evaluation against an evolving threat model. [The Register](https://www.theregister.com/2026/05/04/five_eyes_agentic_ai_recommendations/), [CyberScoop](https://cyberscoop.com/cisa-nsa-five-eyes-guidance-secure-deployment-ai-agents/).

**Why it matters:** The five risk categories map directly onto systems Stack builds — the supply-chain and privilege categories specifically call out MCP server registries, directly echoing TrustFall and the Mitiga OAuth hijack findings in recent briefings. The guidance is non-binding but signals baseline expectations are hardening fast.
