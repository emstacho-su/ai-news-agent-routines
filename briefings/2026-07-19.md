## Tools & Frameworks

### [UPDATE] Claude Code: July 18 Permission-Bypass Security Fixes

The July 18, 2026 Claude Code release is a security-focused patch that closes a chain of permission-check vulnerabilities:

**Background:** Claude Code's allow/deny rules are the permission layer that stops auto mode from running destructive commands.

**New:** Multiple bypass vectors patched in this release:
- `dir/**` allow rules (e.g., `Edit(src/**)`) were auto-approving writes to *any* nested path in the tree, not just within the configured directory.
- Commands in Windows PowerShell 5.1 sessions could bypass permission checks entirely.
- Bash permission analyzer failed closed on file-descriptor redirect forms that bash parses differently.
- Commands over 10,000 characters now always prompt instead of running automatically (previous blind spot).
- zsh variable subscripts and modifiers in `[[ ]]` comparisons were treated as inert text, allowing bypass.
- Certain `help` and `man` invocations with unsafe options or command substitutions were auto-approved.

The update emphasizes fail-closed behavior throughout: ambiguous constructs now prompt rather than assume safe.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot Claude Code](https://releasebot.io/updates/anthropic/claude-code)

**Why it matters:** If you use auto mode or have deny rules in your project settings, update before your next session. The dir/** bug is particularly broad — any `Edit(path/**)` allow rule was effectively unrestricted.

## Model Releases

### [NEW] Kimi K3: 2.8T MoE, #1 on Frontend Code Arena

Moonshot AI released Kimi K3 on July 16, 2026. At 2.8 trillion parameters (Mixture-of-Experts architecture), it is the largest open-track model release to date. Kimi K3 debuted at #1 on Arena.ai's Frontend Code Arena with a 76% pairwise win rate, edging out Claude Fable 5.

**Why it matters:** 76% pairwise win rate on frontend code generation is a meaningful gap. If you're scaffolding frontends via LLM, worth a benchmark against your current stack; the open-track release also means self-hosted options.
