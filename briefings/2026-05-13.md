## Tools & Frameworks

### [UPDATE] Claude Code v2.1.140: Agent Subtype Matching, Background Service Fixes
v2.1.140 shipped today. Headline changes: the `Agent` tool `subagent_type` parameter now accepts case- and separator-insensitive values, so `"Code Reviewer"` automatically resolves to `code-reviewer` without a runtime error; background service startup now waits longer on machines with enterprise endpoint security that slow process initialization; and a settings hot-reload regression is fixed where symlinked settings files caused spurious `ConfigChange` hook events. [ClaudeWorld](https://claude-world.com/articles/claude-code-21140-release/), [GitHub Releases](https://github.com/anthropics/claude-code/releases).

**Background:** v2.1.139 (yesterday) introduced the `/goal` command and `claude agents` dashboard; v2.1.140 is a targeted DX and stability patch on top of those features.

## Research & Technical

### [NEW] Agent Memory Survey: Storage → Reflection → Experience Ladder (arXiv:2605.06716)
A May 7 arXiv paper ("From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms") formalizes three evolutionary stages of agent memory: (1) **Storage** — raw trajectory preservation and retrieval; (2) **Reflection** — trajectory critique and refinement (e.g., Reflexion-style self-critique loops); (3) **Experience** — trajectory abstraction into generalized policies and playbooks. [arXiv](https://arxiv.org/abs/2605.06716). The framing maps cleanly onto Anthropic's "dreaming" feature (announced May 6), which runs a scheduled Experience-stage pipeline across past agent sessions.

**Why it matters:** If you are building an agent that persists across runs — a trading bot, a research agent, anything stateful — this taxonomy gives concrete vocabulary for where your memory system sits and what the next upgrade looks like.
