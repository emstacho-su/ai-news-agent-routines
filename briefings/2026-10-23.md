## Anthropic

### [NEW] Claude Duet: Proactive Agent App in Research Preview

Anthropic launched Claude Duet on October 21 as a research preview for US Pro and Max subscribers (waitlist). It runs as a separate app — distinct from claude.ai — powered by Opus 5.5 with its own virtual machine and browser. Duet connects to email and calendar, sends a morning brief on high-priority items, checks connected apps every few hours, and alerts on anything that needs attention. It asks for sign-off before consequential actions (sending messages, payments, signing documents, deleting files). Anthropic acknowledges it can misjudge urgency. Team and Enterprise plans are not yet included; background tasks count against plan usage limits.

**Why it matters:** Duet is Anthropic's entry into the proactive/ambient agent tier (competing with Meta Muse and OpenAI Dots). The Opus 5.5 runtime + sandboxed VM model is worth watching — it's the architecture pattern for trust-boundaried personal agents. If you're building anything in that space, the approval-gating design is notable.

## Tools & Frameworks

### [NEW] Walmart Agent Gateway: MCP Server for Shopping Agents

Walmart announced the Agent Gateway (Oct 21) — an MCP server that lets approved AI agents connect to Walmart.com and Sam's Club programmatically, replacing the current pattern of agents navigating the site like a human browser. In beta for developers and companies. A paired "Agent Profile" feature (rolling out next month) lets customers link an agent to their Walmart account, set a per-agent spending limit, require per-purchase approval, and view a full purchase log. Prices are identical to what a human sees on Walmart.com. Amazon is taking the opposite approach and has begun blocking AI agents from purchases.

**Why it matters:** Walmart's MCP-first bet signals that the major retail platform wars are now partly about agent API surface. Contrast with Amazon's block: this fractures the agent-commerce space early, and any agent you build that touches shopping needs a vendor-specific strategy.

## Research & Technical

### [NEW] Storm-0940 Used ARTEX AI Pentest Framework to Hit 2,250+ Tenants

Microsoft disclosed (Oct 21) that Storm-0940, a China-state-aligned threat group, used ARTEX — an open-source AI-powered penetration-testing framework — to automate attacks starting in September 2026. ARTEX can plug in any AI model to run autonomous recon and data exfiltration tasks. The campaign reached 2,250+ Microsoft 365 tenants at 2,900 sign-in attempts per minute via a ConnectWise supply-chain compromise. Most targeting failed, but in successful cases Microsoft says the group achieved privileged cloud persistence; secondary reporting claims initial access to privilege in under three hours in some incidents (unverified against Microsoft's primary blog). Sectors hit: aerospace, defense, energy, financial services, government, semiconductors. Beijing denied.

**Why it matters:** ARTEX is open-source. This is the best-documented example yet of a nation-state actor operationalizing a public AI pentest tool at scale — what was a red-team exercise is now an active threat pattern.

Sources: [FourWeekMBA/Reuters summary](https://fourweekmba.com/ai-microsoft-discloses-ai-run-attack-that-reached-2250-tenants/), [CyberScoop](https://cyberscoop.com/?p=91224)

## Wildcard

### [UPDATE] Major Banks Expand AI Agent Risk Management (Morgan Stanley, BofA Added)

**Background:** JPMorgan (Dimon, Oct 13 earnings) and Schwab (Wurster) had already stated they were blocking outside AI agents from customer accounts, with Schwab building MCP servers as an authenticated access layer.

**New:** Axios (Oct 23) reports Morgan Stanley and Bank of America are now publicly named as grappling with the same issue — how to attribute account actions to a customer vs. an agent acting beyond authorization. The core problem remains unchanged: there is no US legal or regulatory liability framework for third-party AI agent account access, and Congress is still debating it.

Sources: [The Neuron digest](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-friday-october-23-2026/)
