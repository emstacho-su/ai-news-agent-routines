### [UPDATE] A2A protocol joins Linux Foundation's Agentic AI Foundation (AAIF)

Google's Agent-to-Agent (A2A) protocol formally joined the Linux Foundation-directed Agentic AI Foundation (AAIF) on August 20. AAIF now counts 250+ members — including AWS, Anthropic, Block, Bloomberg, Cloudflare, Google, Microsoft, and OpenAI — making it the broadest multi-vendor alignment on agentic AI interoperability to date.

**Background:** A2A v1.0 reached GA in June 2026 as Google's counterpart to MCP, focused on agent-to-agent task delegation rather than tool/resource access.

**New:** The Linux Foundation hosting move shifts A2A governance from Google-controlled to neutral-foundation territory — the same move that normalized OpenAPI and Kubernetes. With Anthropic and Microsoft both in the member list, cross-lab agent interop via A2A alongside MCP is now an official industry stance.

**Why it matters:** If you're building multi-agent pipelines, the "MCP or A2A?" question is increasingly becoming "both" — the protocol stack is converging, not forking.

Sources: [DEV Community — Agentic AI Standards 2026](https://dev.to/alexmercedcoder/the-state-of-agentic-ai-standards-in-2026-mcp-a2a-webmcp-osi-and-the-protocol-stack-taking-3o2l), [AAIF — MCP Is Growing Up](https://aaif.io/blog/mcp-is-growing-up), [AI Agents News Week of Aug 24](https://aiagentstore.ai/ai-agent-news/this-week)

### [NEW] AWS Bedrock AgentCore Web Search reaches general availability

AWS pushed Web Search on Amazon Bedrock AgentCore to GA on August 21. It's a managed server-side tool that lets agents retrieve live, cited web results without data leaving the customer's AWS account — no external API keys, no third-party forwarding, IAM-scoped per agent.

**Why it matters:** For agents deployed on AWS, this eliminates self-hosting a search backend or forwarding queries externally. IAM scoping means you can permit/deny web search per agent without touching application code.

Sources: [AI Agents News Week of Aug 24](https://aiagentstore.ai/ai-agent-news/this-week), [Agentic AI News August 2026](https://agentic.ai/news)

### [UPDATE] MCP ecosystem: 400M monthly downloads; roadmap shifts to agent identity and progressive discovery

As of late August 2026, monthly MCP SDK downloads crossed 400M — a 4× jump from the ~97M figure at the July 28 spec ship. TypeScript and Python SDKs have each crossed 1B total downloads. The updated roadmap published August 22–23 names the next priorities: **agent identity** (how agents authenticate and prove who they are across multi-hop chains), **progressive discovery** (agents enumerate server capabilities at runtime rather than at connect time), and expanded **HTTP transport options** beyond the current WebSocket baseline.

**Background:** The 2026-07-28 spec finalized July 28, dropping the stateful handshake for a stateless core that runs cleanly on serverless and edge infrastructure.

Sources: [MCP Roadmap blog](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/), [Google Developers on MCP stateless](https://developers.googleblog.com/scaling-ai-agent-infrastructure-with-the-mcp-stateless-updates/), [Toloka on MCP future](https://toloka.ai/blog/the-future-of-mcp-enterprise-adoption/)

### [NEW] Grok Build v1.0 open source (Apache 2.0)

xAI's Grok Build reached v1.0 on August 7 and open-sourced under Apache 2.0. It's a terminal-based coding agent in the same tier as Claude Code — reads codebases, edits files, runs commands, spawns up to 8 subagents in isolated git worktrees. Runtime requires SuperGrok or X Premium+; the Apache license covers the client source, not API access. Entered AI dev tool power rankings this week per LogRocket's August 2026 analysis.

Sources: [explainx.ai — Grok Build open source](https://explainx.ai/blog/grok-build-open-source-spacexai-july-2026), [AlphaMatch — xAI Opens the Gates](https://www.alphamatch.ai/blog/xai-grok-build-open-source-2026), [LogRocket AI dev tool rankings Aug 2026](https://blog.logrocket.com/ai-dev-tool-power-rankings/)

### [NEW] Visual Studio 2026 August update: per-model thinking-effort controls

Microsoft shipped the Visual Studio 2026 August update, adding thinking-effort controls (low / medium / high) for supported AI models directly in the IDE — developers choose reasoning depth based on task complexity and token budget without modifying prompts or API calls. The update also expands broader AI model integration and improves performance on large solutions.

## Practical Tips

- **ANTHROPIC_DEFAULT_MODEL** (Claude Code v2.1.236+): set this env var in your shell profile to lock the startup model for new Claude Code sessions. `/model` still overrides per-session. Useful if you want a cheap-fast default (Sonnet 5) for exploration and dial up to Fable 5 explicitly for deep tasks.

- **MCP elicitation form in fullscreen** (Claude Code v2.1.238, Aug 22): forms that previously clipped in fullscreen mode now fit the viewport with Accept/Decline always visible. Remote MCP servers also auto-reconnect after transient 5xx errors instead of staying in a failed state for the rest of the session.
