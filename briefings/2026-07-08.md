## Anthropic

### [UPDATE] Fable 5 grace period extended 5 days — new cutover is July 12

**Background:** July 7 was announced as the last day Fable 5 would be included in Pro/Max/Team subscription limits. The July 7 briefing treated today (July 8) as the first day usage credits would be required.

**New:** Anthropic quietly extended the grace period. Fable 5 remains included at up to 50% of weekly subscription limits through **July 12** — no action required. After July 12, usage credits apply at $10/1M input, $50/1M output (enable at claude.ai → Settings → Usage). Single agentic coding session burning 2M output tokens = $100 in credits vs. $50 on Opus 4.8 or $20 on Sonnet 5 (promo pricing). Anthropic has confirmed the move to credits is not permanent; it returns to subscription plans once compute capacity scales.

Sources: [Fable5.app](https://fable5.app/fable-5-usage-limits/), [Android Authority](https://www.androidauthority.com/anthropic-claude-fable-5-credits-usage-july-3684840/), [Codersera](https://codersera.com/blog/claude-fable-5-usage-credits-july-2026/amp/).

**Why it matters:** If you have Routines or background Claude Code agents explicitly targeting Fable 5, you now have until end of day July 12 to set up credits — not today. Plan accordingly before the real cutover.

### [NEW] Claude Cowork launches on web and mobile

Claude Cowork — the agentic workspace product where Claude operates alongside you in long-running sessions with persistent context — is now available on web and mobile in addition to the existing desktop app. The expansion also ships Microsoft 365 write tools: email drafting, calendar management, and OneDrive/SharePoint file creation from within a Cowork session. Rollout is staged, starting with Max plan users over the coming weeks.

Sources: [TechCrunch](https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/).

**Why it matters:** Desktop-only was a real barrier for Cowork adoption on mobile-first teams. The M365 write-tool integration is interesting for the enterprise workflow pitch — but the real signal is that Anthropic is positioning Cowork as a general office-AI competitor to Copilot, not just a developer tool.

### [NEW] Claude for Government Desktop enters public beta

Claude Code and Claude Cowork are now available in public beta under **Claude for Government Desktop**, delivered through a FedRAMP High authorized environment. This is Anthropic's first FedRAMP High offering covering both the coding agent and the workspace product simultaneously, targeting US government contractors and federal agencies whose compliance requirements previously blocked access.

Sources: [Anthropic newsroom](https://www.anthropic.com/news), [Releasebot](https://releasebot.io/updates/anthropic).

### [UPDATE] Claude Code v2.1.202–204: Auto Mode is now opt-in

Three releases shipped in two days:

**v2.1.202 (July 6):** "Dynamic workflow size" setting in /config (controls ultracode agent fleet size); fixed Ctrl+R history search crashes; fixed background session stalling on macOS (false low-memory detection causing 15–20 second delays); fixed context-usage indicator regressions.

**v2.1.203 (July 7):** The big one — **Claude Code now defaults to human approval (Manual mode); Auto Mode requires explicit opt-in**. Previously, whether you got auto-approval depended on your last session state. Now every new session opens in Manual unless you set it explicitly. Also: login-expiry warning before background sessions are interrupted (prevents silent agent death); VS Code remote control toggle added in Settings; agent session status display fixed (completed rows no longer flip to "Needs your input").

**v2.1.204 (July 8):** Fixed hook events not streaming during SessionStart hooks in headless sessions — relevant to this repo, which uses SessionStart hooks for environment setup.

Sources: [GitHub Releases](https://github.com/anthropics/claude-code/releases), [Releasebot](https://releasebot.io/updates/anthropic/claude-code), [TechTimes July 7](https://www.techtimes.com/articles/319874/20260707/claude-code-defaults-human-approval-auto-mode-requires-explicit-opt.htm).

**Why it matters:** The Auto Mode change is the most consequential for agentic workflows. If you have a background agent or Routine relying on Claude Code's auto-approval behavior, it will now pause at the first tool-use permission prompt after updating. Add `--permission-mode auto` or set the appropriate defaultMode in settings.json before updating to preserve prior behavior. The SessionStart hook fix (v2.1.204) directly addresses this Routine's environment.

## Tools & Frameworks

### [NEW] Microsoft deploying MAI to replace OpenAI and Anthropic in some consumer apps

Bloomberg reported on July 7 that Microsoft is actively replacing OpenAI and Anthropic models with its in-house MAI model (previously Project Polaris, first described at Build 2026) in a subset of consumer-facing applications. The report doesn't specify which apps have already switched, but the direction is consistent with Microsoft's stated goal of reducing dependency on external model providers for cost and control reasons. MAI-Thinking-1 (the reasoning counterpart, 35B active / ~1T total sparse MoE) has benchmarks comparable to Claude Sonnet 4.6 on coding tasks and was co-designed with Maia 200 silicon.

Source: [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-07/microsoft-replaces-openai-anthropic-with-own-ai-in-some-apps).

**Why it matters:** Combined with the June 30 cutover where Microsoft's Experiences+Devices org moved from Claude Code to Copilot CLI, this is a consistent pattern: Microsoft is routing workloads toward its own stack wherever MAI has reached threshold capability. Not yet at frontier level, but the gap is narrowing.

### [UPDATE] GPT-5.6 Sol/Terra/Luna: METR risk flag, ~80% GA odds by July 10

**Background:** GPT-5.6 launched in limited preview June 26 as a three-tier family (Sol / Terra / Luna) restricted to ~20 vetted orgs after White House review. No GA date was set.

## Practical tips

- **Before July 12:** Enable usage credits at claude.ai → Settings → Usage if you want Fable 5 access after the grace period. Set a monthly cap to avoid bill shock — a $200/month cap buys roughly 4M output tokens on Fable 5.
- **Claude Code update caution:** After updating to v2.1.203+, verify your permission mode. Run `/config` and check `defaultMode`. Background agents and Routines that relied on auto-approval will block on first tool-use without explicit opt-in.
- **SessionStart hook fix:** The v2.1.204 fix means SessionStart hook events now stream correctly in headless mode — if you were seeing silent hook failures in this Routine, updating should resolve it.
- **GPT-5.6 Sol pricing:** At $5/$30 per Mtok, Sol undercuts Fable 5 by ~50% at the API layer. Worth watching for coding benchmarks against Sonnet 5 (promo at $2/$10) when GA lands this week.
