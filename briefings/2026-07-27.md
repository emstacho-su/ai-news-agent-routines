## Model Releases

### [NEW] Kimi K3 open weights: 2.8T sparse MoE, largest open-weight release in history
Moonshot AI shipped full weights at approximately 00:00 UTC July 27. The model was initially planned for a July 27 drop but released a few hours early. Specs:

- **2.8 trillion total parameters**, 896 experts, 16 active per token → **~50B effective compute per token** (mid-size model inference profile despite the 2.8T headline)
- **1M token context window** via Kimi Delta Attention (KDA) — a hybrid linear-attention mechanism designed to keep ultra-long sequences tractable without standard attention's quadratic cost
- **~1.4TB MXFP4** — full weight pack, serious storage requirement for self-hosting
- **Day-0 inference** available on Together AI and Modal without waiting

On FrontierBench v0.1, Claude Opus 5 leads at 43.3% vs. Kimi K3's independently reported position — confirming K3 is frontier-competitive but not the new top benchmark. Sources: [Interconnects](https://www.interconnects.ai/p/kimi-k3-the-open-weights-escalation), [Eigent](https://www.eigent.ai/blog/kimi-k3-open-weight-frontier-model), [TECHi](https://www.techi.com/kimi-k3-open-weights-inference-economics/), [Startup Fortune](https://startupfortune.com/moonshot-ai-releases-kimi-k3-open-weights-making-the-worlds-largest-open-weight-model-free-to-download/)

**Why it matters:** The 50B-active-parameter effective compute is the key number — you're not actually running a 2.8T model per forward pass. KDA hybrid attention for 1M-token codebases is worth watching. Self-hosting a 2.8T MoE at 1.4TB eliminates data-sovereignty concerns you'd have with the API (Chinese lab origin).

## Tools & Frameworks

### [UPDATE] MCP spec 2026-07-28 ships tomorrow
The 10-week Tier-1 SDK validation window that started May 21 closes tomorrow. What locks in:

- **Fully stateless protocol core** — Mcp-Session-Id header gone; initialize/initialized handshake removed
- **Per-request capability delivery** — server capabilities travel in `_meta` on every request via new `server/discover` method
- **Routing headers** `Mcp-Method` and `Mcp-Name` for gateway routing without JSON parsing
- **JSON Schema 2020-12** for tool inputs — `oneOf`, `anyOf`, `allOf`, `$ref`, conditionals formally supported
- **Tasks API rebuilt** for stateless operation — server returns task handle from `tools/call`; client drives via `tasks/get`, `tasks/update`, `tasks/cancel`
- **Roots/Sampling/Logging deprecated** with 12-month removal runway

All three Tier-1 SDKs (Python, TypeScript, Go) have beta builds. GitHub's MCP server shipped 2026-07-28 stateless support July 23. Sources: [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [MCP SDK Beta post](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/), [GitHub Changelog](https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/), [SecurityWeek](https://www.securityweek.com/new-enterprise-ready-mcp-specification-brings-new-security-challenges/)

## Research & Technical

### [NEW] Anthropic J-lens: ~25-concept global workspace inside Claude mirrors neuroscience theory
Published July 6-12, 2026. Paper and open-source repo `anthropics/jacobian-lens` (Apache-2.0).

The Jacobian lens computes, for each vocabulary token, the average future-output effect of a given internal activation pattern. Running J-lens across Claude's internals revealed **J-space** — a small subspace with approximately 25 active concepts — that behaves structurally like the broadcast "spotlight" in **Global Neuronal Workspace Theory**: dozens of specialized processors work in parallel, but only a narrow J-space subspace gets broadcast to the whole model.

The authors explicitly take **no position on phenomenal/subjective consciousness** — this is a functional analogy, not a consciousness claim. The paper supports: Claude may have a functional analog of conscious access for a small, coherent set of internal states. Sources: [Anthropic Research](https://www.anthropic.com/research/global-workspace), [VentureBeat](https://venturebeat.com/technology/anthropics-new-j-lens-reveals-a-silent-workspace-inside-claude-that-mirrors-a-leading-theory-of-consciousness), [Forbes](https://www.forbes.com/sites/johnwerner/2026/07/12/anthropic-illuminates-llm-j-space-with-j-lens/)

**Why it matters:** J-lens is a practical mechanistic interpretability tool — the open-source implementation lets you probe concept geometry in any Transformer architecture. If you're doing interpretability work or building alignment tooling, this is a production-usable method.
