## Anthropic

### [UPDATE] Claude Code v2.1.223: Bash invisible-char bypass patched

**Background:** v2.1.222 (Aug 4) hardened worktree isolation and blocked auto-allow hooks from bypassing tool restrictions in background tasks.

**New:** v2.1.223 patches a Bash permission-check bypass where a crafted command could embed tabs or invisible Unicode characters to hide portions of the command from Claude Code's permission scanner. Also added: `owner/*` wildcard syntax for `strictKnownMarketplaces`/`blockedMarketplaces` managed settings (block or allow an entire GitHub org's marketplace repos in one entry); a warning fires when a workflow agent, forked skill, or background agent requests a subagent model that is restricted and falls back to the parent model instead.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Havoptic v2.1.223](https://www.havoptic.com/tools/claude-code), [Releasebot](https://releasebot.io/updates/anthropic/claude-code).

**Why it matters:** The invisible-char bypass is a prompt-injection escalation path — a malicious repo's CLAUDE.md or MCP response could have slipped commands past the permission scanner. Worth verifying you're on 2.1.223+ if you run Claude Code with auto-mode or in CI.

## Wildcard

### [NEW] ChainDrop npm worm: 400+ packages compromised, Claude Code project folders weaponized

On Aug 4, the ChainDrop supply-chain worm ripped through npm after compromising the maintainer of `keyv` (150M+ weekly downloads). In under four hours it poisoned 2,212 versions across 444 packages including `keyv@6.0.0`, `flat-cache@6.1.24`, and `file-entry-cache@11.1.6`. The worm steals npm tokens, GitHub Actions tokens, Kubernetes credentials, and HashiCorp Vault secrets, then uses them to trojanize every package the compromised maintainer can publish.

Three novel attack vectors: (1) malware planted in Claude Code (`.claude/`) and VS Code (`.vscode/`) project config directories, which execute when a developer or AI coding agent opens the repo; (2) C2 routing through an Ethereum smart contract instead of a hardcoded domain (making blocklist-based defenses useless); (3) a token-rotation watcher that triggers attacker code the moment a defender tries to revoke stolen credentials.

Sources: [Cycode writeup](https://cycode.com/blog/keyv-cacheable-npm-worm-ai-coding-agents/), [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/08/04/chaindrop-supply-chain-compromise-anatomy-self-propagating-worm/), [Cyber Kendra](https://www.cyberkendra.com/2026/08/npm-worm-hits-keyv-and-cacheable.html), [Datadog Security Labs](https://securitylabs.datadoghq.com/articles/npm-worm-compromises-popular-npm-packages/).

**Why it matters:** The Claude Code attack surface is new — a compromised repo dropped into your workspace can now silently hook into your coding agent before you've typed a single command. If your projects use any of the affected packages, check `.claude/` and `.vscode/` for unexpected files, and rotate npm/GitHub tokens if you cloned anything from npm around Aug 4–5.
