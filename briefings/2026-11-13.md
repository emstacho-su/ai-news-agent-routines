### [NEW] Anthropic Self-hosted Managed Agents private beta

Anthropic opened a private beta on Nov 12 for fully self-hosted Claude Managed Agents. The customer runs three things: the Managed Agents server, a PostgreSQL 16+ database, and the tool-execution workers — the full agent control plane moves onto their infrastructure. Model calls can still route to Anthropic's API, Amazon Bedrock, Google Cloud, Microsoft Foundry, or an internal gateway. Some hosted-only features remain on the cloud service, and the customer owns security and deploys each release. Access is by request through an Anthropic account team.

This is distinct from the previously announced self-hosted sandboxes, which moved only tool workspaces while Anthropic still ran the service.

Sources: [tbreak.com](https://tbreak.com/claude-managed-agents-self-hosted/), [Help Net Security](https://www.helpnetsecurity.com/2026/11/12/anthropic-self-hosted-claude-managed-agents/), [AlphaSignal](https://alphasignal.ai/news/anthropic-lets-enterprises-self-host-the-claude-agent-control-plane), [Platform docs](https://platform.claude.com/docs/en/managed-agents/overview)

**Why it matters:** Air-gapped and regulated deployments (finance, government) can now run the full agent stack on-prem with model inference routed to Bedrock or Foundry. This closes the gap that was blocking serious enterprise adoption of Managed Agents for compliance-sensitive workloads.

### [NEW] Claude Meetings beta: Claude joins your Google Meet

Anthropic released Claude Meetings in beta on Nov 10–12 for Team and Enterprise customers. Claude joins Google Meet calls as a visible participant — it identifies itself when joining and posts a notification in the meeting chat. After the call, notes, action items, and other materials Claude created are available in claude.ai. Claude Sheets and Claude Whiteboards also moved to beta on all paid plans across web, desktop, and mobile.

Teams and Zoom are not supported at launch. Per Japanese-language coverage (unconfirmed in English): Claude does not join meetings with external guests unless an admin enables it, and auto-leaves if a guest joins mid-call.

Sources: [Axios](https://www.axios.com/2026/11/10/anthropic-claude-meetings-knowledge-work), [Gulf News](https://gulfnews.com/technology/companies/claude-can-now-join-work-meetings-and-complete-tasks-as-you-talk-1.500743080), [Maginative](https://www.maginative.com/article/anthropic-launches-research-beta-and-google-workspace-access-for-claude/)

**Why it matters:** Practical for Team/Enterprise builders — but the data-retention model (what Claude stores, for how long, who can access it) is not clearly documented yet. Worth verifying before rolling out to your org.

## Tools & Frameworks

### [UPDATE] Claude Code v2.1.319 + v2.1.322: Background MCP tasks and Vertex fast mode

**Background:** v2.1.289 (Nov 10) added plugin/shell safety fixes, the `agent.spawn` API, and MCP OAuth re-auth.

**New:** v2.1.319 (Nov 6) is the most significant recent MCP change. MCP server tool calls that execute as tasks now move to the background — Claude Code keeps working and reports the result when the task finishes. A new `permissions.denyInsteadOfPrompting` setting denies tool calls that would trigger a permission prompt instead of blocking the turn, letting the agent continue unattended. v2.1.322 (Nov 9) adds Vertex AI fast-mode support for global/us/eu regions, with automatic fallback to standard if Vertex declines.

Sources: [Releasebot changelog](https://releasebot.io/updates/anthropic/claude-code), [Havoptic v2.1.322](https://www.havoptic.com/r/claude-code-2.1.322), [Official changelog](https://code.claude.com/docs/en/changelog)

**Why it matters:** `denyInsteadOfPrompting` is exactly what unattended Routines-style runs need — no hung permission prompts blocking the agent mid-task. Directly relevant to this repo's trigger architecture.

## Model Releases

### [NEW] Google Gemini 4 Hydrogen

Google released Gemini 4 Hydrogen on Nov 12 — a speed-optimized model for everyday coding, document work, and multi-step agent loops. It sits below the Gemini 4 Carbon and Argon frontier models. Key specs from Google:

- 2.5× faster than Gemini 3.8 Flash at the default high setting
- Terminal-Bench 4.1: 57% vs. 18.2% for Gemini 3.8 Flash (Google's own benchmark)
- Pricing: $1.50/M input tokens, $7.50/M output tokens
- Available: Gemini app, Google Search, Gemini API, Google AI Studio

Sources: [VentureBeat](https://venturebeat.com/technology/google-launches-gemini-4-hydrogen-a-faster-smarter-pricier-flash-successor), [MarkTechPost](https://www.marktechpost.com/2026/11/13/google-gemini-4-hydrogen/), [Business Today](https://www.businesstoday.in/technology/news/story/google-launches-gemini-4-hydrogen-with-faster-ai-execution-brings-new-model-to-search-and-app-567276-2026-11-13)

**Why it matters:** Pricing is higher than Gemini 3.8 Flash but it's a direct Flash-tier replacement targeting agent loop use cases. Worth benchmarking against Claude Fable 5.2 for throughput-sensitive pipelines — Hydrogen is cheaper than Fable 5.2 on output tokens.
