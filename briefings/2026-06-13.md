## Anthropic

### [UPDATE] Anthropic billing split: June 15 is the day after tomorrow — claim your credit now

**Background:** Effective June 15, 2026, paid Claude plans gain a separate monthly credit for programmatic usage (Agent SDK, `claude -p`, GitHub Actions, approved third-party apps). Pro = $20/mo, Max 5x = $100/mo, Max 20x = $200/mo; metered at full API token rates, no rollover.

**New:** Anthropic is sending claim emails — the credit is not automatically applied; you must actively claim it through your Claude account settings before it resets. A second decision: enable "usage credits" (overflow billing) if you want programmatic requests to continue at API rates once the monthly credit is exhausted, rather than being hard-rejected. Without overflow enabled, Agent SDK calls fail silently once the pool is empty.

**Why it matters:** Stack's v1-routines project runs its briefing routine on Max plan credits. If the routine triggers after June 15 and the credit hasn't been claimed, the API call will hit an empty pool. Claim the credit and validate overflow settings today.

## Model Releases

### [NEW] DiffusionGemma 26B: open-weight text diffusion at 1,000 tokens/sec on consumer GPUs

Google DeepMind released DiffusionGemma on June 10-11, the first major open-source text diffusion language model. Rather than generating tokens one at a time (autoregressive), it iteratively refines 256-token blocks in parallel, achieving ~1,000 tokens/sec on an NVIDIA RTX consumer GPU — roughly 4× faster than an autoregressive Gemma of comparable scale. Architecture: 25.2B total / 3.8B active (MoE). Natively supported in vLLM, Transformers, MLX, and Unsloth; available on Hugging Face (`google/diffusiongemma-26B-A4B-it`) and Google Cloud Model Garden. Apache 2.0. Google explicitly calls it experimental and not production-ready for quality-sensitive tasks — the parallel block approach sacrifices some coherence at long range.

**Why it matters:** Text diffusion as a model class has been an active research bet precisely because it decouples generation speed from model size. If the quality gap closes over the next generation, the implications for inference cost are significant.

Sources: [MarkTechPost](https://www.marktechpost.com/2026/06/10/google-ai-releases-diffusiongemma-a-26b-moe-open-model-using-text-diffusion-for-up-to-4x-faster-generation/), [Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/), [The New Stack](https://thenewstack.io/google-diffusiongemma-text-diffusion/)
