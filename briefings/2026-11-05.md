## Tools & Frameworks

### [UPDATE] Claude Code v2.1.317–318: Agent SDK `onFailure: "block"` and email pre-check

**Background:** Claude Code v2.1.289 (Nov. 2) added agent.spawn API and MCP OAuth re-auth. MCP Tasks and Elicitations shipped Oct. 23 as a narrow public beta.

**New:** Releases 2.1.317 (Nov. 2) and 2.1.318 (Nov. 3) include:
- **`onFailure: "block"`** in Agent SDK hook callbacks — a callback that fails now blocks the guarded action instead of logging silently. Previously the default was continue-on-failure; this gives hooks real enforcement power.
- An account-email check before tools run (privacy guardrail added in 2.1.317).
- `claude auth status` now surfaces sign-in expiry time (2.1.318).

Sources: [Releasebot Anthropic Claude Code updates](https://releasebot.io/updates/anthropic/claude-code), [ClaudeWorld November 2026 changelog](https://claude-world.com/articles/claude-code-november-2026-whats-new/).

**Why it matters:** `onFailure: "block"` is directly relevant to v1-routines defensive agent workflows — hook callbacks that validate payloads or enforce cost limits can now abort the action on failure rather than silently passing through.

## Wildcard

### [NEW] Ohio and 7 states hold 39+ data center ballot measures today

Today's 2026 US midterm election includes at least 39 local ballot measures across 8 states on data center construction restrictions. Ohio accounts for 21 of them — 11 propose outright prohibition, 6 call for zoning changes. Surging electricity bills from rapid Ohio data center expansion are a primary driver of voter concern. A statewide Ohio constitutional amendment was attempted but failed to gather sufficient signatures by July 1 (required 413K+ signatures across 44 counties). Results will be known tonight.

Sources: [Newsweek on Ohio data center measures](https://www.newsweek.com/ohio-has-half-of-us-data-center-ballot-measures-in-midterms-12525098), [ballotpedia.org](https://ballotpedia.org/Ohio_Prohibition_of_Data_Center_Construction_Amendment_(2026)), [Let's Data Science overview](https://letsdatascience.com/news/voters-weigh-39-data-center-measures-across-eight-states-e8675da5).

### [NEW] Google faced backlash for plan to cut Search access in schools requiring AI opt-out; reversed same day

Google announced that K-12 schools using Google's education software suite would need to opt into AI tools to retain access to Search. Educators and privacy advocates pushed back immediately. Google reversed the same day, clarifying that AI products will be off by default for schools — the original announcement implied the opposite. The incident illustrates how bundling AI access with core services is now a live policy flashpoint.

Sources: [TechCrunch](https://techcrunch.com/2026/11/04/google-faces-backlash-for-plan-that-would-turn-off-search-for-schools-that-restrict-ai/).

## Practical tips

- **Claude Code hooks**: with `onFailure: "block"` now available on Agent SDK hook callbacks (v2.1.317+), audit any existing hooks that do cost or quota validation — they can now abort the action instead of just logging. Set `onFailure: "continue"` explicitly on hooks you want to remain non-blocking.
- **OpenAI Images 2.6 API**: the Flare/Sunburst naming convention suggests a standard quality/speed split. If you prototype image generation, $30/M output tokens is 3× the input cost — same asymmetry as before, but check whether the GIF output tier is priced separately before assuming flat rates.
