## Anthropic

### [UPDATE] Fable 5 / Mythos 5 suspension — Day 10: NSA testimony and ID verification path

**Background:** US Commerce Secretary Lutnick issued an export control directive June 12 suspending global access to Fable 5 and Mythos 5 after a reported jailbreak. Anthropic routed all users to Opus 4.8.

**New today:**

- **NSA testimony reshapes the story.** NSA Director Gen. Joshua Rudd disclosed in a Senate Intelligence Committee briefing (publicly surfaced June 21 by Senator Mark Warner) that Mythos — in a classified red-team exercise — autonomously broke into nearly all NSA classified systems within hours. This is categorically different from a user-side jailbreak that can be patched: it means Mythos's autonomous offensive cyber capability is itself the national security concern. The government's position is now harder to negotiate away.

- **Android UI artifact, not restoration.** Fable 5 has reappeared in the model picker on Claude's Android app. This is a UI artifact — the model is not live and requests fail. Do not mistake it for a partial restore.

- **Free trial window expired today.** The June 9-22 promotional period during which Fable 5 was included at no additional cost on Pro/Max/Team has now lapsed. Refund deadline for subscribers who paid between June 9-14 closed June 20.

- **Prediction markets (June 22):** 57% restoration before July 1 on Polymarket.

Sources: [TechTimes (NSA testimony)](https://www.techtimes.com/articles/318783/20260621/claude-fable-5-resurfaces-android-app-nsa-breach-testimony-reshapes-ban.htm), [Polymarket](https://polymarket.com/event/claude-fable-5-restored-for-us-customers-by-20260613193753196), [explainx.ai status](https://explainx.ai/blog/is-fable-5-back-2026)

**Why it matters:** The NSA testimony makes a purely technical resolution (patch + restore) less likely — the government's concern is now about what the model *can inherently do*, not about a specific user exploit.

### [NEW] Anthropic ID verification launches July 8: government-issued ID + facial biometrics via Persona

Anthropic's updated privacy policy (effective July 8, 2026) introduces a new "Verification Data" category. Affected data: government-issued identity document, photo or video of user's face, and facial geometry templates. Third-party processor: Persona. Applies to consumer accounts (Free, Pro, Max) — not to commercial Team, Enterprise, or API customers.

**The inference everyone is making:** With verified US citizenship on file, Anthropic can satisfy the Commerce Dept. directive's "foreign nationals" restriction without waiting for a formal lift. A US-citizens-only Fable 5 restoration path becomes technically feasible the moment Persona's verification pipeline is live. The July 8 date is 2.5 weeks out — consistent with Anthropic MD Chris Ciauri's "very confident, coming days" statement June 21.

The architecture question for API users: Team/Enterprise/API customers are excluded from this verification path. Any restoration for those tiers likely requires a separate government agreement.

Sources: [TechTimes (ID verification)](https://www.techtimes.com/articles/318778/20260621/claude-identity-verification-starts-july-8-what-facial-data-anthropic-collects.htm), [explainx.ai (ID verification)](https://www.explainx.ai/blog/anthropic-claude-id-verification-persona-fable-5-2026), [Cybernews](https://cybernews.com/ai-news/anthropic-privacy-policy-id-verification/)

**Why it matters:** If you're building on the API or Claude Code on Team/Enterprise, this path does not include you. The restoration timeline for API-tier customers is murkier than for consumer subscribers.

## Tools & Frameworks

### [UPDATE] Claude Code Dynamic Workflows: GA on June 10, ultracode keyword

**Background:** Dynamic Workflows launched as a research preview with Claude Opus 4.8 on May 28. The feature orchestrates parallel subagent runs across a codebase.

**New:** Dynamic Workflows reached general availability in Claude Code on June 10, 2026. Activation keyword was renamed from `workflow` to `ultracode` in v2.1.160 (June 2). On Max/Team/Enterprise, Dynamic Workflows are on by default; Pro users enable via `/config`. With `ultracode` active, Claude plans a full multi-agent workflow for every substantive task in the session — including spawning the tool-calling, editing, and validation agents in parallel.

Real-world data point: Jarred Sumner used dynamic workflows to port Bun from Zig to Rust — ~750K lines of Rust, 99.8% of the existing test suite passing, eleven days from first commit to merge.

Sources: [Anthropic blog](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code), [InfoQ](https://www.infoq.com/news/2026/06/dynamic-workflows-claude-code/), [Claude Code Docs](https://code.claude.com/docs/en/workflows)

## Model Releases

### [NEW] GLM-5.2 (Zhipu AI): 744B MoE, 1M context, MIT license — frontier open-weight coding model

Released June 13, 2026. Weights and API both available; weights under MIT license (no usage restrictions, no regional locks).

**Architecture:** 744B total / 40B active parameters (mixture-of-experts), 1M token context window. Same parameter count as the prior GLM generation but context quadrupled. Selectable reasoning modes.

**Benchmarks:** Intelligence Index v4.1 score of 51 — above MiniMax-M3 (44), DeepSeek V4 Pro (44), and Kimi K2.6 (43). On long-horizon coding benchmarks, matches or beats GPT-5.5 at approximately 1/6 the API cost.

**Geopolitical context:** The open-weight MIT release landed on the same day the US export control directive blocked Fable 5 globally. The timing is not coincidental in the way it's being covered — [TechTimes noted the data risk for API users](https://www.techtimes.com/articles/318543/20260617/glm-52-open-weights-live-top-coding-benchmark-api-use-carries-china-data-risk.htm): running weights locally is fine; sending data to z.ai's API routes through Chinese infrastructure.

Sources: [TrendingTopics](https://www.trendingtopics.eu/glm-5-2-chinas-zhipu-ai-beats-even-googles-top-models-with-its-new-open-llm/), [Pandaily](https://pandaily.com/zhipu-ai-glm-5-dot-2-open-source-mit-jun2026), [TechTimes](https://www.techtimes.com/articles/318543/20260617/glm-52-open-weights-live-top-coding-benchmark-api-use-carries-china-data-risk.htm)

**Why it matters:** If you want Fable-5-class coding performance today, self-hosted GLM-5.2 is now the clearest path. The MIT license removes the legal friction that applied to prior competitive open-weight models. API-tier risk: route only non-sensitive tasks to z.ai's hosted endpoint.

## Practical tips

- **On GLM-5.2:** Self-host the weights for anything sensitive; the MIT license clears IP concerns. For API use, treat z.ai as a third-party China-based data processor — know what's in your prompts before sending.
- **On Dynamic Workflows / ultracode:** Running ultracode on a long task will spawn many parallel subagents and burn through programmatic credits fast on the June 15 billing split. Benchmark your task's credit consumption before enabling by default on CI/CD workflows.
- **On Anthropic ID verification:** The July 8 Persona rollout is opt-in for access to Fable 5 (once restored) but may become required for certain features over time. Read the updated privacy policy before July 8 if biometric data sharing is a concern for your org.
