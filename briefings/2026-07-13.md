## Anthropic

### [UPDATE] Claude Code v2.1.207: auto mode now default on Bedrock, Vertex AI, and Foundry

**Background:** Auto mode (ultracode / Dynamic Workflows) has been opt-in on cloud provider deployments via `CLAUDE_CODE_ENABLE_AUTO_MODE=1` since late May.

**New:** v2.1.207 (released July 10–12) removes the opt-in requirement — auto mode is now the default on Bedrock, Vertex AI, and Foundry. The default model on Bedrock and the Claude Platform on AWS is also updated to Claude Opus 4.8. To revert, set `disableAutoMode: true` in settings. Bedrock and Vertex users who want Manual mode need to explicitly configure it.

**Why it matters:** If you're running Claude Code agents on Bedrock or Vertex in production, this is a behavioral change without a forced upgrade notice — subagent spawning and ultracode workflows activate by default on the next session.

Sources: [DevelopersIO](https://dev.classmethod.jp/en/articles/20260711-cc-updates-v2-1-207/), [TheRouter.ai](https://therouter.ai/news/claude-code-auto-mode-bedrock-vertex-foundry-routing/), [TechTimes](https://www.techtimes.com/articles/320233/20260712/claude-code-removes-enterprise-opt-auto-mode-now-default-major-cloud-platforms.htm)

### [NEW] Claude Opus 4.1 API retirement: August 5, 2026

The Claude Developer Platform has announced that Claude Opus 4.1 will be deprecated and retired from the API on August 5, 2026. Access to Fable 5 and Mythos 5 has also been formally restored on the developer platform following the June export-control lift.

**Why it matters:** If you have any hardcoded `claude-opus-4-1` model strings in API calls, they break on August 5. Migrate to Opus 4.8 (or Sonnet 5 for most workloads).

Sources: [Releasebot Anthropic](https://releasebot.io/updates/anthropic/claude-developer-platform), [Releasebot Claude](https://releasebot.io/updates/anthropic/claude)

## Tools & Frameworks

### [NEW] Meta opens Muse Spark 1.1 via Meta Model API (public preview)

Meta launched the Meta Model API in public preview for US developers on July 9, with Muse Spark 1.1 as the first available model. This is Meta's first public model API.

- **Muse Spark 1.1**: multimodal reasoning model, 1M-token context, built for agentic tasks (tool use, computer use, coding, multimodal understanding)
- **Pricing**: $1.25/Mtok input, $4.25/Mtok output; $20 in free credits to start
- **Muse Image** (the consumer image generation product announced July 7 — photo restoration, style transforms, room restyling) is NOT in the API; it runs only inside Meta AI consumer apps with no public API confirmed

**Why it matters:** First time Meta has offered a general-purpose model via API. At $1.25/$4.25 per Mtok, it undercuts Claude Sonnet 5's promotional rate and is a viable third option alongside Anthropic and OpenAI for agentic workloads — worth a benchmark pass.

Sources: [ai.meta.com](https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/), [DataCamp](https://www.datacamp.com/blog/muse-spark-1-1), [Axios](https://www.axios.com/2026/07/07/ai-meta-image-generator)

### [NEW] Z.ai launches ZCode: 62.1% SWE-bench Pro, open-weight

Z.ai (formerly Zhipu AI's international arm) launched ZCode on July 2, 2026. It's an open-weight agentic coding model built on GLM-5.2, scoring 62.1% on SWE-bench Pro — above Fable 5 (80.3%) in proprietary territory but the strongest open-weight result at this benchmark to date.

- Open weights; designed for autonomous multi-step coding agents
- Positioned as "first open-weight frontier agentic coding environment"
- No API pricing announced; model weights available via Hugging Face

Sources: [AIapps July mega-update](https://www.aiapps.com/blog/july-ai-mega-update-major-breakthroughs-launches/)

### [NEW] Kimi K2.7 Code: first open-weight model in GitHub Copilot picker

Moonshot AI's Kimi K2.7 Code is now available in GitHub Copilot's model picker under usage-based billing — making it the first open-weight model to appear in Copilot. Enterprise customers can route Copilot completions to it directly.

**Why it matters:** The Copilot model picker has been closed-ecosystem until now. Open-weight models in the picker changes the distribution calculus for open-source coding models.

## Wildcard

### [NEW] HHS deploys ChatGPT to scan all 50-state federal health-audit reports

The US Department of Health and Human Services announced it will use ChatGPT and other AI tools to analyze annual audit reports from all 50 states, targeting fraud, waste, and abuse in federal health spending (Medicare/Medicaid). This is one of the largest announced government applications of commercial LLMs in the US so far.
