## Anthropic

### [UPDATE] Fable 5 becomes permanent on Max; Pro moves to usage credits
**Background:** Since Fable 5 was restored July 1 after the export-control suspension, Anthropic ran three successive extensions keeping it included in paid-plan weekly limits at no extra cost. The third extension ran to July 19 at 11:59 PM PT.

**New:** Starting today (July 20), Fable 5's access model is permanently restructured by plan tier:
- **Max and Team Premium**: Fable 5 is now permanently included at 50% of weekly limits — no expiry, no more extensions.
- **Pro and Team Standard**: Moves to pay-as-you-go usage credits at $10/1M input and $50/1M output; all Pro users receive a one-time $100 credit.
- Usage credits setup: Settings → Usage → Enable credits; per-session and daily caps configurable.

Sources: [TechTimes](https://www.techtimes.com/articles/320905/20260718/claude-fable-5-ends-subscription-limbo-permanent-max-credits-only-pro.htm), [Simon Willison](https://simonwillison.net/2026/Jul/18/claude-make-fable-5-permanent/), [Claude Help Center](https://support.claude.com/en/articles/15424964-claude-fable-5-on-your-plan)

**Why it matters:** Max plan users (Stack included) now have stable, permanent Fable 5 access at 50% of weekly limits — no more tracking extension deadlines.

### [UPDATE] Claude Code Artifacts: live MCP connector calls on view
**Background:** Artifacts launched June 18 for Team/Enterprise — session-generated HTML pages, static snapshots of whatever Claude built during the session.

**New (July 16):** Published artifacts can now call MCP connectors each time a viewer opens the page. The page is no longer a static snapshot — it rehydrates from live systems on each view. Key specifics:
- Viewers use their **own** MCP connector credentials, not the publisher's — publishers don't expose credentials and viewers only see data they have access to.
- Viewers must approve connector access on first load.
- Now available on **Pro, Max, Team, and Enterprise** plans (previously Team/Enterprise only).
- Not available on publicly-shared artifacts (org-member access only).

Sources: [Claude Code Week 29 docs](https://code.claude.com/docs/en/whats-new/2026-w29), [AlternativeTo](https://alternativeto.net/news/2026/7/claude-code-artifacts-add-mcp-connector-support-for-dynamic-data/), [ClaudeDevs X](https://x.com/ClaudeDevs/status/2077489907350856038)

**Why it matters:** You can now build a dashboard in a Claude Code session — pulling from GitHub, Jira, Notion, Salesforce via MCP — and publish it as an artifact that stays live for teammates without leaking credentials or requiring you to re-run the session to refresh data.

## Tools & Frameworks

### [NEW] Hugging Face discloses autonomous-AI-driven production breach
An autonomous AI agent system compromised Hugging Face's data-processing pipeline end-to-end over a single weekend — the first publicly disclosed production breach driven entirely by an agentic AI system.

**Attack chain:** A malicious dataset exploited a code-execution vulnerability in a remote dataset loader combined with a configuration template injection, giving the attacker initial code execution on a processing worker. From there, the agent escalated privileges, harvested cloud and cluster credentials, and moved laterally across internal infrastructure — logging 17,000+ actions across short-lived sandboxes over the weekend.

**Impact:** Unauthorized access to a limited set of internal datasets and several service credentials. No evidence of tampering with public-facing models, datasets, or Spaces; software supply chain verified clean.

**Detection and defense:** Hugging Face's LLM-based anomaly-detection pipeline correlated signals and flagged the intrusion. The blue team deployed their own LLM analysis agents to reconstruct the full 17,000-action attack timeline. Notably, when defenders initially tried using frontier models via commercial APIs to analyze attack commands and C2 artifacts, those requests were blocked by provider safety guardrails.

Sources: [Hugging Face security disclosure](https://huggingface.co/blog/security-incident-july-2026), [The Hacker News](https://thehackernews.com/2026/07/worlds-largest-ai-model-repository.html), [Neowin](https://www.neowin.net/news/hugging-face-experienced-cyberattack-carried-out-end-to-end-by-agentic-ai/)

**Why it matters:** Second major agentic attack this month (after JADEPUFFER, July 7). The dataset loader is now a confirmed production attack surface — relevant for any pipeline that ingests datasets from external HF repos. Also worth noting that safety guardrails on frontier APIs blocked defensive analysis during an active incident.

## Wildcard

### [NEW] WAIC 2026 closes in Shanghai; China launches 29-nation WAICO AI governance bloc
The 2026 World Artificial Intelligence Conference (July 16-20, Shanghai) closes today after Xi Jinping's first keynote appearance since 2018, 140+ forums, and 1,100+ exhibitors.

The headline geopolitical move: the launch of the **World Artificial Intelligence Cooperation Organization (WAICO)** — a China-backed intergovernmental body headquartered in Shanghai with 29 founding nations including Russia, Cuba, Brazil, Venezuela, Pakistan, Indonesia, and Kazakhstan. WAICO is explicitly positioned as an alternative to US- and EU-led AI governance frameworks (the UN AI Global Commission, the EU AI Act enforcement regime). Think a Global South + authoritarian-aligned counterweight to Western AI governance norms.

On the hardware side, Huawei used WAIC to officially unveil the **Atlas 950 SuperPoD**: 1,024-chip base configuration (Ascend 950DT, UnifiedBus 2.0 interconnect) scaling to 8,192 NPUs. Huawei claims 6.7x the compute and 15x the memory of NVIDIA's NVL144. Q4 2026 availability target.

### [NEW] EU DMA: Google must open Android to rival AI assistants; search data shared from January 2027
The European Commission issued binding specification measures against Google under the Digital Markets Act on July 16, covering two areas:

**Android AI interoperability (11 features):**
- Users can invoke third-party AI assistants via voice ("Hey Claude", "Hey ChatGPT") on Android — concurrent wake words required by August 2028.
- Third-party assistants can perform in-app actions, receive contextual suggestions, access device resources, and interact with installed apps on users' behalf.
- Primary deadline: Android 18 release + August 1, 2027 for most measures.

**Search data sharing:**
- Google must share search data (with multi-layer anonymization aligned to GDPR) with eligible third-party search engines from January 2027 — addresses the data moat that makes it hard for AI-backed search competitors to match Google's signal volume.

Sources: [European Commission press release](https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1634), [DMA official guidance](https://digital-markets-act.ec.europa.eu/commission-provides-guidance-google-ai-interoperability-android-and-sharing-google-search-data-under-2026-07-16_en), [TECHi](https://www.techi.com/eu-google-ai-interoperability-android-dma/)

### [NEW] Current AI: $400M public-interest AI nonprofit backed by French government + DeepMind
**Current AI** — a nonprofit with explicit "build the public Web of AI" framing — announced $400M in total commitments: $100M anchor from the French government, plus the Ford Foundation, MacArthur Foundation, DeepMind (unusual for a competitor to back a public-access nonprofit), and Salesforce.
