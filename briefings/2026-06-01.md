## Anthropic

### [NEW] Billing split June 15: programmatic usage gets a separate credit pool

Announced May 14 (effective June 15), Anthropic is separating programmatic Claude access from standard subscription usage. Affected workloads: Claude Agent SDK, `claude -p`, Claude Code GitHub Actions, and any third-party app built on the Agent SDK. **Not** affected: Claude Code in the terminal, Claude.ai chat, Claude Cowork — those still count against normal subscription limits.

Credit allocations by plan:
| Plan | Monthly programmatic credit |
|------|--------------------------|
| Pro | $20 |
| Max 5x | $100 |
| Max 20x | $200 |
| Team Standard | $20/seat |
| Team Premium | $100/seat |

Credits bill at full API rates, must be claimed (watch for an Anthropic email on **June 8**), and do not roll over. Indie/solo builders on Pro should audit their automated workflows — the $20 cap can evaporate fast at API rates.

**Why it matters:** Stack's ai-news-agent-routines Routines run via the Agent SDK / managed execution path and almost certainly draw from this credit pool. $100/mo on Max 5x is generous for a daily-briefing workflow, but multi-agent pipelines will need tracking.

## Tools & Frameworks

### [NEW] GitHub Copilot switches to AI Credits usage-based billing — effective today

As of June 1, 2026, GitHub Copilot drops premium request units in favor of GitHub AI Credits: a token-based system where 1 AI Credit = $0.01, debited at listed API rates per model (input, output, cached). Copilot Pro+ ($39/mo) includes $39 in monthly AI Credits; Copilot Business ($19/user) includes $19; Enterprise ($39/user) includes $39. Code completions and Next Edit Suggestions remain unlimited and do not consume credits. Business and Enterprise customers get a higher credit allotment through September 1 as a transition buffer. The critical detail: heavier Copilot Chat and agent-mode usage now has a metered ceiling instead of soft throttling — "you will get less, but pay the same price" is the developer community's accurate summary.

Sources: [GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/), [UsageBox](https://usagebox.com/articles/github-copilot-usage-based-billing-2026), [VS Magazine](https://visualstudiomagazine.com/articles/2026/04/27/devs-sound-off-on-usage-based-copilot-pricing-change-you-will-get-less-but-pay-the-same-price.aspx)

### [NEW] LangGraph v1.2: DeltaChannel, per-node timeouts, streaming API v3

Released May 11, LangGraph 1.2 addresses two pain points in long-running production agents:

- **DeltaChannel**: checkpoints only the incremental diff each step, writes full snapshots every K steps (configurable via `snapshot_frequency=K`). For message-list-heavy threads this keeps storage costs flat as conversation length grows — previously every step re-serialized the whole accumulated value.
- **Per-node timeouts**: pass `timeout=TimeoutPolicy(run_timeout=..., idle_timeout=...)` to `add_node`. On breach, LangGraph raises `NodeTimeoutError`, discards writes from that attempt, and hands off to the retry policy. Async nodes only.
- **Streaming API v3**: content-block-centric streaming replaces token-stream assumptions.
- The `prebuilt` module was extracted into `langgraph-prebuilt` (Supervisor, Swarm, LangMem, Trustcall) — import paths changed.

**Why it matters:** DeltaChannel directly solves checkpoint bloat in the kind of stateful multi-step research agents Stack is building. Worth pulling in at the next dependency update.

Sources: [LangChain Blog](https://www.langchain.com/blog/delta-channels-evolving-agent-runtime), [LangGraph Releases](https://github.com/langchain-ai/langgraph/releases), [LangChain Changelog](https://changelog.langchain.com/)

## Model Releases

### [NEW] Gemini 3.5 Pro enters limited Vertex preview; GA target before June 30

Sundar Pichai's exact words at Google I/O May 19: "Give us until next month." As of late May, 3.5 Pro is in limited Vertex enterprise preview. Confirmed capabilities: 2M-token context, Deep Think reasoning, frontier multimodal. Pricing not yet announced (reference point: 3.1 Pro at $2.00/$12.00 per 1M input/output). Gemini 3.5 Flash (already GA since May 19) is the widely available 3.5 model in the meantime, and it's already the reference point to beat on agentic benchmarks: MCP Atlas 83.6% (vs. Claude Opus 4.7 at 79.1%, GPT-5.5 at 75.3%).

Sources: [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/), [CodersEra — 3.5 Pro launch guide](https://codersera.com/blog/gemini-3-5-pro-launch-guide-2026/), [Ofox — Pro specs](https://ofox.ai/blog/gemini-3-5-pro-release-date-expected-specs-2026/)
