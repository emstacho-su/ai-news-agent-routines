## Tools & Frameworks

### [UPDATE] Claude Code v2.1.296: doubled MCP description cap, workflow model pinning, gateway code key

**Background:** Prior release (v2.1.289/292) added agent.spawn API, MCP OAuth re-auth prompts, and the --marketplace flag for plugin install.

**New (v2.1.296, released Oct 9):**
- **MCP tool description limit doubled** — from 2,048 to 4,096 characters per tool and per server instructions block. Removes a common truncation issue for MCP servers that embed schema hints in descriptions.
- **Workflow agent model pinning** — new `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` env var locks every workflow agent to one model while other sub-agents keep their own settings. Useful for cost control on large fan-out workflows.
- **Sub-agent `autoCompactWindow`** — sub-agent frontmatter and `--agents` definitions now accept this key, so a long-running sub-agent can compact context sooner than the main conversation.
- **Gateway `code` policy key** — `managed.policies[]` in the Claude apps gateway gains a `code` key that applies CLI settings to the Code tab in Claude Desktop. Unified managed-admin control across chat and code surfaces.
- **Admin hook fix** — `PreToolUse` hooks that deny with `"continue": false` now refuse the call without ending the turn (prior behavior terminated the whole turn on denial).
- **BASH_ARGV0 permission gap closed** — prevents a specific shell-completion bypass.

Sources: [ai-tldr.dev v2.1.296](https://ai-tldr.dev/releases/anthropic-claude-code-2-1-296/), [Claude Code October releases](https://www.havoptic.com/releases/claude-code/2026/10)

**Why it matters:** The doubled MCP description cap is practically useful right now — most heavy MCP servers (Postgres, filesystem, large APIs) exceed 2K characters and previously truncated silently. The workflow model pinning + autoCompactWindow pair gives finer cost/context control for multi-agent builds.

## Model Releases

### [NEW] Meta Muse Wonder + Muse Wonder Full: MSL's frontier model series launches

Meta Superintelligence Labs released Muse Wonder and Muse Wonder Full on October 12, 2026, marking the start of a new model series above the Muse Spark line. Meta's research page describes them as frontier models for personal and professional agentic tasks. No parameter count or numeric benchmarks were published alongside the launch.

Pricing (per aggregator reporting, not yet confirmed on Meta's pricing page): Muse Wonder Full is reportedly $4.00/M input, $20.00/M output — roughly 3× the Muse Spark 1.3 price. No independent benchmark comparisons have published yet.

Context: MSL's model progression has been fast — Muse Spark launched April 2026, Spark 1.3 arrived September 2, and Muse Wonder follows in October. Wonder is a new series name, suggesting a larger capability jump than the Spark 1.x point releases.

Sources: [Meta AI Research](https://ai.meta.com/research/), [TheRundown](https://www.therundown.ai/p/meta-superintelligence-labs-ships-its-first-model), [eWeek](https://www.eweek.com/news/meta-internal-ai-key-models/)

**Why it matters:** MSL has shipped a named frontier model roughly every 2-3 months since April. At Muse Wonder Full pricing ($4/$20), it's squarely in Sonnet-class territory. Independent evals will be the test — but given MSL's pace, waiting for perfect benchmarks before evaluating is slower than testing against your own tasks.

## Practical Tips

**GPT-5.5 retires today from ChatGPT/Codex — action required now:** If you use Codex via ChatGPT sign-in (not an API key), you must manually switch to `gpt-5.6-sol` before end of day. API key users have no deadline. Workspace defaults, saved model settings, custom agents, and scheduled tasks hard-coded to `gpt-5.5` will break. `gpt-5.6-sol` is the named like-for-like replacement; `gpt-6-astra` for hard multi-step agentic work.

**Claude Code MCP tool descriptions:** After upgrading to v2.1.296, MCP servers that were silently truncating their tool descriptions at 2,048 characters will now send the full text (up to 4,096 chars). If any existing server sends junk instructions that were benign at 2K, review them post-upgrade.
