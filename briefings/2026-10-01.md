## Tools & Frameworks

### [UPDATE] OpenAI Codex Security Cloud: Daybreak Blue Default + Oct 1 Hardware Key Enforcement
Daybreak Blue — GPT-5.6 Sol with security prompt filters removed — is now bundled by default into Codex Security Cloud, enabling whole-repo scans, continuous commit review, deduplicated findings, and fix-draft generation directly from the Codex desktop and web clients. Starting October 1, individual users must have an eligible hardware security key to unlock cyber-forward features. The Blue/Red split (Blue = defensive ops; Red = GPT-5.6-Cyber for authorized exploit research) remains in place.

**Background:** Daybreak initiative launched May 2026; Blue/Red tiers separated August 2026; hardware keys required for all Daybreak accounts since September 1. October 1 is the deadline for individual Codex Security users, not just Daybreak-specific accounts.

## Model Releases

### [NEW] Space Bunny Alpha: Anonymous 1M-Context Multimodal on OpenRouter
OpenRouter is serving "Space Bunny Alpha," an unattributed multimodal stealth model with a 1M-token context window and up to 524,288 output tokens, with tools and structured output enabled. The model is free through October 5 during the promotional window. The provider is undisclosed — OpenRouter has been running these stealth windows for months as a low-friction way for labs to collect baseline benchmarks against real workloads.

The window is short enough that running your own eval suite against it now is worth the effort if you care about anonymous comparative benchmarks.

## Wildcard

### [NEW] Stanford MMBU Challenge: Medical Multimodal Benchmark (Oct 1 – Dec 31)
Stanford launched the MMBU Challenge to evaluate whether vision-language models genuinely recognize medical modality, body part, specimen type, and staining method — rather than surface-level pattern-matching. Three tracks, $100K+ in compute and prize funding. Competition runs October 1 through December 31. The dataset is designed to expose overfit on consumer-oriented medical image training sets.

Relevant if you're evaluating or building on any vision-language model for clinical, life science, or diagnostic use cases.
