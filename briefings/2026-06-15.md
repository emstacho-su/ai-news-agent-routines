## Anthropic

### [UPDATE] Fable 5 / Mythos 5 shutdown: Amazon triggered it

**Background:** On June 12, Commerce Secretary Howard Lutnick signed an export control directive forcing Anthropic to disable Fable 5 and Mythos 5 globally within hours of receipt. Publicly cited reason was a Pliny the Liberator jailbreak posted June 10.

**New:** A Fortune investigation published June 14 reveals the actual trigger: Amazon researchers at AWS successfully jailbroke Mythos 5, extracting cyberattack-useful information. CEO Andy Jassy then personally alerted senior White House officials. A source told Fortune that Anthropic was given only 90 minutes to pull both models globally. Commerce Secretary Lutnick's directive followed. Anthropic continues to dispute the characterization — calling it "a narrow potential jailbreak" that provides "no Mythos-specific uplift" — but compliance was non-negotiable. As of June 15, both models remain offline with no announced restore timeline.

The Amazon angle matters structurally: Amazon is simultaneously Anthropic's largest outside investor (~$8B), the primary cloud host (AWS Bedrock), and — via this incident — the party that reported the jailbreak to the US government. [TechTimes](https://www.techtimes.com/articles/318350/20260614/amazon-triggered-claude-fable-5-shutdown-investor-cloud-host-now-regulator.htm) labels the role: "Investor, Cloud Host, Now Regulator."

Sources: [Fortune](https://fortune.com/2026/06/14/how-a-warning-from-amazon-led-the-white-house-to-shut-down-anthropics-mythos-model/), [Axios](https://www.axios.com/2026/06/13/anthropic-amazon-white-house), [TechTimes](https://www.techtimes.com/articles/318350/20260614/amazon-triggered-claude-fable-5-shutdown-investor-cloud-host-now-regulator.htm), [MLQ.ai](https://mlq.ai/news/amazons-jassy-alerted-white-house-to-anthropic-fable-5-security-flaws-triggering-export-ban/)

**Why it matters:** The conflict-of-interest geometry here is unusual for the AI industry. Anthropic's biggest infrastructure partner and investor had financial incentive to keep Fable 5 running (AWS Bedrock revenue) yet was the entity that reported it to the government. Raises real questions about what access cloud providers have to safety testing their hosted models, and whether that access will now become standard practice.

### [UPDATE] Anthropic programmatic credit billing split — now live

**Background:** Announced May 14, effective today: Agent SDK, `claude -p`, GitHub Actions, and approved third-party apps move to a separate monthly credit ($20/Pro, $100/Max 5x, $200/Max 20x), metered at full API rates. Credits require manual claim and don't roll over.

**New:** The billing change is live as of today. Developer reactions are running mixed-to-negative for heavy automation users. Key practical pattern emerging from community: switching non-reasoning pipeline steps (formatting, summarization, simple code review) from Opus 4.8 to Sonnet 4.6 cuts credit burn approximately 3-4x with minimal quality difference on those tasks. Per-user credit pooling cannot be shared across CI committers — a team running GitHub Actions under multiple authors needs to account for each user's $200 cap independently.

Sources: [The New Stack](https://thenewstack.io/anthropic-agent-sdk-credits/), [Level Up Coding](https://levelup.gitconnected.com/anthropic-will-quietly-reprice-your-claude-pro-plan-on-june-15-the-free-20-credit-replacing-1ebd922a7786), [Codersera](https://codersera.com/blog/anthropic-june-2026-billing-change-claude-code/)

**Why it matters:** This billing structure directly affects this project's Routines — the Agent SDK calls running this briefing draw from the Max 20x $200 credit pool. If you're at Max 5x, budget $100/month for all programmatic calls combined.

### [UPDATE] Claude 4 API models retired — effective today

**Background:** Deprecation announced with June 15 hard retirement date for `claude-sonnet-4-20250514` and `claude-opus-4-20250514`.

**New:** The retirement is now in effect. API calls to either model string now return hard errors. Current replacement targets: `claude-sonnet-4-6` (Sonnet 4.6) and `claude-opus-4-8` (Opus 4.8). Check CI configs, `.env` files, hardcoded client initializers. Make-compatible integrations had a separate deprecation notice via their help center.

Sources: [Anthropic Help — Make](https://help.make.com/anthropic-claude-model-deprecations-on-june-15-2026), [Hidekazu Konishi model timeline](https://hidekazu-konishi.com/entry/anthropic_claude_model_release_timeline.html)

### [UPDATE] Microsoft Agent Framework 1.8.0

**Background:** Agent Framework 1.0 GA'd April 3, merging AutoGen and Semantic Kernel. v1.0 was MCP-native, .NET + Python.

**New:** v1.8.0 (released in June 2026) adds several developer-facing capabilities: `McpSkillsSource` for MCP-based skills discovery (agents can now enumerate and invoke tools from any MCP server as first-class skills), `FunctionInvocationContext` for progressive tool exposure (expose only relevant tools to sub-agents based on task context), background agent support in the harness agent, and `AgentFileStore`/`FileAccessProvider` for structured file access operations. Provider matrix expanded: Bedrock, Foundry, Mistral, A2A, GitHub Copilot, and OpenAI all updated.

Sources: [Microsoft Agent Framework Blog](https://devblogs.microsoft.com/agent-framework/), [Releasebot](https://releasebot.io/updates/microsoft)

**Why it matters:** `McpSkillsSource` is the practical bridge between MCP servers and the Agent Framework's planner — if you're running MCP servers that expose domain tools, v1.8.0 means the AF planner can discover and invoke them without manual registration.
