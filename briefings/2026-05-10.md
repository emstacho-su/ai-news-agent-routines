## Anthropic

### [NEW] Claude Managed Agents: "Dreaming" enters research preview, Outcomes and Multi-Agent Orchestration hit public beta

Announced at Code with Claude SF (May 6), **dreaming** is a scheduled background process that reads across an agent's past sessions and memory stores, identifies recurring patterns — repeated mistakes, converging workflows, shared preferences — merges duplicate entries, removes stale context, and writes structured updates back to memory. Agents improve between sessions without weight updates; the model itself is unchanged. Two modes: auto-commit (dreaming writes directly) or human-review (diff shown before changes land). [VentureBeat](https://venturebeat.com/technology/anthropic-introduces-dreaming-a-system-that-lets-ai-agents-learn-from-their-own-mistakes), [9to5Mac](https://9to5mac.com/2026/05/07/anthropic-updates-claude-managed-agents-with-three-new-features/), [The New Stack](https://thenewstack.io/anthropic-managed-agents-dreaming-outcomes/)

**Why it matters:** Dreaming is the missing piece for stateful, self-improving agent pipelines — exactly the pattern Routines will use once the memory store is live in R5. Harvey Legal AI's reported 6x task-completion lift shows this isn't marginal.

Also at the same launch: **Outcomes** (agents evaluate their own output against quality rubrics) and **Multi-Agent Orchestration** both graduated from research preview to **public beta**.

## Model Releases

### [NEW] Claude Sonnet 5: 92.4% SWE-bench Verified, 88.3% OSWorld-Verified, 2M token context

Released April 1, 2026 (model string `claude-sonnet-5-20260401`), Sonnet 5 was not covered in prior briefings. Benchmarks: **92.4% SWE-bench Verified** (vs. Claude Opus 4.6 at 80.8%, GPT-5.4 at 57.7%) and **88.3% OSWorld-Verified** computer-use accuracy against a 72.4% human expert baseline. Context jumps to 2M tokens (1M from Sonnet 4.6 is now stable/GA). Pricing unchanged from Sonnet 4.6: $3/$15 per million tokens in/out. The adaptive-thinking architecture from the 4.6 generation is upgraded with smarter reasoning-depth allocation. [DEV Community](https://dev.to/best_codes/anthropic-just-dropped-claude-sonnet-5-and-the-benchmarks-are-kind-of-insane-3ppc), [Bytebot](https://bytebot.io/articles/claude-sonnet-5-release), [NxCode](https://www.nxcode.io/resources/news/claude-sonnet-5-fennec-leak-2026)

**Why it matters:** Sonnet 5 is the default model for Claude Code sessions and sets a new bar for autonomous coding tasks — 92.4% SWE-bench at Sonnet-level pricing effectively obsoletes using Opus for most agent loops. Routines running on Max quota should default to Sonnet 5.

## Practical tips

- **Dreaming opt-in:** Managed Agents dreaming is research preview — to enable, set `"dreaming": {"mode": "human_review"}` in your agent config first. Auto-commit is the default once enabled; human-review mode surfaces a diff before writes land. Worth reading the [API docs](https://platform.claude.com/docs/en/managed-agents/dreams) before enabling in production.
- **Sonnet 5 in Claude Code:** If your Claude Code sessions are still running on Sonnet 4.6 by default, upgrade: `claude config set defaultModel claude-sonnet-5-20260401`. The 2M context is immediately useful for large-repo Routine runs.
