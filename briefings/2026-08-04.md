## Anthropic

### [UPDATE] Claude Code v2.1.221: Focus view and credential masking

**Background:** Claude Code has been shipping rapid changelogs through July–August 2026; previous coverage tracked versions through v2.1.220 (July 25).

**New:** v2.1.221 (released August 4) adds:

- **Focus view** — a chat-menu toggle (Ctrl+Alt+F or "Claude Code: Toggle Focus view" command) that hides tool activity behind an expandable per-turn summary with a live running-tool indicator. Useful for long agentic sessions where tool noise drowns the conversation.
- **mode: "mask"** for sandbox credential files on Linux and WSL — sandboxed commands read a sentinel copy while the sandbox proxy substitutes the real value on egress. On macOS the feature gracefully falls back to `deny`.
- **Plugin validate warnings** for marketplace/plugin names that would be rejected by Claude Desktop's managed marketplace sync.

Sources: [Claude Code Changelog (August 2026)](https://www.gradually.ai/en/changelogs/claude-code/), [Claude Code Changelog: All Release Notes (2026)](https://claudefa.st/blog/guide/changelog)

**Why it matters:** Focus view is the quality-of-life fix for anyone running long ultracode workflows where you care about the outcome, not the 400 tool-call lines getting there. Credential masking is a concrete sandbox hardening win.

### [UPDATE] MCP 2026-07-28 stateless spec rolling out to Claude products

**Background:** The MCP 2026-07-28 specification was finalized July 28, replacing stateful sessions with a self-describing stateless request model, adding Multi Round-Trip Requests, Extensions framework, Tasks, and hardened OAuth/OIDC.

**New:** Anthropic has published a blog post confirming the rollout of 2026-07-28 support across Claude products. AWS AgentCore Gateway is the first major production cloud deployment live on the new stateless protocol. The key operational win: no more sticky sessions — round-robin load balancers work without shared session-state storage. Tier 1 SDK betas (Python `mcp 2.0.0b1`, TypeScript `@modelcontextprotocol/server 2.0.0-beta.1`) are available for server authors to begin migrating ahead of Claude product rollout.

Sources: [MCP 2026-07-28 spec: stateless core, coming to Claude](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude), [How AgentCore Gateway supports the MCP 2026-07-28 spec](https://aws.amazon.com/blogs/machine-learning/how-agentcore-gateway-supports-the-mcp-2026-07-28-spec/), [The 2026-07-28 Specification](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

**Why it matters:** If you're running MCP servers, the 2026-07-28 SDK betas are your migration target. The stateless model removes the stickiness constraint that made horizontal scaling painful.

## Tools & Frameworks

### [UPDATE] Claude Sonnet 5 standard pricing starts Sept 1 — the tokenizer tax

**Background:** Claude Sonnet 5 launched April 1 2026 at introductory $2/$10 per million input/output tokens through August 31.

**New:** Standard rates of $3/$15 per Mtok take effect September 1 — a 50% sticker increase. The less-obvious factor: Sonnet 5 uses a new tokenizer that encodes the same text as roughly 0–35% more tokens than Sonnet 4.6's tokenizer. So even at the same per-token sticker price as 4.6, request costs can run higher. At standard September prices ($3/$15), teams that haven't profiled their actual token counts against the new tokenizer may see cost growth larger than the 50% headline number.

Sources: [Claude Sonnet 5 intro pricing deadline (Aug 31)](https://finopsllm.com/research/sonnet-5-intro-pricing-deadline), [Sonnet 5 vs 4.6: The Hidden Cost Jump](https://moclaw.ai/blog/claude-sonnet-5-tokenizer-cost-migration), [Claude Sonnet 5 Pricing 2026](https://www.eesel.ai/blog/claude-sonnet-5-pricing)

**Why it matters:** If you're billing LLM costs through to clients or have a budget ceiling, August 31 is the hard migration-evaluation deadline. Run actual token count comparisons on representative inputs before September.

## Practical tips

- **Credential masking in v2.1.221 is Linux/WSL only** — if you're on macOS and relying on sandbox to protect creds, you're in the `deny` fallback path, not mask. Plan accordingly if you're using sensitive credentials inside sandboxed commands.
- **Aug 31 Sonnet 5 deadline**: run `anthropic.messages.count_tokens()` on your representative workloads against Sonnet 5 vs 4.6 before committing to September rates. The tokenizer gap is real and varies by content type.
- **MCP migration**: if you have MCP servers in prod, clone the `@modelcontextprotocol/codemod@beta` tool now — it auto-migrates v1 server code to v2 stateless API. Don't wait until Claude products flip the switch.
