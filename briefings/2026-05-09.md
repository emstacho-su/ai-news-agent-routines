## Tools & Frameworks

### [NEW] AWS MCP Server is generally available (May 6)

AWS shipped the GA of the AWS MCP Server, giving AI coding agents secure, auditable access to AWS services through MCP. Authorization runs through IAM; metrics export to CloudWatch; every tool call is logged to CloudTrail. Agents discover AWS tools dynamically through the standard MCP interface—no manual API wiring.

**Why it matters:** First major cloud provider with a production-ready, enterprise-auditable MCP server. If you're building agents that provision, query, or monitor AWS resources, this is the official path. CloudTrail audit trail also meaningfully addresses the TrustFall-class threat concerns around unverifiable MCP server actions.

Sources: [AWS](https://aws.amazon.com/about-aws/whats-new/2026/05/aws-mcp-server/)

### [NEW] Claude Code /ultrareview: parallel multi-agent cloud code review

`/ultrareview` orchestrates a swarm of specialist subagents—each reviewing a branch from a distinct angle (security, correctness, architecture, style, test coverage)—then synthesizes findings into a single report. Works against a GitHub PR number (`/ultrareview <PR#>`) or diffs against the default branch when called without args. Billed to extra usage at roughly $5–20 per review depending on diff size; three free runs for Pro/Max (expired May 5).

**Why it matters:** For security-sensitive work (see: Mythos, TrustFall coverage in recent briefings), a multi-perspective automated review catches classes of bugs that a single-pass review misses. Directly applicable to the R6 `dashboard.py` refactor and the Resend MCP server work.

Sources: [Claude Code Docs](https://code.claude.com/docs/en/ultrareview), [Claude Directory](https://www.claudedirectory.org/blog/ultrareview-claude-code-guide)

## Practical tips

**Using the AWS MCP Server from Claude Code:** Install with `npm install -g @aws-sdk/mcp-server`, then register in `.mcp.json`:

```json
{
  "mcpServers": {
    "aws": {
      "command": "aws-mcp-server",
      "args": [],
      "env": { "AWS_PROFILE": "your-profile" }
    }
  }
}
```

Your Claude Code session then gets `aws_*` tools that proxy through IAM — every call lands in CloudTrail. This sidesteps the TrustFall threat model since the server ships from the official `@aws-sdk` npm scope, not an untrusted cloned repo.
