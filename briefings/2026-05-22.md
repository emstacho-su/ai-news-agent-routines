## Anthropic

### [UPDATE] SpaceX S-1 reveals full Anthropic compute payment terms: $1.25B/month, $45B total

**Background:** Anthropic rented all capacity at SpaceX's Colossus I data center in Memphis — 300+ MW, 200,000+ NVIDIA GPUs — with xAI folding into SpaceX as SpaceXAI.

**New:** SpaceX filed a public S-1 on May 20 ahead of its planned June Nasdaq listing. The filing disclosed that Anthropic is paying **$1.25 billion per month** under Cloud Services Agreements covering Colossus I and the expanded Colossus II — **$15B/year**, **~$45B** over the term through May 2029. Either party can terminate on 90 days notice; Anthropic retains ownership of its AI models and data. The S-1 also confirms Colossus II exists alongside the original cluster, materially expanding the scope of the deal beyond what was previously reported.

Sources: [TechCrunch](https://techcrunch.com/2026/05/20/anthropic-will-pay-xai-1-25-billion-per-month-for-compute/), [Benzinga](https://www.benzinga.com/markets/ipos/26/05/52724877/spacexs-45-billion-anthropic-deal-could-fund-its-ai-buildout-three-times-over), [Teslarati](https://www.teslarati.com/spacex-reveals-what-anthropic-will-pay-for-massive-compute-deal/), [SEC S-1](https://www.sec.gov/Archives/edgar/data/0001181412/000162828026036936/spaceexplorationtechnologi.htm)

**Why it matters:** $1.25B/month is the first hard number on Anthropic's compute spend; it anchors the unit economics of the upcoming IPO narrative and explains why the $900B valuation is the floor rather than the ceiling.

## Tools & Frameworks

### [UPDATE] Claude Code v2.1.147 + v2.1.148 hotfix

v2.1.147 (shipping today) adds **pinned background sessions** (Ctrl+T in `claude agents`): pinned sessions stay alive when idle, auto-restart in place on Claude Code updates, and are shed under memory pressure only after non-pinned sessions. The auto-updater is hardened with network-failure retries, specific error codes/OS error codes on failure, and shows the current version when an update fails. Bug fixes: Bedrock and Vertex users unable to select Opus 1M context from the `/model` picker (regression from v2.1.129); MCP images with unsupported MIME types (e.g., SVG) now saved to disk and referenced in the tool result rather than breaking the conversation.

v2.1.148 was a same-day hotfix: fixed Bash tool returning exit code 127 on every command for some users (regression introduced in v2.1.147).

Sources: [GitHub Releases](https://github.com/anthropics/claude-code/releases), [Changelog](https://code.claude.com/docs/en/changelog), [claudefa.st](https://claudefa.st/blog/guide/changelog)

**Why it matters:** Pinned background sessions are the first explicit lifecycle guarantee for long-lived background agents — they survive updates and memory pressure, which matters when you're running multi-hour Routine-style tasks.

### [NEW] WebMCP enters Chrome 149 origin trial: structured tool exposure for browser AI agents

Google shipped a Chrome 149 origin trial for **WebMCP**, a proposed open web standard that lets sites register JavaScript functions and HTML forms as structured MCP tools callable by browser AI agents — rather than having agents simulate human clicks. The spec lives in the W3C Web Machine Learning Community Group (not yet on the official Standards Track). Companion docs published on [developer.chrome.com](https://developer.chrome.com/docs/ai/webmcp).

The only current consumer is **Gemini in Chrome** (the in-browser assistant, separate from the Gemini web app). When a user is on a WebMCP-enabled page, Gemini can discover and call the registered tools. Early adopters committing to the origin trial include Booking.com, Expedia, Instacart, Intuit, Shopify, and Redfin.

Sources: [Chrome for Developers](https://developer.chrome.com/blog/chrome-at-io26), [WebMCP docs](https://developer.chrome.com/docs/ai/webmcp), [The New Stack](https://thenewstack.io/google-agent-ready-web/), [ppc.land](https://ppc.land/chrome-149-origin-trial-puts-webmcp-in-developers-hands-at-last/)

**Why it matters:** WebMCP is the browser-native equivalent of MCP server registration — if it gains traction, web developers could ship agent-callable APIs without running a separate MCP server process. Still Google-only at consumer layer, and W3C adoption is uncertain.

## Wildcard

### [NEW] OpenAI files confidential IPO S-1 with Goldman, Morgan Stanley, JPMorgan; September target at $1T+

OpenAI filed a confidential S-1 registration statement with the SEC approximately today, with Goldman Sachs and Morgan Stanley as lead underwriters and JPMorgan Chase also in the deal.
