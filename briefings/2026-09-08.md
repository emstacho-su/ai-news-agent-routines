### [NEW] HiddenLayer Closes $100M Series B for AI Agent Runtime Security

HiddenLayer (Austin, TX) announced a $100M Series B on September 2, led by Delta-v Capital, with participation from Ten Eleven Ventures, M12 (Microsoft Ventures), Morgan Stanley, and Booz Allen Ventures. Total raised now exceeds $155M.

Key product: **Agent Harness Security** — runtime interception layer sitting between the agent and its environment (file system, shell, network) to catch malicious tool calls, sandboxed escapes, and post-compromise pivots in real time. Extends HiddenLayer's existing AI Runtime Security module to cover coding agents specifically.

Company metrics: 10x ARR growth year-over-year; 50+ new enterprise platform customers across securities brokerage, banking, insurance, government, and US defense/intelligence. Selected in August 2026 to support the DoE's $60M Prometheus initiative (AI + nuclear energy safety).

**Why it matters:** Claude Code, Codex CLI, and Cursor all run on production machines with broad file-system and shell access. Agent-level runtime security is the new endpoint protection problem — HiddenLayer is the most-funded pure-play in this space.

## Research & Technical

### [NEW] OpenAI: 3.1 Agent-Workdays per Human Workday; Pachocki Calls for Voluntary Slowdown

On September 6, OpenAI published two paired posts that are best read together:

**Agents accelerating research:** By mid-August, OpenAI's internal research org was consuming 3.1 agent-workdays of runtime per human workday — faster code iteration, more experiments run in parallel. OpenAI explicitly notes that this is a *compute* ratio, not a speed ratio; design and evaluation bottlenecks shift upstream as implementation gets cheaper.

**Jakub Pachocki, "An Alien Mind":** Chief scientist Pachocki writes that no lab — OpenAI included — has solved alignment and monitoring well enough to keep scaling at maximum speed. He calls for voluntary slowdowns while labs develop stronger control mechanisms, describing frontier models as developing reasoning "alien to human introspection." This is a relatively rare public call from a sitting lab chief scientist for the field to pace itself, not just signal alignment work.

The tension: OpenAI is simultaneously making the case that agents are economically transformative *and* that the field must slow down. These positions can both be correct; the interesting question is what "slow down" would actually look like in practice with compute supply still expanding.

**Why it matters:** The 3.1× workday metric is a leading indicator of what happens inside any AI-native org that wires agents into workflows — worth tracking as a benchmark for Stack's own builds. Pachocki's essay is worth reading in full.
Sources: [The Next Web](https://thenextweb.com/news/openai-slowdown-pachocki-alien-mind-research-intern-compute), [The Decoder](https://the-decoder.com/openai-reports-ai-research-interns-and-warns-about-its-own-pace-at-the-same-time/), [MLQ News](https://mlq.ai/news/openai-says-its-researchers-now-use-31-agent-workdays-for-every-human-workday/), [InsideAI](https://insideai.news/news/agentic-ai/openai-coding-agents-research-acceleration/9779/)
