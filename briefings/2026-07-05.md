**New:** Anthropic's redeployment statement (confirmed via official X post) notes that some routine coding and debugging tasks currently fall back to Opus 4.8 while the new classifiers are calibrated — the broad initial net is catching some legitimate coding prompts, and the company says this is temporary. Sources: [Anthropic X](https://x.com/AnthropicAI/status/2072163884430229756), [MacRumors](https://www.macrumors.com/2026/07/01/anthropic-fable-5-relaunch/), [Axios](https://www.axios.com/2026/07/01/anthropic-fable-5-back-online-trump-export-controls-lifted).

**Why it matters:** Two-day window left on the free allotment. If you have compute-heavy work queued, now is the time. The Opus 4.8 fallback on coding tasks is temporary but real — you may see degraded output on tasks that should hit Fable 5.

### [UPDATE] Claude Code v2.1.198-199: Claude in Chrome GA, background PR commits, skill stacking

**Background:** v2.1.197 (July 1) set Sonnet 5 as default with 1M context and patched the MCP supply-chain security vector.

**New:** v2.1.198 (July 1, 33 changes): Claude in Chrome reached general availability for all paid-plan users — chat panel in Chrome toolbar, Claude reads the visible page, clicks, and fills inputs on your behalf; defaults to Haiku 4.5 for speed. Background agents can now commit, push, and open draft PRs autonomously without requiring an interactive session. A new Notification hook fires when a background session completes or blocks on user input. v2.1.199 (July 2): up to 5 stacked slash-skill invocations in a single command; auto-retry on transient 429s for subscribers.

Sources: [code.claude.com changelog](https://code.claude.com/docs/en/changelog), [DevelopersIO v2.1.198 writeup](https://dev.classmethod.jp/en/articles/20260702-cc-updates-v2-1-198/), [releasebot.io](https://releasebot.io/updates/anthropic/claude-code).

**Why it matters:** Background agents opening draft PRs is the cleanest async workflow unlock so far — fire a task before bed, wake up to a PR with context. The Notification hook is the missing piece to integrate this into any notification stack without polling.

## Wildcard

### [NEW] UN Global AI Governance Dialogue: opens tomorrow in Geneva

The first Global Dialogue on AI Governance runs July 6-7, 2026 at Palexpo, Geneva — established by the UN General Assembly under the Global Digital Compact. All 193 Member States invited alongside private sector, civil society, academia, and technical community. Co-located with WSIS Forum 2026 (July 6-10) and the ITU AI for Good Global Summit (July 7-10). A second session is planned for New York, May 2027. No binding commitments expected; this establishes the multilateral template and working relationships for future global AI governance coordination — distinct from the separate UN AI for Good Global Commission (Marc Benioff and President Kagame co-chairs, launched July 1).

Sources: [UN.org](https://www.un.org/global-dialogue-ai-governance/en), [UNESCO](https://www.unesco.org/en/articles/global-dialogue-ai-governance-geneva-6-7-july), [ITU](https://www.itu.int/en/mediacentre/Pages/MA-2026-06-02-UN-Dialogue.aspx).
