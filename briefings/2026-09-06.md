## Tools & Frameworks

### [UPDATE] Claude Code v2.1.261 — /skill-doctor, Bigger Output Buffers, Diff Panel
**Background:** Sept 1 release made Fable 5.1 the default and added the Containment Escape auto-mode rule.
**New (Sept 2–6):**
- `managedMcpServers` org-managed setting: administrators can push HTTP/SSE MCP servers to every user in the organization without per-user config changes. Fixes: `/mcp reconnect`/`enable` no longer bypasses admin allow/deny list; `claude mcp remove` now clears stored OAuth credentials; MCP servers that disconnect during tool listing now show the error instead of appearing connected with no tools.
- v2.1.261 (Sept 4): `bashOutputMaxChars` and `taskOutputMaxChars` settings let you raise the inline command/background-task output limit up to 128K characters — previously, long build output was silently truncated before Claude saw it.
- `/skill-doctor` slash command shows which loaded skills are going unused in the current session and their context cost in tokens. Useful for trimming bloat in long sessions.
- `--append-subagent-system-prompt-file` flag reads subagent system prompt additions from a file (vs. inline CLI arg).
- Added "Organization policy" line to `/status` and `claude doctor` explaining when org policy fails to load.
- Sept 6: bug fixes and stability improvements only.
- Diff panel: a side panel shows uncommitted changes as Claude edits, in fullscreen mode.

**Why it matters:** `bashOutputMaxChars` is immediately useful for any workflow where build/test output gets truncated — the 128K ceiling means Claude can now see full stack traces and verbose test output without piping to files. `/skill-doctor` is useful for managing context cost in the multi-skill setups Stack runs.
Sources: [Claude Code Docs](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)

## Practical Tips

- **Raise output buffers now:** If you're running Claude Code on long build pipelines and seeing truncated output, set `bashOutputMaxChars: 131072` in your project settings to get the full 128K. Same for background tasks: `taskOutputMaxChars: 131072`.
- **Run `/skill-doctor`** in any long session that's feeling slow — it'll show you which skills are loaded but never triggered, and their token cost. Easy wins on context pressure.
- **Check `managedMcpServers`** if you're managing Claude Code for a team: you can now centrally push MCP server configs to all users without asking them to edit settings files.
