## Model Releases

### [UPDATE] GPT-5.6 actually launched — Sol, Terra, Luna three-tier family

**Background:** For two weeks, prediction markets tracked GPT-5.6 with 83% odds it *wouldn't* ship before June 28 and $1.55M+ in volume; OpenAI chief scientist had called it "a meaningful leap" but no system card appeared.

**New:** OpenAI launched GPT-5.6 on June 26 as three named variants under a government-reviewed restricted preview:
- **Sol** (flagship): $5/$30 per 1M in/out tokens; "max" reasoning mode + "ultra" mode that spins up sub-agents for complex tasks; focus on coding, biology, and cybersecurity.
- **Terra** (balanced): $2.50/$15 per 1M tokens.
- **Luna** (fast/affordable): $1/$6 per 1M tokens.

Currently accessible to ~20 vetted organizations. General availability planned in the "coming weeks." Key architectural change: redesigned reward audit pipeline targeting alignment failures that contaminated GPT-5.5 training data ("Where the Goblins Came From" post-mortem).

Sources: [Axios](https://www.axios.com/2026/06/26/openai-gpt-sol-terra-luna-trump), [VentureBeat](https://venturebeat.com/technology/openai-unveils-gpt-5-5-6-sol-terra-and-luna-models-but-only-accessible-to-limited-preview-partners-for-now-per-us-gov), [OpenAI](https://openai.com/index/previewing-gpt-5-6-sol/).

**Why it matters:** Sol's "ultra" sub-agent mode is a direct parallel to Claude Code's ultracode / dynamic workflows. The tiered pricing ($1–$5/1M input) undercuts Fable 5's positioning if/when Fable 5 gets broader access. Tracking GA timing is worth it for API cost comparisons.

## Tools & Frameworks

### [UPDATE] ARD's ai-catalog.json has zero real-world adoption 10 days post-launch

**Background:** Agentic Resource Discovery (ARD) was published June 17 by 11 companies (Google, Microsoft, Cisco, Databricks, GitHub, GoDaddy, Hugging Face, NVIDIA, Salesforce, ServiceNow, Snowflake) as the discovery layer above MCP — a `/.well-known/ai-catalog.json` file lets agents find which tools a site exposes.

**New:** A June 18 adoption census of 39 major sites — including all 11 named working-group members — found *zero* sites serving a discoverable `ai-catalog.json`. The spec is v0.9 draft and Apache-2.0; reference implementation is GitHub Copilot Agent Finder, but even GitHub itself had not deployed the file at the time of the sweep.

Sources: [Synscribe](https://www.synscribe.com/blog/google-agentic-resource-discovery-ard-specification), [Synscribe ARD guide](https://www.synscribe.com/agentic-discovery/agentic-resource-discovery).

**Why it matters:** Worth watching but not worth implementing against yet. The pattern of "spec published, proposers don't deploy" is a classic early-standardization signal — treat ARD like robots.txt in 1995 until at least one working-group member ships the file.

### [UPDATE] MCP 2026-07-28 RC: stateless at the protocol layer — what actually changes

**Background:** The MCP 2026-07-28 release candidate was locked May 21, opening a 10-week SDK validation window ahead of a July 28 GA.

**New (clarification on scope of breaking changes):** The headline change is removal of the `Mcp-Session-Id` header and the `initialize/initialized` handshake entirely — any MCP request can now land on any server instance (load-balancer friendly). Capabilities no longer require an initialization round-trip; they travel inline via a `_meta` field per request and via a new `server/discover` method. Two new routing headers — `Mcp-Method` and `Mcp-Name` — allow gateways and rate-limiters to route on the operation without inspecting the request body. `Roots`, `Sampling`, and `Logging` are formally deprecated (Active → Deprecated → Removed minimum 12-month policy). Breaking for any client that relies on session affinity.

Sources: [MCP blog RC post](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [MCP.directory](https://mcp.directory/blog/mcp-2026-07-28-release-candidate), [Microsoft TechCommunity](https://techcommunity.microsoft.com/blog/appsonazureblog/mcp-just-went-stateless-%E2%80%94-what-the-2026-spec-changes-about-scaling-on-app-servic/4530222).

**Why it matters:** If you're running a custom MCP server (Resend, internal tools) or using FastMCP, you need to track Tier 1 SDK maintainers' RC support timelines — the 10-week window runs out around July 30. Stateless MCP enables horizontal scaling that was impossible before.

## Practical Tips

- **`claude agents`** is now in Claude Code CLI — run it to inspect active agent sessions during Routines runs or multi-agent ultracode workflows.
- **MCP session affinity:** If you're deploying MCP servers behind a load balancer today, the 2026-07-28 RC removes the need for sticky sessions entirely. Plan the migration now rather than retrofitting after GA.
- **GPT-5.6 Sol pricing:** At $5/$30 per 1M tokens (in/out), Sol is priced between Fable 5 API and Opus 4.8. Worth a cost-per-task benchmark once GA — particularly for agentic tasks where the "ultra" sub-agent mode may change token economics.
