## Tools & Frameworks

### [UPDATE] MCP 2026-07-28 release candidate locked: stateless protocol, MCP Apps, Tasks extension

**Background:** The MCP 2026 roadmap (published May 18) outlined a stateless protocol overhaul as the year's headline work — removing session-affinity requirements that have been the main production scaling bottleneck.

**New:** The release candidate was locked May 21. Six coordinated SEPs achieve statelessness at the protocol layer:

- `initialize`/`initialized` handshake removed (SEP-2575): protocol version, client info, and capabilities now travel in `_meta` on every request.
- `Mcp-Session-Id` and all protocol-level session state removed (SEP-2567): any server instance can handle any request — plain round-robin load balancers work, no sticky routing, no shared session stores.
- `server/discover` method replaces the handshake for on-demand capability lookup.

Also in the RC: **MCP Apps extension** — servers ship interactive HTML interfaces rendered in sandboxed iframes; tools declare UI templates ahead of time so hosts can prefetch, cache, and security-review them before runtime; every UI-initiated action routes through the same audit/consent path as a direct tool call. **Tasks extension** — servers answer `tools/call` with a task handle; clients drive with `tasks/get`, `tasks/update`, `tasks/cancel`; supports retry semantics and expiry policies.

Authorization aligns more closely with OAuth and OpenID Connect. Ten-week SDK validation window is open now. Final specification publishes July 28, 2026.

**Why it matters:** Stateless MCP eliminates the sticky-session and shared-store requirements that made horizontal scaling hard in production. If you maintain an MCP server or client library, start testing against the RC now — the 10-week window is your lead time before the final spec lands and adoption accelerates.

Sources: [MCP Blog RC post](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [The New Stack](https://thenewstack.io/model-context-protocol-roadmap-2026/), [MCP Roadmap](https://modelcontextprotocol.io/development/roadmap)

## Security

### [NEW] TeamPCP supply chain attack breaches GitHub, OpenAI, Mistral via Nx Console VS Code extension

A multi-stage supply chain attack culminated in a GitHub breach disclosing approximately 3,800 internal repositories. Timeline:

- **May 11:** TeamPCP compromised TanStack's entire router ecosystem — 170 npm packages and 2 PyPI packages simultaneously updated with a worm-like credential-stealing payload.
- **May 18:** A stolen contributor GitHub token pushed a trojanized `Nx Console` v18.95.0 (2.2M+ VS Code installs). The malicious build was live on the VS Code Marketplace for **18 minutes** (12:30–12:48 PM UTC). In that window, developer machines at GitHub, OpenAI, and Mistral were compromised.
- The payload is a multi-stage credential stealer that exfiltrates secrets via HTTPS, the GitHub API, and DNS tunneling.
- **May 19:** GitHub disclosed the breach publicly (~3,800 internal repos exfiltrated). Grafana Labs also confirmed a breach via the same vector.
- **May 20:** TeamPCP claimed responsibility; security community confirmed TanStack as root cause.

Fix: update Nx Console to **18.100.0 or later** immediately. If you had any version installed between May 11–18, rotate all credentials that were present in any VS Code workspace during that period.

Sources: [The Hacker News](https://thehackernews.com/2026/05/github-internal-repositories-breached.html), [Help Net Security — root cause](https://www.helpnetsecurity.com/2026/05/21/github-grafana-breach-root-cause-nx-console/), [Help Net Security — breach](https://www.helpnetsecurity.com/2026/05/20/github-breached-teampcp/), [aikido.dev](https://www.aikido.dev/blog/github-breached-vs-code-extension), [OX Security](https://www.ox.security/blog/teampcp-strikes-again-how-a-trojan-vs-code-extension-brought-down-github/)

## Practical tips

- **Nx Console:** If you use VS Code and have Nx Console installed, open Extensions, check your installed version, and update to 18.100.0+ immediately. Also audit any `.env` files and API keys that were accessible in open workspaces the week of May 11–18.
- **MCP RC testing:** The MCP 2026-07-28 RC is open for review at `blog.modelcontextprotocol.io`. If you ship an MCP server or SDK integration, the 10-week window before the July 28 final spec is your validation lead time. The stateless model means you'll need to move any session state out of protocol-layer headers — plan accordingly.
- **Claude Code:** v2.1.148 (May 22) is a hotfix for a Bash tool exit-code-127 regression introduced in v2.1.147. If you hit unexpected Bash failures after the recent auto-update, `claude --version` to confirm you're on 2.1.148+.
