## Tools & Frameworks

### [UPDATE] Claude Code v2.1.281 — cross-account Bedrock, MCP elicitation, attribution opt-out

**Background:** v2.1.280 (Sep 22) set Opus 5.5 as the default Opus model and patched symlink write-path security.

**New (v2.1.281, Sep 23):**

- **Cross-account AWS Bedrock:** `assume_role` on Claude apps gateway Bedrock upstreams — gateway calls Bedrock as an IAM role assumed through STS in another AWS account, optionally one session per developer. Relevant if you're routing Claude Code through a shared centralized gateway.
- **Bedrock guardrail enforcement:** `{id, version}` on gateway Bedrock upstreams applies an Amazon Bedrock guardrail to every request passing through — org-level content policy enforcement without per-request client code.
- **MCP URL-mode elicitation (2026-07-28):** Servers on the new stateless spec can now ask Claude Code to open a browser-based auth/consent flow mid-session. Prerequisite for MCP servers that need OAuth or multi-step setup.
- **`claude plugin validate` MCP checks:** Now reports `.mcp.json` entries that would be silently dropped at load, plus insecure URLs. Good addition if you're building/shipping MCP servers.
- **`"attribution": false` in settings.json:** Hides all commit and PR attribution lines from Claude Code-authored commits/PRs.
- **Desktop security policy additions:** `blockReadsOutsideWorkingDirectories` and `disableBypassPermissionsMode` in desktop policy blocks for Claude Desktop deployments.
- **`/insights` auto-mode recommendation:** Estimates how many recent permission prompts auto mode could have handled — helps calibrate whether to flip the switch.
- **`telemetry.resource_attributes`:** Fixed labels pushed onto telemetry for all Claude Desktop and /login sessions — useful for multi-team gateway deployments.

Sources: [Havoptic v2.1.281 summary](https://www.havoptic.com/tools/claude-code), [GitHub release](https://github.com/anthropics/claude-code/releases/tag/v2.1.281), [Claude Code changelog](https://releasebot.io/updates/anthropic/claude-code)

### [NEW] LLM Gateway Smart Route — classifier-based model routing, free beta

LLM Gateway shipped **Smart Route** on September 25 as a free beta feature. A classifier rates each incoming request and dispatches it to one of up to 30 models you configure — easy prompts go to a cheap model, hard ones to a frontier model.

- **How it works:** Choose the model pool (up to 30 from the catalog) and the classifier under Organization → Smart Routing. Use the string `smart` as the model identifier in your API calls.
- **Pilot results:** 33.2% cost reduction against a premium-model baseline.
- **Cost:** Free for every organization while in beta; not yet available on DevPass.
- **Relevance:** Drop-in if you're running high-volume agent pipelines mixing simple tool calls with complex reasoning — no code changes beyond the model string.

Sources: [LLM Gateway changelog](https://llmgateway.io/changelog/smart-routing), [LLM Gateway timeline](https://llmgateway.io/timeline)

## Model Releases

### [UPDATE] Claude Opus 5.5 ranks #1 on Blueprint-Bench 2 (3D spatial)

Claude Opus 5.5 topped Blueprint-Bench 2, a benchmark that asks AI agents to draw accurate floorplans from photographs of apartment interiors — testing 3D physical-world understanding rather than pure language or math reasoning.

**Why it matters:** Spatial reasoning from unstructured visual input is a prerequisite for real-world computer-use agents (navigating UIs, interpreting screenshots, understanding diagrams). Opus 5.5 leading here reinforces the value of the 1M-context + vision combination for complex agentic tasks.

## Practical Tips

**Claude Code v2.1.281 — quick wins:**
- If you're doing commits you don't want attributed to Claude Code (e.g., for a portfolio project where you want to show personal authorship), add `"attribution": false` to `.claude/settings.json`.
- If you have any `.mcp.json` entries you've been debugging, run `claude plugin validate` — the new check will surface silently-dropped entries.
- The `/insights` auto-mode recommendation is worth checking after a heavy session — it'll give you a concrete estimate of prompts that could have been auto-approved.
