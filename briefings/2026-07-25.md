## Anthropic

### [NEW] Claude Opus 5: outperforms Fable 5 on most benchmarks at half the price

Anthropic launched Claude Opus 5 on July 24, 2026 — its fourth new model in roughly two months. The headline number: 43.3% on Frontier-Bench v0.1, versus 33.7% for Fable 5 and 18.7% for Opus 4.8. On ARC-AGI 3, Opus 5 scores roughly 3× higher than any other model. Anthropic's system card describes it as approaching Mythos 5 quality in many areas while costing significantly less.

Pricing matches Opus 4.8 ($5/$25 per M input/output tokens) — half of Fable 5's $10 input rate. Fast mode doubles the rate ($10/$50) and runs ~2.5× faster. Context window is 1M tokens. Opus 5 is now the default `claude-opus-5` model in Claude Code v2.1.219.

Safety: deployed at ASL-3 (same as Opus 4.8). Cyber capabilities exceed Opus 4.8 but fall meaningfully short of Mythos 5 on exploitation tasks. Anthropic claims it is the company's safest model to date by multiple measures, with reduced deceptive behavior and fewer hard-to-reverse errors. System card published same day.

Sources: [TechCrunch](https://techcrunch.com/2026/07/24/anthropic-launches-opus-5/), [The Next Web](https://thenextweb.com/news/anthropic-claude-opus-5-launch-frontier-bench-coding), [SiliconANGLE](https://siliconangle.com/2026/07/24/anthropic-launches-claude-opus-5-efficiency-safety-improvements/), [AI Weekly](https://aiweekly.co/alerts/anthropic-launches-claude-opus-5-at-half-fable-5s-price), [System Card](https://www-cdn.anthropic.com/c5fbac3f0b1280a933ebd26d3cb8bb9f5bdeaf48/Claude%20Opus%205%20System%20Card.pdf).

**Why it matters:** For Stack's work: `claude-opus-5` is now the right pick for tasks that previously required Fable 5 but don't need Mythos-class security capabilities. The price drop is meaningful for any production agentic workflow running on Opus.

### [NEW] Claude Voice Mode expands to Sonnet and Opus with tool access and 18 languages

On July 23, Anthropic shipped a voice mode overhaul. Previously limited to Haiku, voice mode now supports Sonnet and Opus for paid plans. Voice now defaults to the last text model used, with a mid-conversation model picker (Haiku / Sonnet / Opus). Paid plan users can invoke connected tools — Gmail, Docs, Calendar — directly via voice mid-conversation.

Free plan users get the 18-language multilingual support (multilingual voice exited beta in June). Paid plans get all of the above.

Sources: [The Next Web](https://thenextweb.com/news/anthropic-claude-voice-mode-opus-sonnet-tools), [TechBriefly](https://techbriefly.com/2026/07/24/claude-voice-mode-adds-sonnet-and-opus-models/), [MLQ News](https://mlq.ai/news/anthropic-expands-claude-voice-mode-to-opus-and-sonnet-models/).

## Tools & Frameworks

### [UPDATE] Claude Code v2.1.219 (July 24): Opus 5 default, strictAllowlist, DirectoryAdded hook

Several developer-facing additions alongside the Opus 5 release:

- **Opus 5 default**: `claude-opus-5` is now the default Opus model (1M context). Existing configs using `claude-opus-4-8` continue to work.
- **`sandbox.network.strictAllowlist`**: denies all non-allowlisted outbound hosts in sandboxed commands without prompting — replaces the current prompt-on-unknown behavior.
- **`DirectoryAdded` hook**: fires after `/add-dir` or the SDK `register_repo_root` control request registers a new working directory mid-session. Useful for mono-repo setups where sub-project hooks need to activate dynamically.
- **`mcp_server_errors` in stream-json init event**: headless `--mcp-config` entries that fail config validation are now surfaced in the init event rather than silently skipped.
- **`workflowSizeGuideline` settings key**: the advisory dynamic workflow size cap can now be set from any settings file (previously required a config flag).
- **Nested subagent forwarding**: subagents spawned at depth-2+ now appear in stream-json output when `--forward-subagent-text` is set.
- **Bug fix**: `claude -p` no longer drops already-produced output when a turn dies mid-stream on an API error.

July 25: bug fixes and reliability improvements (no new features listed).

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code).

**Why it matters:** `sandbox.network.strictAllowlist` is a meaningful security improvement for workflows that run agent-generated code in sandboxes — replaces a prompt that users were likely auto-approving. The `DirectoryAdded` hook closes a gap for mono-repo setups with per-package CLAUDE.md files.

### [UPDATE] MCP 2026-07-28 spec: beta SDKs live, GA in 3 days

The MCP 2026-07-28 release candidate has been final since May 21; beta SDKs for the spec are now published. GA ships Monday, July 28. Recap of the breaking changes:

- Session layer removed: `Mcp-Session-Id` header and the initialize/initialized handshake are gone. Servers can now sit behind plain round-robin load balancers.
- Route traffic on `Mcp-Method` header; `tools/list` responses can be cached server-side via `ttlMs`.
- MCP Apps (server-rendered UI) and Tasks extension graduate from experimental to normative.
- OAuth integration becomes first-class. New `_meta` object standardized.
- 12-month deprecation window for legacy features — nothing breaks July 28 for compliant existing implementations.

Sources: [MCP Blog](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/), [WorkOS](https://workos.com/blog/mcp-2026-spec-agent-authentication), [Akamai](https://www.akamai.com/blog/security-research/new-mcp-specification-security-teams-must-prepare), [Developer migration guide](https://stacktr.ee/blog/mcp-2026-spec-changes).

**Why it matters:** Beta SDKs being published now means production tooling can be validated before Monday's GA. Any MCP server relying on session state needs to pin the old spec or remove that dependency by July 28 + deprecation window.

## Model Releases

### [NEW] Grok STT 1.0: enterprise voice API goes broadly available via OpenRouter (July 23)

xAI's Grok STT 1.0 went live on OpenRouter on July 23 (one day ahead of xAI's announcement), opening the model to developers without a direct xAI account. The original Grok STT/TTS APIs launched in April 2026 in a more limited form; this 1.0 versioned release is the developer-accessible GA.

Specs: 25 languages, word-level timestamps, optional speaker diarization, multichannel audio. Pricing: $0.10/hr batch, $0.20/hr streaming. Benchmark claims (xAI-provided): 5.0% entity error rate on phone call transcription vs. ElevenLabs 12%, Deepgram 13.5%, AssemblyAI 21.3%. Also available on Vercel AI Gateway.

Sources: [OpenRouter](https://openrouter.ai/x-ai/grok-stt-1.0), [MarkTechPost](https://www.marktechpost.com/2026/04/18/xai-launches-standalone-grok-speech-to-text-and-text-to-speech-apis-targeting-enterprise-voice-developers/), [Vercel AI Gateway](https://vercel.com/ai-gateway/models/grok-stt).
