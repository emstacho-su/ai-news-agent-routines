## Tools & Frameworks

### [NEW] Apple iWork gains MCP support and AI assistants (Keynote, Pages, Numbers, Logic Pro)

Apple's October 27 Creator Studio update adds Model Context Protocol support to Keynote, Pages, and Numbers on macOS 27 — in beta, US English only. External AI agents can now read content, make edits, and trigger automated actions inside iWork documents without any screen-scraping. Logic Pro also gets an AI assistant.

Keynote simultaneously launches `.keyx`, an open JSON-based file format designed to be readable by developer tools and AI agents. Pages and Numbers get MCP but no matching format change. The update ships as a free update for Creator Studio subscribers in November.

Sources: [Daring Fireball](https://daringfireball.net/linked/2026/10/27/apple-creator-studio-updates), [ithinkdiff](https://www.ithinkdiff.com/keynote-pages-numbers-mcp-support-keyx/), [LetsDataScience](https://letsdatascience.com/news/apple-adds-motionvfx-ai-assistants-and-mcp-support-to-creato-61063603)

**Why it matters:** MCP surface area just expanded into Apple's productivity stack. If you're building MCP servers, iWork is now a consumer endpoint — worth knowing before you'd otherwise trip over it in a demo.

## Model Releases

### [UPDATE] Mistral Large 4 weights: Oct 31 planned release

**Background:** Mistral launched an API preview of Large 4 ("Le Chonk") on Oct 6 — 1T total parameters, ~49-52B active per token, multimodal, strong on cybersecurity tasks. October 31 was listed as the open-weights release date on Hugging Face.

**New:** The Hugging Face listing confirms Oct 31 as the target. The weights will ship under a custom Mistral license, not Apache 2.0 (different from Large 3). RL training updates are included in the weight drop; Mistral had noted further gains were expected. Active parameter count discrepancy (49B in launch post vs 52B on model page) remains unresolved.

Sources: [AIWeekly](https://aiweekly.co/alerts/mistrals-1t-parameter-large-4-slated-for-october-31-drop), [The New Stack](https://thenewstack.io/mistral-large-4-weights/), [Betanews](https://betanews.com/article/mistral-large-4-preview-open-weights/)

## Wildcard

### [NEW] OpenAI cuts $30B round valuation target to $1.25T

OpenAI trimmed its target valuation for an ongoing $30B funding round from ~$1.4T to $1.25T after investor pushback, per FT reporting from around Oct 23. UAE investors and Coatue are leading. The prior closed round (March 2026) was $122B at an $852B post-money valuation — so even at $1.25T this would represent a ~47% step-up in roughly seven months.

### [NEW] Google AI Mode ads expand to 10 countries; multiturn ads launch in US

Google announced October 28 that ads in AI Mode are expanding to Australia, Canada, India, Kenya, Malaysia, New Zealand, Nigeria, Pakistan, Philippines, and Singapore. Brazil, Mexico, and UK are slated for Q4 2026. In the US, "multiturn ads" are going live — sponsored results that persist across follow-up queries in the same AI Mode session, labeled "Sponsored."

Sources: [Search Engine Roundtable](https://www.seroundtable.com/google-expands-ads-ai-mode-42412.html), [Google Ads Blog](https://blog.google/products/ads-commerce/ads-in-ai-mode-global/)

## Practical tips

- Before building an MCP server targeting Apple productivity workflows: the new Keynote `.keyx` format is JSON-based and explicitly designed for external tooling — start there rather than screen-scraping `.key`.
- If you're evaluating Mistral Large 4 for a project, wait for the weight drop today before committing to hosted API pricing. Check the custom license terms before any commercial use — it's not Apache 2.0.
