## Tools & Frameworks

### [NEW] OpenAI GPT-5.6 family now in Kiro (AWS AI-native coding IDE)
Announced Aug 24, 2026. **Kiro** is AWS's AI-native coding agent/IDE built around engineering-rigor workflows: requirements → structured implementation plans → multi-step code execution → checkpoint review → property-based test generation. It's been in preview; this update brings all three GPT-5.6 tiers (Sol, Terra, Luna) as available backends.

Joint OpenAI+AWS testing on Terminal-Bench 2.1: **~82% cost reduction per completed task** compared to prior model baselines. GPT-5.6 Luna handles routine steps cheaply; Sol handles complex reasoning steps; Terra sits between.

Sources: [OpenAI announcement](https://openai.com/index/gpt-5-6-in-kiro/), [Kiro blog](https://kiro.dev/blog/gpt-5-6/).

**Why it matters:** Kiro is positioned as Cursor/Claude Code competition from the AWS ecosystem. The tiered-model routing within a single agent loop is a real differentiator — and the 82% cost claim is specific enough to verify. Worth watching as an architectural pattern even if you stay on Claude Code.
