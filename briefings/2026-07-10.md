### [UPDATE] MCP security: stateless spec shifts burden to devs; 5,832 vulnerable servers; NSA guide

With the July 28 RC making MCP fully stateless, the security posture shifts: the protocol no longer enforces session boundaries, so everything relies on implementation.

**New data this week:**
- **5,832 vulnerable public MCP servers found** (Adversa AI sweep); 2,259 confirmed exploitable — file access, command injection, SSRF, SQL injection via natural-language queries.
- **NSA released official MCP hardening guidelines** — first government-level guidance on securing MCP deployments; covers tool vetting, auth layering, and restricting server-initiated requests.
- **Production attack documented by Microsoft:** Tool-poisoning and description-injection against a fintech enterprise MCP server — AI processed malicious tool descriptions and exfiltrated data; detailed defensive playbook published.
- **Amazon Q auto-execution vulnerability** found in the new stateless spec; patched, but illustrates the class of problem.
- SecurityWeek frames the architectural issue: the stateless model lets any round-robin load balancer route MCP traffic, but removes the protocol's former session-validation layer entirely. Security is now the implementer's problem.

**Why it matters for Stack:** If you're building MCP servers or connecting Claude Code to third-party MCP servers, this is the current threat model — the July 28 spec changes raise the floor for performance and scalability but raise the ceiling for attack surface. NSA guide is worth reading before plugging in new servers.

Sources: [SecurityWeek](https://www.securityweek.com/new-enterprise-ready-mcp-specification-brings-new-security-challenges/), [Adversa AI (July 2026)](https://adversa.ai/blog/top-mcp-security-resources-july-2026/), [GBHackers](https://gbhackers.com/thousands-of-mcp-servers-found-vulnerable/)

### [UPDATE] OpenAI ChatGPT Work: outcome-agent launches with GPT-5.6, Codex merged into desktop

Alongside the GPT-5.6 GA yesterday (July 9), OpenAI shipped two structural product changes:

**ChatGPT Work** is a new agentic mode in the ChatGPT desktop app that takes an outcome (not a prompt), gathers context across connected apps and workflows, and stays with complex projects for hours — breaking them into sub-tasks and completing them independently. Think of it as a persistent background worker rather than a chat session. Powered by GPT-5.6 Sol/Terra/Luna depending on subscription tier.

**Codex merged into the desktop app:** The separate Codex app is being folded into a unified new ChatGPT desktop (macOS and Windows) — three modes: Chat, Work, and Codex. The old ChatGPT desktop is renamed "ChatGPT Classic." All three modes available on every plan, including Free.

The rebranding signals OpenAI consolidating its coding + agent + chat surfaces into a single front-end, similar to how Claude Code + Claude.ai + Claude Cowork are converging around Claude's desktop.

## Wildcard

### [NEW] Illinois AI Safety Measures Act: nation's strongest state AI law, signed July 6

Gov. Pritzker signed SB 315 in Chicago on July 6, effective January 1, 2027. Key provisions:

- **Mandatory annual third-party safety audits** — first US state law requiring independent audits of frontier AI models; goes beyond California and New York bills.
- **Catastrophic-risk disclosure:** Frontier AI developers must publish a plan addressing "catastrophic risk" (defined as: >50 deaths, >50 serious injuries, or >$1M property damage from a single AI-caused incident) and update it annually.
- **Bipartisan passage, industry support:** Both OpenAI and Anthropic supported the bill. Illinois joins California and New York — three states estimated to cover ~40% of the US AI market, effectively creating a defacto national standard in the absence of federal regulation.
- The law specifically targets "developers of the largest advanced AI systems" — aimed squarely at frontier labs, not every company deploying AI.

Context: EU AI Act full enforcement arrives August 2, 2026 (23 days away). Illinois sets the US domestic equivalent for frontier safety disclosure.

Sources: [Capitol News Illinois](https://capitolnewsillinois.com/news/pritzker-signs-landmark-ai-regulation-bill-that-aims-to-mitigate-risks/), [WTTW Chicago](https://news.wttw.com/2026/07/06/pritzker-signs-landmark-ai-regulation-bill-aims-mitigate-risks), [Transparency Coalition](https://www.transparencycoalition.ai/news/illinois-gov-pritzker-signs-landmark-ai-safety-measures-act-into-law)
