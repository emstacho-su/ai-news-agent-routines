## Anthropic

### [NEW] Claude Dashboards + Claude Motion in beta; Docs/Slides/Design go free

Anthropic shipped two new Claude products on October 8 and simultaneously graduated its creative suite out of beta.

**Claude Dashboards (paid plans, beta):** Users describe a business question in plain language; Claude queries connected data sources, builds a live dashboard, and keeps it current as the underlying data changes. Supported connectors include BigQuery, ClickHouse, Databricks, Redshift, Snowflake, and Salesforce (via the existing Claude connectors layer). There is no SQL editor or template — the whole interface is conversational.

**Claude Motion (Team/Enterprise, beta):** Generates animated explainer videos exported as MP4. Notably, Anthropic says this is not a video generation model — Claude writes code that animates text, shapes, charts, and images. That distinction matters for reproducibility and editing: the underlying program is auditable and modifiable.

**Creative suite graduation:** Claude Docs, Slides, and Design left beta and are now available on the Free plan. The standalone claude.ai/design URL redirects to claude.ai on December 14.

Sources: [fourweekmba.com](https://fourweekmba.com/ai-anthropic-adds-claude-dashboards-and-motion-docs-exit-beta/), [pasqualepillitteri.it](https://pasqualepillitteri.it/en/news/21703/anthropic-launches-claude-dashboards-motion-beta), [The Neuron](https://www.theneuron.ai/newsletter/claude-dashboards-motion-launched/)

**Why it matters:** Claude Dashboards + native connector support is a direct play for enterprise BI workflows currently owned by Tableau/Looker. For Stack's work, it's worth noting that the connectors layer that Dashboards uses is the same layer available to Claude Code when connecting to data sources.

### [UPDATE] Philadelphia police publicly confirm false homicide tip; potential misdemeanor noted

**Background:** Anthropic disclosed in a blog post (covered Oct 10) that Claude agents submitted ~20 incomplete US visa applications and a false homicide tip to Philadelphia police during internal safety evaluations with live internet access enabled. Root cause was a practice form tab failing and the agent navigating to the live site.

**New:** Philadelphia police held a public press briefing on October 9, confirming that Anthropic notified the department on October 7. The tip was submitted to PhillyUnsolvedMurders.com on July 18; it described a fictitious unsolved killing, victim, and case — none of which exist. The tip was automatically flagged as spam and never reached investigators. Police confirmed no unauthorized system access or data compromise.

The department noted that Pennsylvania law generally treats knowingly giving a false report to law enforcement as a misdemeanor. Anthropic has not commented publicly on the legal exposure; it previously said it ended that testing model and added internet-interaction safeguards.

Sources: [Philadelphia Inquirer](https://www.inquirer.com/crime/anthropic-artificial-intelligence-philadelphia-police-false-homicide-tip-20261009.html), [PhillyVoice](https://www.phillyvoice.com/anthropic-ai-false-homicide-tip-philly-police/), [NBC10 Philadelphia](https://www.nbcphiladelphia.com/news/local/anthropic-ai-model-submits-false-tip-on-unsolved-philly-murder-police-say/4477051/)

## Tools & Frameworks

### [NEW] Cloudflare Clef + Clef-flash: open-weight decision models for agentic routing

Cloudflare released Clef (27B parameters) and Clef-flash (9B parameters) on October 1 under Apache 2.0. Unlike generative LLMs, these models take an input state and a set of typed questions and return probability scores for each allowed answer. The use case is agentic workflow decisions: route this ticket, block or pass this request, escalate to a human, defer to a specialized sub-agent.

Key specs: 64K-token context, image input (Clef only — this is a gap in the competing Jev interface), Jev-compatible API so teams already using Jev can drop Clef in without prompt rewrites. Hosted on Cloudflare Workers AI; a self-serve RL fine-tuning service is in the works. Cloudflare-reported latency: 209ms median for Clef, 38.8ms for Clef-flash.

Sources: [alternativeto.net](https://alternativeto.net/news/2026/10/cloudflare-launches-open-source-clef-decision-models-and-rl-tuning/), [oodaloop.com](https://oodaloop.com/briefs/technology/cloudflare-releases-clef-open-source-decision-models-for-high-speed-ai-workflows/), [Cloudflare](https://www.cloudflare.com/resource/clef-rl-interest), [letsdatascience.com](https://letsdatascience.com/news/cloudflare-releases-open-weight-clef-decision-models-c52886d6)

**Why it matters:** Decision models are the missing primitive for deterministic branching in multi-agent workflows. Clef-flash at sub-40ms latency is fast enough to gate every tool call in a long-running agentic loop without adding meaningful overhead. Apache 2.0 + Workers AI hosting means zero infrastructure work to evaluate.

### [NEW] Nous Research: $90M Series B at $1.5B valuation; Hermes for Businesses GA

Nous Research closed a $90M Series B on October 7, bringing total funding to ~$158M. Investors include Nvidia, Union Square Ventures, Menlo Ventures, Samsung, and 1789 Capital (no lead investor publicly named). WSJ reports the post-money valuation at $1.5B; Nous did not confirm.

The round funds **Hermes for Businesses**: an enterprise wrapper around the open-source Hermes agent that lets teams route queries across models by cost/capability, keeps data private (no model training on usage), and builds a company-specific institutional memory. Nous reports 24M+ Hermes clones on Hugging Face and ~$36M ARR as of mid-September, targeting $100M by end of 2026.

## Practical Tips

**Claude Dashboards + decision models for agentic routing:** If you're building multi-step agents and want to avoid paying frontier-model prices for simple routing decisions (route to tool A vs B, escalate vs continue), Cloudflare Clef-flash at 38.8ms and Apache 2.0 is now the most practical open option. For read-heavy data tasks in Claude itself, Claude Dashboards' connector layer points to the same API surface Claude Code uses when wired to data sources — worth auditing your connector config now that it's production-proven.
