## Model Releases

### [NEW] Google DeepMind Genie 4: Real-Time World Model With Native Audio

Google DeepMind announced Genie 4 on October 27, 2026, in limited preview for select trusted testers. It is the first world model to generate native audio (music, ambient noise, interactive dialogue) alongside video, based on the Gemini Omni architecture. Users can inject new text prompts mid-simulation to redirect the scene in real time. Simulations run up to two minutes. Output is SynthID-watermarked. No public API access or downloadable checkpoint has been announced; a Gemini 4 Argon-driven robotics experiment was demoed where the model broke tasks into steps that Genie 4 simulated in real time.

**Why it matters:** Genie 4 is the most credible candidate for a simulation backend for agentic testing environments — structured, grounded, real-time. Worth watching if Anthropic or any agent framework integrates a world model for sandboxed agent evaluation.

Sources: [Android Authority](https://androidauthority.com/google-genie-4-ai-world-model-launched-3728951), [BetaNews](https://betanews.com/article/google-announces-genie-4-model-for-creating-interactive-world-simulations/), [Northeast Times](https://northeasttimes.com/2026/10/27/google-deepmind-opens-genie-4-preview-to-testers-with-audio-and-two-minute/)

### [UPDATE] DeepSeek V4.1 Flash 1017: Native Vision + 1M Token Context

**Background:** DeepSeek V4.1-Flash launched in Sept 2026 as the fastest V4 architecture variant, with strong agent-benchmark results ($0.14/$0.28/M tokens in/out).

**New:** An October 17 build (`deepseek-v4-1-flash-1017`) adds native visual input (image understanding without a separate vision model) and extends the context window to 1M tokens. It is now listed as the canonical `deepseek-chat` API alias on OpenRouter. No pricing changes confirmed from the finalized Aug 16 rates.
