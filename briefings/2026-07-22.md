## Anthropic

### [NEW] Anthropic ships `agent-memory-2026-07-22` API beta with stable listing and SDK updates

Released today, the new beta header `agent-memory-2026-07-22` replaces `managed-agents-2026-04-01` for all memory store calls and changes listing behavior: results are now returned in a stable, server-defined order (the `order_by` and `order` params are ignored when the header is active). Breaking changes to note: `depth` now accepts only `0`, `1`, or omitted — other values return a 400; `path_prefix` must end with `/` and matches whole path segments instead of substrings; cursors issued without the header are invalid with it. The Python (0.116.0), TypeScript (0.110.0), Go (1.56.0), Java (2.48.0), Ruby (1.55.0), PHP (0.36.0), C# (12.35.0), and CLI (1.16.0) SDKs all send the new header by default as of today. Sending both headers together returns a 400. [Anthropic API release notes](https://releasebot.io/updates/anthropic/claude-developer-platform), [Anthropic managed agents memory docs](https://platform.claude.com/docs/en/managed-agents/memory).

**Why it matters:** If you're building on Claude Managed Agents and relying on memory pagination ordering, update SDK versions and re-test any code that uses `depth`, `path_prefix`, or paginated memory lists — the old cursor format is explicitly invalidated.

### [NEW] Nadella calls Fable 5 "editorially controlled" — first public Microsoft/Anthropic friction

In a July 16 internal engineers meeting first reported by CNBC, Microsoft CEO Satya Nadella said of Anthropic's Fable 5: "When it refuses for any random thing, it just is like, when was the last time you had a creation tool that was so editorially controlled?" The comments were directed at engineers building Copilot products on top of Fable. Context matters: Microsoft committed $5B to Anthropic in November while Anthropic pledged to route $30B to Azure; Copilot Cowork is built on Fable. Anthropic had acknowledged when restoring Fable access July 1 — following the US government export control pause — that the updated safeguards would flag a higher share of harmless requests than before. [CNBC](https://www.cnbc.com/2026/07/16/microsoft-ceo-says-anthropic-fable-request-policy-doesnt-make-sense.html), [Yahoo Finance](https://ca.finance.yahoo.com/news/microsoft-ceo-nadella-criticizes-anthropics-143800588.html).

**Why it matters:** This tension sits directly in the Anthropic-Microsoft financial relationship. If Copilot product teams route around Fable toward MAI or another model, it would affect which platform Anthropic's revenue flows through and which models Stack's own tools get in enterprise Copilot contexts.

## Tools & Frameworks

### [NEW] Google drops three Gemini Flash models; 3.6 Flash adds built-in Computer Use

On July 21, Google shipped Gemini 3.6 Flash, Gemini 3.5 Flash-Lite (GA), and a restricted Gemini 3.5 Flash Cyber in a single announcement. Key numbers for 3.6 Flash: $1.50/$7.50 per M tokens (input/output), 304 tok/s, 1M context, March 2026 knowledge cutoff, and 17% fewer output tokens needed on the Artificial Analysis Index vs. 3.5 Flash — meaning real cost drop is bigger than the sticker. The headline developer addition is built-in Computer Use shipped as a native client-side tool via the Gemini API and Gemini Enterprise; the benchmark is 83.0% OSWorld-Verified vs. 78.4% on 3.5 Flash. Gemini 3.5 Flash-Lite prices at $0.30/$2.50 per M tokens — the cheapest GA Gemini model. Gemini 3.5 Flash Cyber is a restricted security specialist (same channel as OpenAI's Daybreak/GPT-5.5-Cyber). Google separately confirmed it has begun pretraining for Gemini 4. [MarkTechPost](https://www.marktechpost.com/2026/07/21/google-releases-gemini-3-6-flash-3-5-flash-lite-and-3-5-flash-cyber-a-cheaper-more-token-efficient-flash-tier-built-for-agentic-workloads/), [9to5Google](https://9to5google.com/2026/07/21/gemini-3-6-flash-launch/), [Artificial Analysis](https://artificialanalysis.ai/models/gemini-3-6-flash).

**Why it matters:** Built-in Computer Use at Flash pricing is a direct competitive move against Claude's computer use and Fable-tier pricing. For cost-sensitive agent workloads, 3.6 Flash's effective output reduction plus lower per-token price makes it worth benchmarking as a drop-in for Claude Haiku 4.5 use cases. Flash-Lite at $0.30/$2.50 undercuts Haiku 4.5 on input price.

## Wildcard

### [NEW] South Korea plans free national AI chatbot for all citizens; targets year-end launch

South Korea's Ministry of Science and ICT opened competitive bidding July 14 for "AI for Everyone," a free, unlimited AI chatbot and public-service agent for all residents. The winning consortium (two or three private companies) must build the system using Korean domestic AI models for at least 50% of capacity. Timeline: beta chatbot by late September 2026, full service including a proactive government-benefits AI agent by year-end, free through 2028 under government funding. The initiative is a direct response to the roughly 23 million South Koreans using ChatGPT — the government wants to reduce dependency on US platforms. South Korea becomes the first G20 nation to pursue this model. [UPI](https://www.upi.com/Top_News/World-News/2026/07/21/free-nationwide-ai-service-december/2111784663714/), [TechTimes](https://www.techtimes.com/articles/321169/20260721/korea-pairs-ai-law-free-chatbot-23-million-quit-chatgpt.htm), [AI in Asia](https://aiinasia.com/north-asia/south-korea-ai-for-everyone-free-national-chatbot-msit-north-asia-deep-dive-2026-07-15).

### [NEW] Meta AI content moderation outperforms human moderators — with false positive collateral

Meta reported its AI content moderation system now produces 13% fewer errors and catches 10% more policy violations than human moderators at scale across Instagram and Facebook. The flip side: some users report the system has incorrectly deleted their accounts, suggesting the false-positive tail is visible to end users even while aggregate accuracy improves. [AI News Today July 22](https://aitoolsrecap.com/Blog/ai-news-july-22-2026).

## Research & Technical

### [NEW] LLM-as-a-Coach: Microsoft Research on post-training for non-verifiable tasks

Microsoft Research published "LLM-as-a-Coach: Experiential Learning for Non-Verifiable Tasks" (July 20, arXiv). The framework converts rich natural-language feedback into high-bandwidth learning signals for post-training LLMs on open-ended tasks where there's no ground-truth verifier — the main bottleneck for RL-based improvement on tasks like long-form writing, planning, and strategic reasoning. The approach treats the LLM itself as both student and coach in an iterative feedback loop. [arXiv via AlphaXiv](https://www.alphaxiv.org/).
