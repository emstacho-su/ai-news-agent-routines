## Tools & Frameworks

### [NEW] Microsoft cancels internal Claude Code licenses; Copilot CLI mandatory by June 30

Microsoft's Experiences+Devices team — the org that ships Windows, Microsoft 365, Outlook, Teams, and Surface — has begun revoking employee Claude Code licenses, with a hard cutoff of June 30, 2026 (end of Microsoft's FY). Engineers are being redirected to GitHub Copilot CLI as the single standard command-line agent.

The stated rationale is toolchain convergence; the financial subtext is that Claude Code's internal popularity was cannibalizing Copilot CLI adoption. The irony is notable: Microsoft quietly rolled out Claude Code to thousands of employees in December 2025 precisely because it caught on fast. That momentum is now the problem.

Anthropic's Claude models are not being dropped — they remain accessible through Copilot CLI and inside Microsoft 365 Copilot features, and the Foundry/Cowork agreements are unaffected. This is a distribution-layer decision, not a model-quality verdict.

**Why it matters:** This is the first confirmed large-scale enterprise rollback of Claude Code. It signals that Claude Code's enterprise adoption is now real enough to create internal political conflicts at the companies that build competing AI tooling. Watch for GitHub to accelerate Copilot CLI feature parity.

### [NEW] Semantic Kernel RCE: prompt injection → eval() → host code execution (patch now)

Microsoft disclosed two patched vulnerabilities in its Semantic Kernel agent framework on May 7. Both allow a prompt injection to escalate into host-level code execution or arbitrary file writes.

**CVE-2026-26030** (CVSS 9.8, Python SDK): The InMemoryVectorStore's default filter was constructed as a Python lambda and passed through `eval()`, with user-controlled input interpolated in. An attacker with any prompt injection route into the agent can execute arbitrary Python on the host. Affected: `semantic-kernel` Python < 1.39.4. Fix: upgrade to 1.39.4+.

**CVE-2026-25592** (.NET SDK): The `SessionsPythonPlugin`'s `DownloadFileAsync` helper — intended for sandboxed Azure Container Apps sessions — was accidentally exposed to the model as a callable kernel function, with no path validation. A hostile prompt could direct the agent to write a file to an arbitrary host path. Affected: Semantic Kernel .NET < 1.71.0. Fix: upgrade to 1.71.0+.

The pattern here is the same one that drove the trustfall-cli and OAuth hijacking disclosures: agent frameworks are blurring the line between language model inference and trusted OS operations. No architecture rewrite needed — both CVEs are fixed by patching.

**Why it matters:** If you or your employer is running Semantic Kernel-based agents (common in enterprise Azure+M365 Agent Framework deployments), check your version now. The eval() sink attack in particular is trivially weaponizable from a prompt injection that doesn't even need to be in the direct user turn.

Sources: [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/05/07/prompts-become-shells-rce-vulnerabilities-ai-agent-frameworks/), [NVD CVE-2026-26030](https://nvd.nist.gov/vuln/detail/cve-2026-26030), [NVD CVE-2026-25592](https://nvd.nist.gov/vuln/detail/CVE-2026-25592), [Windows Forum summary](https://windowsforum.com/threads/semantic-kernel-prompt-injection-bugs-let-attackers-run-code-or-write-files.416873/)

## Wildcard

### 1 million exposed AI services: the infrastructure attack surface is bigger than expected

The Hacker News ran findings from a scan of one million publicly exposed AI services this week. Summary: AI infrastructure is more misconfigured than any comparable software category previously surveyed. The leading exposure vector is self-hosted LLM inference APIs left open without authentication (LLMjacking). One reported honeypot handled 113,000 requests from thousands of unique IPs in a single month, with 23% of traffic specifically targeting AI capabilities.

Separately, Google's Mandiant team published first-in-kind evidence of threat actors using AI to develop a zero-day exploit — a 2FA bypass — with the script showing LLM-generation markers. The exploit was discovered proactively before mass exploitation.

Time-to-exploit is now negative for a meaningful fraction of CVEs (28.3% exploited within 24 hours of public disclosure). For anyone deploying any inference or agent API endpoint: auth is not optional.

Sources: [The Hacker News — 1M scan](https://thehackernews.com/2026/05/we-scanned-1-million-exposed-ai.html), [Help Net Security — AI-generated zero-day](https://www.helpnetsecurity.com/2026/05/11/google-ai-vulnerability-exploitation/), [The Hacker News — AI-assisted attacks](https://thehackernews.com/2026/05/2026-year-of-ai-assisted-attacks.html)
