## Anthropic

### [NEW] Claude Fable 5 + Mythos 5: First public Mythos-class models

Anthropic released two models built on the same weights on June 9: **Claude Fable 5** and **Claude Mythos 5**. Fable 5 is the general-use variant — it includes classifiers that detect high-risk requests (cybersecurity, bio/chem, distillation) and route those sessions to Opus 4.8 instead, triggering in under 5% of sessions on average. Mythos 5 is the same model with safeguards partially lifted, deployed exclusively through Project Glasswing in coordination with the US government. Sources: [Anthropic](https://www.anthropic.com/news/claude-fable-5-mythos-5), [CNBC](https://www.cnbc.com/2026/06/09/anthropic-mythos-claude-fable-5.html), [NBC News](https://www.nbcnews.com/tech/security/fable-5-anthropic-release-public-mythos-claude-model-rcna349104).

**Benchmarks:** 95.0% SWE-bench Verified, 80.3% SWE-bench Pro (+11 pts vs. Opus 4.8's 69.2%, +21 pts vs. GPT-5.5's 58.6%), 88.0% Terminal-Bench 2.1, 59.0% Humanity's Last Exam. Top on FrontierCode. Sources: [llm-stats](https://llm-stats.com/blog/research/claude-fable-5-review), [MangoMind](https://www.mangomindbd.com/blog/claude-fable-5-benchmarks), [Vellum](https://www.vellum.ai/blog/claude-fable-5-and-mythos-5-benchmarks-explained).

**Availability:** Included at no extra cost on Pro, Max, Team, and seat-based Enterprise plans June 9–22. Also available on Amazon Bedrock and GitHub Copilot. Sources: [AWS](https://aws.amazon.com/blogs/aws/anthropic-claude-fable-5-on-aws-mythos-class-capabilities-with-built-in-safeguards-now-available/), [GitHub Changelog](https://github.blog/changelog/2026-06-09-claude-fable-5-is-generally-available-for-github-copilot/).

**Why it matters:** Fable 5 is the first time Anthropic has made a Mythos-class model broadly accessible. The classifier-based safeguard architecture — rather than a separate restricted model — is a notable design choice; it means the same weights handle general and high-risk workloads, with routing at inference time.

### [UPDATE] Claude Code v2.1.169: /cd, safe mode, disableBundledSkills

**Background:** Claude Code has shipped incremental releases throughout May–June tracking under this topic.

**New (June 8, v2.1.169):**
- `--safe-mode` / `CLAUDE_CODE_SAFE_MODE` env var: starts Claude Code with all customizations disabled (CLAUDE.md, plugins, skills, hooks, MCP servers) for clean troubleshooting isolation.
- `/cd <dir>`: changes working directory mid-session without breaking prompt cache — useful for monorepo workflows.
- `disableBundledSkills` / `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS`: hides built-in skills, workflows, and slash commands from the model — useful for teams deploying their own complete skill sets.
- Auto-retry on unexpected non-retryable API errors using the fallback model.
- Fixed a recurring "image could not be processed" error that was burning extra tokens.
- Fixed remote sessions getting permanently stuck on backend disruption at startup.

Sources: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Classmethod DevelopersIO](https://dev.classmethod.jp/en/articles/20260609-cc-updates-v2-1-169/), [Releasebot](https://releasebot.io/updates/anthropic/claude-code).

**Why it matters:** `--safe-mode` is the right debugging primitive for diagnosing hook/MCP conflicts. The `/cd` cache-preserving directory switch directly improves Routine-style workflows where the working directory changes mid-run.

## Tools & Frameworks

### [UPDATE] WWDC 2026: Apple Foundation Models gets image input, multi-agent Dynamic Profiles, open-source plan

**Background:** WWDC 2026 keynote (June 8) confirmed Gemini-powered Siri, the LanguageModel protocol letting apps swap Claude/Gemini/on-device inference with a single SPM swap, and Anthropic's Claude Swift package implementing that protocol.

**New (June 9, Platforms State of the Union):**
- **Image input** added to the Foundation Models framework.
- **Dynamic Profiles**: a system for building multi-agent workflows within an iOS/macOS app; agents can be composed with different model backends per profile.
- **Free Private Cloud Compute** for developers with fewer than two million first-time App Store downloads — removing inference cost as a barrier for small developers building with cloud models.
- **Python SDK** for Foundation Models announced.
- Apple confirmed Foundation Models framework **goes open source** later this summer.

Sources: [MacRumors](https://www.macrumors.com/2026/06/09/apple-outlines-major-ai-and-developer-tool-updates/), [TechTimes](https://www.techtimes.com/articles/318039/20260609/wwdc-2026-developer-tools-foundation-models-now-swaps-ai-providers-without-code-changes.htm), [byteiota](https://byteiota.com/apple-foundation-models-wwdc-2026-multimodal-python-sdk/).

**Why it matters:** The free PCC tier makes the LanguageModel protocol actually viable for indie devs and side projects. Dynamic Profiles is Apple's answer to multi-agent orchestration — worth watching as a pattern for how the ecosystem will expect agents to compose.

## Wildcard

### [NEW] AI lab CEOs jointly urge Congress to mandate synthetic DNA screening

On June 5, the heads of OpenAI, Anthropic, Google DeepMind, and Microsoft AI sent a joint open letter to US Congress calling for mandatory screening requirements on synthetic DNA providers. The letter argues that recent AI advances have eroded the technical expertise barriers previously required to weaponize biological material — AI now lowers the entry threshold enough that existing voluntary screening programs are insufficient. The letter is notable for being a rare joint statement from companies that are otherwise in direct competition. Source: [Yellow.com](https://yellow.com/news/openai-anthropic-google-microsoft-synthetic-dna-congress-letter).

**Why it matters:** This is a direct intersection of AI capability and biosecurity policy. Anthropic has historically taken hard stances on CBRN (Glasswing/Mythos structure reflects this). The Fable 5 classifier routing on bio/chem requests launched the same week as this letter.

## Practical Tips

**Claude Code `/cd` in Routines:** If your Routine changes directories mid-run (e.g., cloning a data branch to `/tmp` then working in the source repo), `/cd <dir>` preserves the prompt cache across the directory switch. Previously you'd restart or lose cache on a manual `cd` via Bash.

**Fable 5 trial window ends June 22:** If you want to test Fable 5 on hard SWE tasks before deciding whether to pin it in production configs, the free-on-Max-plan window is 12 days from today.

**Claude 4 API retirement is June 15 (5 days):** Any code calling `claude-sonnet-4-20250514` or `claude-opus-4-20250514` hard-stops on the 15th. Audit MCP server configs and CI scripts now.
