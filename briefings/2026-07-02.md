## Anthropic

### [NEW] Claude Science: Multi-Agent Bioscience Workbench in Beta

Anthropic launched Claude Science in beta on June 30, 2026. It is an integrated research workbench — not a new or specially tuned model. It runs on existing Claude models (primarily Opus 4.8) and packages them with domain-specific tooling that researchers previously had to assemble themselves.

**Architecture:** Users interact with a generalist coordinating agent that has access to 60+ curated skills and connectors pre-configured for genomics, single-cell, proteomics, structural biology, and cheminformatics. This agent can spin up specialist sub-agents or invoke user-created specialist agents. A separate reviewer agent checks citations and calculations. The system produces auditable artifacts with verifiable output histories.

**Renderable outputs:** 3D protein structures, genome browser tracks, chemistry drawings — rendered directly in the workbench rather than handed back as raw files.

**Deployment options:** Runs locally on macOS or Linux; connects to SSH/HPC remote compute for heavier jobs.

**Grant program:** Applications open through July 15, 2026. Anthropic will fund up to 50 research projects with $30,000 in Claude Science compute credits each; Modal contributing up to $2,000 per selected project. Projects run September 1 to December 1, 2026.

Sources: [Anthropic blog](https://www.anthropic.com/news/claude-science-ai-workbench), [TechCrunch](https://techcrunch.com/2026/06/30/anthropics-claude-science-bets-on-workflow-not-a-new-model-to-win-over-scientists/), [MIT Technology Review](https://www.technologyreview.com/2026/06/30/1139987/claude-science-is-anthropics-newest-flagship-product/), [The New Stack](https://thenewstack.io/anthropic-claude-science-workbench/), [Endpoints News](https://endpoints.news/anthropic-debuts-claude-science-an-ai-product-for-bioscience/)

**Why it matters:** The VirBench result from yesterday's AI for Science event (16.9% → 92.8% with a single deterministic tool call) is now the stated product thesis for Claude Science: deterministic domain tools wrapped as agent skills outperform raw model capability on specialized scientific tasks. The same pattern — specialized MCP tool + generalist agent — is directly portable to non-biology domains for anyone building with Claude Code. The 60+ pre-built connectors are the differentiator, not the model weights.

## Tools & Frameworks

### [NEW] X Launches Official Hosted MCP Server

X (formerly Twitter) launched a hosted Model Context Protocol server on June 30, 2026. This is the first official, platform-hosted MCP server from a major social network.

**What it exposes:** 200+ X API endpoints as discoverable MCP tools — posting, searching, reading user timelines, managing bookmarks, looking up profiles, likes, and retweets. All covered by browser-based OAuth consent using the user's own account permissions.

**Developer impact:** Previously building X integration into a Claude Code workflow required you to run your own MCP server, manage API keys, and handle OAuth yourself. Now it's a one-line config addition pointing at X's hosted endpoint. The same pattern applies to Claude Desktop, Cursor, and Grok — any MCP-compatible client.

Sources: [TechCrunch](https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use/), [The Next Web](https://thenextweb.com/news/x-hosted-mcp-server-ai-tools-api), [CyberSecurityNews](https://cybersecuritynews.com/x-launches-hosted-mcp-servers/), [Startup Fortune](https://startupfortune.com/x-launches-an-official-mcp-server-and-every-social-platform-will-need-to-follow/)

**Why it matters:** The distribution story here is that MCP is becoming the default integration surface for consumer platforms. Linkedin, Reddit, and GitHub already have MCP servers; X joining closes most of the gap for social-context tools. For Stack building AI agents: X context (search, timelines) is now a plug-and-play MCP tool rather than a side project. The bigger observation from Startup Fortune is right: every social platform will eventually need an MCP endpoint or lose agent-accessible distribution.

## Policy & Wildcard

### [UPDATE] White House AI EO 30-Day Implementation Deadline Hits Today

The Trump administration's June 2, 2026 executive order "Promoting Advanced Artificial Intelligence Innovation and Security" set a 30-day deadline — today, July 2 — for the Secretary of the Treasury (in consultation with the National Cyber Director, NSA, and CISA) to establish an **AI Cybersecurity Clearinghouse**. The clearinghouse is designed to coordinate voluntary vulnerability reporting between AI developers and critical-infrastructure operators.

No public completion announcement had been made as of this briefing. The EO also set an August 1 deadline for a voluntary frontier model pre-release framework (a successor mechanism to the pre-release notification system that was previously postponed).

Sources: [White House EO](https://www.whitehouse.gov/presidential-actions/2026/06/promoting-advanced-artificial-intelligence-innovation-and-security/), [Lawfare](https://www.lawfaremedia.org/article/white-house-releases-executive-order-on-ai), [Inside Privacy](https://www.insideprivacy.com/artificial-intelligence/white-house-releases-executive-order-on-ai-and-security/)

### Lookahead: UN Global AI Governance Dialogue — Geneva, July 6

The UN Global Dialogue on AI Governance begins Monday in Geneva. Member states will discuss international approaches to managing frontier AI development, including compute governance, model access frameworks, and liability. No binding outcome is expected, but the dialogue runs parallel to ongoing US export-control negotiations and the EU AI Act August enforcement window — the policy calendar is dense. Worth tracking for any surprises on international AI access rules.

Source: [UN News](https://news.un.org/en/story/2026/07/1167848)

## Practical Tips

- **Claude Science applications open until July 15.** If you're doing computational research or building tools for researchers, the grant program is a legitimate $30K+ credit opportunity. The application bar is probably not high for a graduate student with an iSchool research angle. Apply at the Anthropic site — 50 slots.
- **X MCP server:** Drop `x.com/mcp` (OAuth flow required) into your `.mcp.json` to get real-time X search in Claude Code sessions. Useful for news monitoring, sentiment analysis, or any workflow that benefits from live social context without building a scraper.
- **MCP 2026-07-28 spec RC is live.** The stateless protocol update removes the initialize/initialized handshake and Mcp-Session-Id header — breaking changes for anything that depends on session IDs. If you maintain an MCP server, the 10-week SDK update window started May 21; final spec ships July 28. Check the [spec RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) before then.
