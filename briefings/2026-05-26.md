## Tools & Frameworks

### [NEW] Cursor Composer 2.5: near-Opus-4.7 coding at 1/60th the input cost; SpaceXAI 10x-compute model in training

Released May 18–19, 2026. The headline is pricing: $0.50/$2.50 per million input/output tokens (Standard tier) versus Opus 4.7's $30/$150 — roughly 60x cheaper on input. Performance is within a rounding error of Opus 4.7: 79.8% SWE-Bench Multilingual vs Opus 4.7's 80.5%; on Cursor's own CursorBench v3.1 at default settings, Composer 2.5 leads 63.2% vs 61.6%.

Architecture: Composer 2.5 is built on the Kimi K2.5 open-source base (1T MoE, ~32B active params per inference), identical to Composer 2. The differentiation is entirely in Cursor's post-training: 85% of compute budget went to 25x more synthetic RL coding tasks versus Composer 2, targeted text-feedback RL (localized correction signals during long rollouts), and a Sharded Muon optimizer. The approach outperforms simply scaling the base model — Cursor's synthesis dominates the performance gap over vanilla Kimi K2.5.

Next: Cursor and SpaceXAI are jointly training a model from scratch on Colossus 2 (1M H100-equivalents) using 10x total compute. No ship date.

**Why it matters:** For agentic pipelines where Opus 4.7 is the incumbent model, Composer 2.5 cuts inference cost dramatically with essentially no benchmark tradeoff. The "cheap open-weight base + heavy RL post-training" pattern is now clearly validated at near-frontier coding performance — expect more labs to replicate this approach.

Sources: [Cursor blog](https://cursor.com/blog/composer-2-5), [The New Stack](https://thenewstack.io/cursor-composer-benchmarks/), [ChatForest](https://chatforest.com/builders-log/cursor-composer-2-5-kimi-k2-5-coding-agent-benchmark/)

## Model Releases

### [NEW] Kimi K2.6: 1T open-weight MoE, ties GPT-5.5 on SWE-Bench Pro (released April 20, 2026)

Moonshot AI's open-weight flagship. 1T total / ~32B active parameters MoE. Key benchmarks: SWE-Bench Pro 58.6% (ties GPT-5.5 Instant), HLE with tools 54.0% (Moonshot claims top position), BrowseComp 83.2% (Agent Swarm variant: 86.3%). Agent Swarm architecture scales to 300 concurrent sub-agents across 4,000 coordinated steps — up from K2.5's 100 / 1,500. Pricing roughly 80% below GPT-5.5. Weights on Hugging Face. No restrictions on commercial use.

K2.6 is the same base underlying Cursor Composer 2.5, which demonstrates that Cursor's post-training nearly fully closes the gap to Opus 4.7 on coding tasks from this baseline.

Sources: [Miraflow](https://miraflow.ai/blog/kimi-k2-6-explained-moonshot-ai-open-source-model-ties-gpt-5-5-coding), [Kili Technology](https://kili-technology.com/blog/data-story-kimi-k2-6), [Hugging Face](https://huggingface.co/moonshotai/Kimi-K2.5)

### [NEW] Gemma 4: Google's #3 open model globally — late coverage (released April 2, 2026)

This was missed in prior briefing runs. Gemma 4 released April 2, 2026 under Apache 2.0. Four sizes: E2B (effective 2B), E4B, 26B MoE, 31B Dense. The 31B Dense ranks #3 globally on Arena AI text leaderboard; 26B MoE ranks #6 — both are the highest-ranked open-weight models in each size class. Native function-calling, structured JSON output, and system instructions baked into training for agentic workflows. Gemma 4 outperforms models 20x its size on reasoning benchmarks. Built on the same research base as Gemini 3. Cumulative Gemma family downloads across all generations: 400M+.

Notable ecosystem development: Hirundo's security-hardened Gemma 4 fine-tune, highlighted by Google DeepMind, outperforms models 170x its size on security evals.

Sources: [Google DeepMind](https://deepmind.google/models/gemma/gemma-4/), [Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/gemma-4/), [VentureBeat](https://venturebeat.com/business/google-deepmind-features-hirundos-security-hardened-gemma-4-model-outperforms-llms-170x-its-size-on-security)

## Practical tips

- Cursor's `composer-2.5` Standard tier ($0.50/$2.50 per M) makes it viable as a drop-in for Sonnet-class tasks in agent pipelines — if you're routing heavy agentic loops through the Cursor API, check whether the benchmark gap to Opus 4.7 matters for your specific task type before paying 60x more.
- Kimi K2.6 weights are freely available on Hugging Face (Apache 2.0). If you want an open-weight 1T MoE to experiment with for fine-tuning or self-hosting, K2.6's Agent Swarm benchmarks make it the strongest open option for multi-agent coding tasks right now.
- If you have Gemma 4 31B available via Vertex/Ollama, it's worth a benchmark pass for any agentic task that currently calls out to a larger (and more expensive) cloud model.
