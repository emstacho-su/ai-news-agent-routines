### [NEW] Anthropic cache diagnostics: public beta — API now returns cache miss reason

Anthropic shipped cache diagnostics in public beta. Pass `diagnostics.previous_message_id` on any Messages request and the API returns `cache_miss_reason`, identifying exactly where the prompt prefix diverged from the previous turn. Enable with the `cache-diagnosis-2026-04-07` beta header; the Anthropic Python SDK received support for it in mid-May. Sources: [Anthropic API release notes](https://docs.anthropic.com/en/release-notes/api), [Prompt Caching Dashboard coverage](https://phemex.com/news/article/anthropic-unveils-prompt-caching-dashboard-with-key-metrics-75230).

**Why it matters:** Cache hits are one of the most opaque failure modes in multi-turn agent loops. `cache_miss_reason` replaces manual header diffs and content-length guessing with a direct signal from the API.

### [UPDATE] Antigravity 2.0: Google's answer to Claude Code goes full agent platform; Gemini CLI retires June 18

**Background:** Google's Antigravity was a Gemini-powered coding assistant; Gemini CLI was the terminal-facing counterpart.
**New (from Google I/O May 19):** Antigravity 2.0 is a full agent-first development platform with three components: a redesigned desktop app with multi-agent parallel orchestration and scheduled background tasks; a Go-based Antigravity CLI (replacing Gemini CLI — same harness, same agent quality, terminal-optimized UX); and an Antigravity SDK for building custom agents on Google's coding infrastructure. Managed Agents integration in the Gemini API and enterprise support via Gemini Enterprise Agent Platform also ship. Running Gemini 3.5 Flash at 289 tokens/sec. **Gemini CLI and Gemini Code Assist IDE extensions retire June 18, 2026** for AI Pro, Ultra, and free-tier users; Agent Skills, Hooks, Subagents, and Extensions (now Antigravity plugins) carry over. **Why it matters:** Antigravity CLI is the first direct structural competitor to Claude Code with comparable feature depth: Skills/Hooks/Subagents map closely to Claude Code's plugin system. The June 18 hard retirement forces any Gemini CLI users off the old toolchain within four weeks.

## Model Releases

### [NEW] Gemini 3.5 Flash: GA today — 1M context, $1.50/$9/M, 4× faster, now the primary Google developer model

Google shipped Gemini 3.5 Flash as generally available at I/O on May 19. It replaces Gemini 3.1 Pro as the primary developer model for agentic and long-horizon work. Specs: 1M input / 65K output tokens; 4 thinking levels with "thought preservation" that carries reasoning state across turns; API model ID `gemini-3.5-flash`. Pricing: $1.50 input / $9.00 output per million tokens; $0.15 cached. Benchmarks vs. 3.1 Pro: 76.2% vs 70.3% on Terminal-Bench 2.1; 83.6% vs 78.2% on MCP Atlas (agent-level MCP tool use); 289 tokens/second sustained output in Antigravity CLI. Google claims scores within 2 points of Anthropic's flagship model on their internal benchmark at roughly a third of the price. Available immediately: Gemini API, AI Studio, Antigravity, Gemini app, AI Mode in Google Search. Sources: [Google DeepMind](https://deepmind.google/models/gemini/flash/), [llm-stats.com](https://llm-stats.com/models/gemini-3.5-flash), [RD World Online](https://www.rdworldonline.com/googles-gemini-3-5-flash-scores-within-two-points-of-anthropics-flagship-at-a-third-of-the-price/).

**Why it matters:** MCP Atlas is the benchmark to watch — it measures real agent tool-use across MCP surfaces. 83.6% puts Gemini 3.5 Flash well above its predecessor on the axis that matters most for production agent work, at a price point below Claude Sonnet 5.

## Practical Tips

- **Cache debugging**: Enable the `cache-diagnosis-2026-04-07` beta header on your Messages requests and log `cache_miss_reason`. If your agent loop mutates system prompts between turns (e.g., injecting timestamps or session IDs), this will immediately surface that as the miss reason.
- **Gemini CLI users**: Antigravity CLI migration is mandatory by June 18. Agent Skills, Hooks, and Subagents all port over; Extensions become Antigravity plugins. Start the migration now — four weeks goes fast.
- **Claude Code behind VPN**: The startup hang fix is live. If you were working around it with `ANTHROPIC_BASE_URL` or a local proxy, you can revert those workarounds.
